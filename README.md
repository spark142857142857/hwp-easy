# HWP Easy

**한글 설치 없이, 에이전트로 HWP 양식의 필요한 칸을 읽고 수정합니다.**

[English](README.en.md) · [사용 안내](docs/quick-start.md) · [문서 모음](docs/README.md)

HWP를 직접 처리하는 WASM 엔진에 대상 확인, 편집 검증과 저장을 더한 프로젝트입니다. **로컬 Codex에서는 지정한 HWP를 읽고 수정해 같은 파일에 저장하는 실행 경로**를 추가했습니다. 별도의 원격 MCP는 서버 보관본 저장·다운로드를 제공하며 공개 심사 중입니다. [로컬 직접 편집](docs/local-file-editing.md)

## 현재 상태

| 구분 | 상태 |
| --- | --- |
| 비공개 MVP | 한 계정에서 업로드 → 전체 읽기 → 기존 문단·표 셀 수정 → 저장 → 미리보기·다운로드·복구 확인 |
| 로컬 직접 편집 | 같은 경로 저장·복구, 문단·병합 표 행/열·셀 변경, 글꼴·서식·본문/셀 그림 삽입과 PNG 교체. 실문서 사본과 분리 패키지 검증 완료. 실제 디렉터리 업데이트는 별도 |
| 공개 플러그인 | 원격 패키지 0.1.9 심사 제출 완료, In review / Not published |
| Codex Cloud | 고정 합성 HWP의 입력·편집·저장·결과 회수 확인. 일반 양식과 결과 첨부 UI 전체 지원은 미검증 |
| 인증 | 현재 연결 호출과 자동 갱신의 지속 동작은 별도. 자동 갱신 문제는 조사 중 |

**저장소 공개와 플러그인 게시는 별개입니다.** 도메인 확인을 위해 사이트 URL 접근을 공개로 전환했으며 문서 작업에는 로그인과 소유자 확인이 필요합니다. 실제 공개 접속에서 익명 요청과 위조 신원 헤더의 거부를 확인했습니다. 다른 실제 계정의 설치·격리 검증은 남아 있습니다. 검증 범위는 [MVP 상태](docs/mvp-status.md), 출시 절차는 [공개 플러그인 준비](docs/public-plugin-release.md)에서 확인하세요.

## 원격 MCP를 사용할 때의 흐름

1. HWP Easy를 연결하고 본인 계정으로 인증합니다. 현재는 기존 비공개 연결 사용자에게 제공하는 흐름입니다.
2. 브라우저에서 HWP를 선택해 업로드하고, 저장본의 읽기 요청을 에이전트 대화에 전달합니다.
3. 원하는 기존 문단이나 표의 칸과 바꿀 내용을 지정합니다. 에이전트는 대상·기존 값·버전을 확인하고 검사 후 저장합니다.
4. 저장된 HWP를 내려받습니다. 이전 버전도 보관하며 필요한 경우 복구합니다.

> “‘지원 동기’ 칸을 아래 내용으로 바꾸고 다른 부분은 유지해줘. 같은 문서에 저장하고 HWP 다운로드를 알려줘.”

읽기·요약만 요청하면 저장하지 않습니다. 기본 저장은 **같은 원격 문서의 새 버전**이며 PC 원본은 바뀌지 않습니다. 다른 이름으로 저장은 요청한 경우에만 수행합니다. 자세한 조작은 [사용 안내](docs/quick-start.md)를 따릅니다.

## 원격 MCP의 지원 범위와 제한

- 비암호화 HWP 5.x의 지원하는 본문과 최상위 표 셀을 읽고, 버전에 고정된 대상의 텍스트를 수정합니다. 긴 문서는 끝까지 이어 읽습니다.
- 검증된 빈 셀 채우기·셀 비우기와 제한된 혼합 서식 치환은 원격 경로에서 제공합니다. 문서마다 실제 저장 전 검사에 통과해야 합니다.
- 원격 입력은 **최대 4 MiB**, 본문·표 셀 합계는 **400,000 UTF-16 단위**입니다. 이모지 등은 여러 단위로 계산될 수 있습니다.
- 새 문단·표 행·이미지·서식 생성, 암호·DRM 해제와 HWPX·PDF·DOCX 변환은 지원 범위에서 제외합니다. 새 줄바꿈을 추가하는 치환도 거부합니다.
- 직접 생성한 SVG 미리보기를 제공합니다. 내용·바이트 보존 검사가 모든 외부 HWP 뷰어의 글꼴·표·페이지 배치 일치를 보장하지는 않습니다.

사용하는 HWP 엔진은 [`@rhwp/core`](https://github.com/edwardkim/rhwp) **0.8.6**입니다. HWP Easy는 자체 parser/writer를 처음부터 구현한 제품이 아닙니다. 외부 엔진 위에 검증·저장·에이전트 작업 흐름을 구성합니다.

## 저장소 구조

```text
plugins/hwp-easy/       공개 MCP 플러그인 패키지 초안
plugins/hwp-easy-local/ 로컬 직접 편집 스킬 패키지 후보
probes/sites-runtime/  원격 Worker: 엔진 어댑터·검증·인증·D1/R2 저장·브라우저 화면
src/one_hwp/           공통 엔진 코드·Python 로컬 MCP·보존된 Windows COM 경로
tests/                 로컬 엔진·저장·MCP와 합성 HWP 검사
scripts/               저장소 점검·공개 플러그인 패키징
docs/                  사용자 안내·개발·검증·출시 문서
docs/legacy/           이전 Windows COM 개발·배포·형식 안내
.github/               Linux·Windows CI
```

디렉터리의 역사적 이름을 유지해 기존 실행 경로와 연결을 보존합니다. 개발 환경은 Node.js 22 이상과 Python 3.11 이상이며, 새 엔진 경로에 한글·COM·Wine·GUI는 필요하지 않습니다. 개발자는 [개발 시작](docs/developer-guide.md)과 [구조 설명](docs/architecture.md)을 확인하세요. 설치 명령은 일반 사용자의 정상 이용 흐름으로 요구하지 않습니다.
