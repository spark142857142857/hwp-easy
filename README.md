# HWP Easy

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

HWP Easy는 에이전트가 HWP 파일을 읽고 편집하도록 돕는 로컬 도구입니다. 변경 사항은 같은 파일에 저장하고 저장 전 내용은 복구용으로 보관합니다. Codex에는 플러그인으로 설치합니다. Claude Code와 Cursor용 패키지도 제공하며 두 앱의 최신 버전 갱신은 보류하고 있습니다.

문서 처리는 실행 환경의 파일 시스템에서 이루어집니다. [`@rhwp/core`](https://github.com/edwardkim/rhwp) 엔진을 패키지에 포함하며, 저장 전에는 현재 파일과 수정 대상을 확인합니다. 지원 범위는 문서 구조에 따라 달라집니다.

## 주요 기능

- 본문과 표 셀 읽기, 문구 검색과 SVG 미리보기
- 텍스트 수정, 문단 추가와 이동, 여러 줄 답변 작성
- 지원하는 표 구조와 글자 모양 변경
- 지원하는 위치의 PNG와 JPEG 그림 삽입, 교체와 크기 조정
- 충돌 검사와 보존 검사를 거친 같은 파일 저장
- 이전 버전 복구와 복구 전 편집본 보관
- 저장 후 내장 미리보기 텍스트와 첫 쪽 썸네일 갱신

편집 지원 범위는 문서 구조와 대상에 따라 다릅니다. [0.2.42에서 추가한 표 흐름 기능](docs/local-release-0.2.42.md)은 요청한 경우 내용에 맞춰 행·중첩 표 높이를 줄이고 빈 공간을 정리합니다. 일반 편집에서는 기존 최소 높이와 명시적 쪽 나눔을 보존합니다. 지원 부동 그림·단순 글상자는 같은 쪽의 확인 가능한 공간을 활용하며, 공간 부족·불확실한 흐름에서는 새 쪽으로 분리합니다. 같은 파일 저장·정확한 복구와 실제 한글 배치를 검증합니다. 현재 PC의 Codex 설치는 0.5.0이고 Claude Code와 Cursor는 0.2.19입니다. 검증하지 못한 구조는 부분 읽기 전용으로 처리하거나 작업을 거부하며, 부분 읽기에는 일부 개체 내용이 빠질 수 있습니다. F2 핵심 지원 프로필은 [대표 양식 마감 검증](docs/f2-closure-0.2.42.md)을 완료했으며 구조별 조건은 [확정 지원 범위](docs/f2-support-0.2.42.md)를 따릅니다.

**소스와 현재 PC 설치는 [0.5.0](docs/release-review-0.5.0.md)입니다.** HWP Easy 이름을 유지하고 설명과 로컬 정책을 정리했습니다. 설치된 실행기의 저장과 복구를 확인했으며 공개 포털에는 아직 제출하지 않았습니다. 설명과 정책을 검토한 뒤 실제 자동 검사와 심사를 진행합니다. 회전 그룹 표시를 보완한 I3 실행기는 이전 검증과 같습니다.

소스·검증 패키지 [0.2.51](docs/local-release-0.2.51.md)는 그룹/상자 내부 문단·서식·필드와 개별 하위 그룹 변형을 추가합니다. 같은 파일 저장·정확한 복구·실제 한글 배치를 대조했으며 [F4 지원 범위와 제한](docs/f4-support-0.2.51.md)을 따릅니다. [F3의 미리보기/배치 진단 확정 범위](docs/f3-support-0.2.50.md)도 유지합니다. 실제 Codex도 [0.2.51 설치·새 채팅 검증](docs/local-install-0.2.51.md)을 마쳤으며, 설치·공개 후속 작업은 [남은 작업](docs/remaining-work.md)에서 관리합니다.

현재 문서의 SVG 미리보기와 저장 후 재읽기는 외부 한글 프로그램과의 정확한 글꼴·줄바꿈·쪽 배치를 보장하지 않습니다. 작업별 조건과 미리보기 제한은 [지원 기능과 제한](docs/supported-features.md)에 정리되어 있습니다.

## 구성

`SKILL.md`는 AI에게 편집 절차를 알려 주는 지침입니다. 실제 HWP 처리는 함께 배포하는 실행기와 엔진이 수행합니다. 스킬 폴더에는 다음 파일이 포함됩니다.

| 구성 | 역할 |
| --- | --- |
| `SKILL.md` | 파일 읽기, 대상 선택, 편집·저장·복구의 실행 절차 |
| `references/` | 지원 작업, 요청 형식과 작업별 제한 |
| `scripts/local-runner.mjs` | 엔진 호출, 편집 검사, 로컬 저장·백업·복구를 수행하는 JS 번들 |
| `scripts/rhwp_bg.wasm` | HWP 내부 구조를 읽고 수정본과 SVG를 만드는 엔진 |
| 미리보기 WASM·폰트·고지 | 저장 후 내장 BMP 썸네일 생성과 미리보기 글꼴 대체 |

Codex 플러그인은 이 스킬과 실행 자원에 `plugin.json`, 이름·아이콘·설명·버전 등 설치 목록용 정보를 더한 패키지입니다. 같은 버전으로 생성한 세 앱 패키지는 같은 소스·실행기·WASM과 지원 조건을 사용합니다. 실제 설치 버전의 차이는 프로젝트 상태에 기록합니다. `SKILL.md` 하나만 복사해서는 HWP Easy를 실행할 수 없습니다. 세부 구조는 [아키텍처](docs/architecture.md)를 참조하세요.

## 설치

실행기와 엔진을 포함한 앱별 패키지 전체를 설치합니다. 실행 환경에는 Node.js 22 이상과 대상 파일의 접근 권한이 필요하며, 문서 엔진·WASM·JS 의존성은 배포본에 포함됩니다. 에이전트의 로그인과 이용 조건은 각 앱을 따릅니다.

| 클라이언트 | 배포 형식 | 설치 안내 |
| --- | --- | --- |
| Codex | 로컬 플러그인 | [설치 기록과 재현 절차](docs/local-plugin-installation.md) |
| Claude Code | 개인 스킬 패키지 | [설치와 호출](docs/agent-client-skills.md#설치와-호출) |
| Cursor | 개인 스킬 패키지 | [설치와 호출](docs/agent-client-skills.md#설치와-호출) |

Codex의 현재 설치 검증 버전은 **0.2.42**이며, 공개 배포와 Claude Code·Cursor 설치본은 **0.2.19**입니다. [공개 릴리스](https://github.com/spark142857142857/hwp-easy/releases/tag/hwp-easy-local-v0.2.19)에서 앱별 ZIP과 SHA-256을 받을 수 있습니다. OpenAI 디렉터리 게시는 별도 진행하며, 실제 설치와 검증 범위는 [프로젝트 상태](docs/project-status.md)에서 확인할 수 있습니다.

## 사용법

Codex에서는 스킬 메뉴에서 **HWP Easy**를 선택합니다. Claude Code와 Cursor에서는 `/hwp-easy`를 명시적으로 호출합니다. 스킬은 호출한 작업에만 적용됩니다.

Claude Code·Cursor 요청 예시:

```text
/hwp-easy C:\문서\지원서.hwp를 읽고 질문과 작성할 칸을 정리해줘. 파일은 수정하지 마.

/hwp-easy C:\문서\지원서.hwp의 지원 동기 칸을 "지역사회 문제를 해결하는 경험을 쌓고 싶습니다."로 채우고 같은 파일에 저장해줘.

/hwp-easy C:\문서\지원서.hwp를 방금 수정하기 전 내용으로 복구해줘.
```

기본 저장 대상은 지정한 파일의 원래 경로이며, 이전 바이트는 파일 옆의 `.hwp-easy-backups`에 보관합니다. 파일 지정, 저장 결과 확인과 복구 절차는 [사용 가이드](docs/quick-start.md)를 참조하세요.

## 프로젝트 상태

Codex 0.2.42 설치본을 새 채팅에서 명시적으로 호출해 일반 본문·셀 두 문단, 중첩 표 높이 축소, 부동 그림·글상자를 동반한 표 성장을 세 합성 파일에 저장하고 별도 후속 요청으로 원본 바이트를 정확히 복구했습니다. 설치 파일 25개·독립 판독·실제 한글 배치도 확인했습니다. [설치·새 채팅 검증](docs/local-install-0.2.42.md)과 [F2 마감 회귀](docs/f2-closure-0.2.42.md)를 참조하세요. Claude Code·Cursor는 0.2.19를 유지하며 갱신을 보류합니다. 다른 사용자 환경과 공개 준비는 [남은 작업](docs/remaining-work.md)에서 관리합니다.

원격 **0.1.9**와 Windows COM 프로토타입은 이전 구현으로 보관합니다. 코드·패키지·심사 기록은 [보관 자료](docs/README.md#보관-자료)에 있습니다.
