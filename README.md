# HWP Easy

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

한글을 설치하지 않고 에이전트에게 HWP 파일의 편집을 요청할 수 있습니다.

[English](README.en.md) | [사용 안내](docs/quick-start.md) | [문서 모음](docs/README.md)

로컬 Codex에서는 지정한 파일을 읽고 수정한 뒤 **같은 HWP 파일에 저장**합니다. 이전 파일은 복구용으로 보관합니다. 원격 MCP를 사용할 때는 서버에 올린 사본을 편집하고 결과를 내려받습니다. [로컬 편집 안내](docs/local-file-editing.md)

| 공개 플러그인 | 원격 패키지 0.1.9 심사 제출 완료. 제출 당시 상태는 In review / Not published입니다. |

사이트 주소는 도메인 확인을 위해 공개했지만, 문서에는 로그인한 소유자만 접근할 수 있습니다. 익명 요청과 위조 신원 헤더가 거부되는 것을 확인했습니다. 다른 계정의 플러그인 설치와 문서 격리 검증은 남아 있습니다. 자세한 기록은 [MVP 상태](docs/mvp-status.md)와 [출시 준비](docs/public-plugin-release.md)에 있습니다.

## 로컬에서 할 수 있는 편집

| 대상 | 지원하는 작업 |
| --- | --- |
| 텍스트와 문단 | 문구 검색, 부분 수정, 여러 줄 답변, 문단 추가와 삭제, 분리, 병합, 복제, 이동 |
| 표 | 표 생성과 이동, 지원하는 병합 표의 행과 열 변경, 셀 병합과 분리, 크기와 여백, 정렬 |
| 글자 서식 | 글꼴, 크기, 색, 굵게, 기울임, 밑줄, 취소선 |
| 그림 | 본문과 셀의 PNG/JPEG 삽입, 교체, 크기와 위치 변경, 자르기, 회전 |
| 복잡한 개체 | 누름틀 값 수정, 중첩 셀 텍스트와 글자 서식 수정, 그림 그룹 이동과 선택한 자식 그림 자르기 |

지원 여부는 문서 구조와 작업에 따라 달라집니다. 중첩 표의 구조 변경, 누름틀 생성과 삭제, 그룹 그림의 교체와 회전 등은 아직 지원하지 않습니다. 여러 수정을 한 번에 검사해 저장하며, 한 작업이라도 실패하면 일부만 저장하지 않습니다. 세부 조건과 시험 결과는 [로컬 편집 안내](docs/local-file-editing.md)를 참고하세요.

## 원격 MCP를 사용할 때의 흐름

1. HWP Easy를 연결하고 본인 계정으로 인증합니다. 현재는 기존 비공개 연결에서 사용하는 방식입니다.
2. 브라우저에서 HWP를 선택해 업로드하고, 저장본의 읽기 요청을 에이전트 대화에 전달합니다.
3. 바꿀 문단이나 표의 칸과 내용을 지정합니다. 에이전트가 대상과 기존 내용, 현재 버전을 확인한 뒤 수정본을 검사하고 저장합니다.
4. 저장된 HWP를 내려받습니다. 이전 버전도 보관하며 필요한 경우 복구합니다.

> “‘지원 동기’ 칸을 아래 내용으로 바꾸고 다른 부분은 유지해줘. 같은 문서에 저장하고 HWP 다운로드를 알려줘.”

읽거나 요약하기만 하면 저장하지 않습니다. 원격에서 저장하면 **같은 문서의 새 버전**이 생기고 PC 원본은 바뀌지 않습니다. 다른 이름으로 저장하려면 별도로 요청하세요. 자세한 조작은 [사용 안내](docs/quick-start.md)에 있습니다.

## 원격 MCP의 지원 범위와 제한

- 비암호화 HWP 5.x의 지원하는 본문과 최상위 표 셀을 읽고, 버전에 고정된 대상의 텍스트를 수정합니다. 긴 문서는 끝까지 이어 읽습니다.
- 검증된 빈 셀을 채우거나 비울 수 있습니다. 혼합 서식의 문구 수정도 일부 지원하며 저장 전 검사가 필요합니다.
- 원격 입력은 **최대 4 MiB**, 본문과 표 셀의 합계는 **400,000 UTF-16 단위**입니다. 이모지 등은 여러 단위로 계산될 수 있습니다.
- 새 문단, 표 행, 이미지나 서식을 만들거나 줄바꿈을 추가하는 수정은 지원하지 않습니다. 암호와 DRM 해제, HWPX/PDF/DOCX 변환도 지원하지 않습니다.
- SVG 미리보기를 제공합니다. 내용과 바이트 보존 검사만으로 모든 외부 HWP 뷰어의 글꼴과 표, 페이지 배치가 같다고 보장할 수는 없습니다.

HWP 처리에는 [`@rhwp/core`](https://github.com/edwardkim/rhwp) **0.8.6**을 사용합니다. HWP Easy는 이 WASM 엔진에 편집 대상 확인, 독립적인 보존 검사, 저장과 에이전트 연결을 더합니다.

## 저장소 구조

```text
plugins/hwp-easy/       공개 MCP 플러그인 패키지 초안
plugins/hwp-easy-local/ 로컬 직접 편집 스킬 패키지 후보
probes/sites-runtime/  원격 Worker, 인증, D1/R2 저장, 브라우저 화면
src/one_hwp/           공통 엔진, Python 로컬 MCP, 이전 Windows COM 코드
tests/                 엔진과 저장, MCP 검사
scripts/               저장소 점검과 플러그인 패키징
docs/                  사용 안내와 개발 문서, 검증 기록
docs/legacy/           이전 Windows COM 안내
.github/               Linux와 Windows CI
```

개발에는 Node.js 22 이상과 Python 3.11 이상을 사용합니다. 새 엔진은 한글이나 COM, Wine, GUI 없이 실행됩니다. 환경 준비는 [개발 시작](docs/developer-guide.md), 코드 구성은 [구조 설명](docs/architecture.md)을 참고하세요. 이 개발 환경 설치를 일반 사용자에게 요구하지 않습니다. 기존 실행 경로와의 호환성을 위해 디렉터리 이름은 유지했습니다.
