# HWP Easy

AI가 **내 PC에 설치된 한글**을 통해 기존 HWP 양식의 지정 항목을 수정하고, 원본을 보존한 새 HWP로 저장하도록 연결하는 프로젝트입니다. 저장소 이름은 `hwp-easy`입니다.

> 현재는 개발·검증 단계입니다. 내려받을 설치 파일, 일반 사용자용 화면, 원클릭 Codex 연결, 공개 플러그인은 아직 제공하지 않습니다.

## 무엇을 할 수 있나요?

- 기존 양식의 본문이나 표 안 텍스트, 이름 있는 입력 필드를 수정합니다.
- 기본 작업은 **HWP를 읽고 새 HWP로 저장**하는 것입니다. PDF나 DOCX를 거치는 작업이 아닙니다.
- 원본과 이미 있는 출력 파일은 덮어쓰지 않습니다.
- PDF·DOCX 출력은 사용자가 별도로 요청한 경우에만 추가합니다.

문서 처리 엔진, 개발자용 명령 도구, AI 연결용 로컬 MCP는 구현되어 있습니다. 실제 한글 2020과 개인정보 없는 합성 문서로 편집·저장·재열기 검사를 수행했습니다. 모든 복잡한 양식의 배치가 그대로 유지된다는 보장은 아닙니다. DOCX는 출력만 지원하며 배치가 달라질 수 있습니다.

## 현재 필요한 환경

Windows PC에 한글이 설치되어 있어야 합니다. HWP Easy는 한글 프로그램이나 독립적인 HWP 편집 엔진을 대신 제공하지 않습니다.

현재 구현은 **이미 등록된 한글 파일 접근 보안 모듈**도 필요합니다. 한글만 새로 설치한 PC에서 바로 작동한다고 약속할 수 없으며, 설치·승인 환경을 확인해야 합니다. DLL 설치나 레지스트리 변경을 자동 수행하지 않습니다.

신뢰할 수 있는 문서만 사용하세요. 작업 폴더 제한이 한글 앱 자체의 보안 격리를 뜻하지는 않습니다. AI 연결에서 조회한 본문·필드 정보가 사용 중인 AI 앱으로 전달될 수 있으므로, 민감한 문서는 해당 앱의 데이터 처리 조건도 확인해야 합니다.

## 만들고 있는 간편 사용 방식

목표는 별도 개발 환경 설정 없이 다음 흐름으로 사용하는 것입니다. **아래 화면과 파일은 아직 미구현입니다.**

1. 설치형 또는 포터블 프로그램을 실행합니다.
2. 작업할 문서 폴더를 직접 선택합니다.
3. 원하는 경우에만 연결 내용을 확인하고 Codex 연결을 승인합니다.
4. HWP Easy를 명시적으로 선택해 필요한 수정을 요청하고 새 파일을 받습니다.

설치 파일은 로컬 실행에 필요한 구성요소를 준비하고, 플러그인/MCP는 AI가 그 도구를 호출하게 연결하는 역할입니다. 플러그인 하나만 추가하면 내 PC의 한글 설치·보안 설정까지 해결된다는 뜻은 아닙니다.
