# 로컬 플러그인 디렉터리 등록

[프로젝트 상태](project-status.md) · [0.2.19 검증](local-release-0.2.19.md) · [개발 가이드](developer-guide.md)

2026년 10월 13일, 로컬 0.2.19 패키지를 OpenAI 포털에 업로드했습니다. 표시 이름은 HWP Easy이며 등록 식별자는 `hwp-easy-local`입니다. 현재 초안·미게시 상태이고 심사 제출은 수행하지 않았습니다. GitHub 사전 릴리스와 실제 설치본은 이 포털 등록과 별개입니다.

## 등록 식별자

처음에는 공개한 `hwp-easy-0.2.19.zip`을 사용했습니다. 포털의 기존 `hwp-easy` 등록에는 MCP 서버가 연결되어 있어, 서버 없는 패키지로 바꾸려는 업로드가 거부됐습니다. 오류는 기존 플러그인의 MCP 서버 추가·제거·교체를 지원하지 않으므로 새 플러그인을 만들도록 안내했습니다.

`package_directory_plugin.py`는 검증한 ZIP에서 등록 식별자와 호출 안내·디렉터리 표시 필드만 조정합니다. 실행기, HWP·미리보기 WASM, 글꼴, 스킬 지침, 참조와 라이선스는 원본과 바이트가 같습니다. 명시적 호출 정책도 유지합니다. 별도 엔진이나 원격 서버를 만들지 않습니다. 기존 원격 심사본은 유지합니다.

포털 제목 아래 설명은 줄바꿈 없는 30자 이하의 한국어 문구를 사용하며, 긴 설명에는 한국어 다음 영어를 둡니다. 기능 요약의 줄바꿈과 길이 문제도 보완했습니다. Codex·Claude Code·Cursor의 기존 배포 ZIP은 바꾸지 않았습니다.

## 포털 자동 검사

| 항목 | 관측 |
| --- | --- |
| 업로드 | 새 로컬 등록과 0.2.19 초안 생성 |
| 표시 필드 | 설명 길이·줄바꿈과 기능 요약의 초기 오류를 보완한 ZIP 재업로드 |
| 스킬 검사 | `edit-local-hwp` 검사 진행 중. 통과로 표시하지 않음 |
| 정책 URL | 개인정보처리방침·이용약관 URL 누락을 차단 항목으로 표시 |
| 접수 제한 | “We are not accepting more skills-only submissions at this time.”를 차단 항목으로 표시 |
| 심사·게시 | 미제출·미게시 |

이는 해당 시점의 실제 포털 관측입니다. [공식 제출 안내](https://developers.openai.com/plugins/deploy/submission)는 스킬 전용 패키지에 MCP 심사용 사례·시연 영상을 요구하지 않는다고 설명하지만, 이 계정의 포털에는 위 차단 항목이 표시됩니다. 문서의 일반 설명을 근거로 차단을 해제됐다고 판단하지 않습니다.

기존 개인정보처리방침과 이용약관은 원격 업로드·저장을 설명합니다. 이를 서버 없는 로컬판 정책으로 그대로 연결하지 않았습니다. 로컬 처리와 사용 중인 에이전트 플랫폼의 데이터 처리를 구분하는 정책을 준비하고 게시자가 확정한 뒤 URL을 연결해야 합니다.

원격판 승인 이력 때문에 로컬판의 심사 기간이나 요구사항이 줄어든다는 공식 보장은 확인하지 못했습니다. [새 버전 심사 안내](https://developers.openai.com/plugins/deploy/app-review)는 제출 정보·스킬 변경에 별도 초안과 새 심사가 필요하다고 설명합니다. 포털 접수 제한도 승인 이력으로 해제된 것으로 취급하지 않습니다.

## 패키지 검증

등록용 ZIP의 실행기로 합성 문서를 읽고 계획 무저장, 본문·두 문단 셀 편집, 같은 파일 저장·재읽기, 충돌 거부, 무변경 무저장, 이력, 원본 복구와 편집본 재복구를 확인했습니다. 별도 Python OLE·레코드 판독도 통과했습니다. 표시 필드 보완 뒤에도 모든 실행 자원과 스킬 지침의 바이트 일치를 확인했습니다.

이 결과는 로컬 실행 검증이며 포털 스킬 검사나 공개 승인 결과를 대신하지 않습니다. 생성 ZIP·해시·화면 기록은 ignored `outputs/directory-package/`와 `outputs/progress-20261013/`에 보관합니다.
