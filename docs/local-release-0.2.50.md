# 로컬 HWP Easy 0.2.50 검증 기록

[F3 확정 지원 범위](f3-support-0.2.50.md) · [남은 작업](remaining-work.md) · [프로젝트 상태](project-status.md)

2026년 10월 27일. F3의 남은 핵심 문장/서식·행 내부 쪽 이어짐·자동 다단·꼬리말/후속 본문을 한 묶음으로 보완했다. 원래 HWP 편집/저장 모델과 일회용 렌더 모델은 분리한다. 제목 행 반복·복잡한 개체/트리·전체 글꼴 조판 등 [지원 밖의 조건](f3-support-0.2.50.md#지원-밖의-조건)은 완료로 바꾸지 않았다.

## 변경 사항

- 원본 글꼴 지표를 사용한 구두점/괄호·기울임·장평/자간·같은 서식의 표시용 NFC·빈 문단을 포함한 복수 문단을 보완했다. 원본 문자와 편집 오프셋으로 역매핑하며 원본을 NFC로 저장하지 않는다.
- 자간과 장평의 조합에서 고정 크기의 자간을 더하던 오류를 수정했다. 장평을 적용한 각 글자 진행폭에 자간 비율을 적용한다. 장평 95%·자간 5% 문장의 마지막 두 줄이 실제 한글처럼 `2026, 확` / `인.`으로 나뉘는지 확인했다.
- 빈 ClickHere의 안내를 가상 글로 표시하고 원본 값/필드 식별을 보존한다. 개체/셀 판독 조건을 넘는 안내는 계속 거부한다.
- 한 루트·깊이 2/3의 행 내부 분할을 읽기 전용 뷰로 구성한다. 음수 좌표의 반복 글과 인접 쪽의 중복 줄을 제거하고, 병합 표에서 생기던 불필요한 빈 쪽을 보완했다. 계속 셀의 경계·쪽별 위/가운데/아래 정렬·중첩 여백도 반영한다.
- 2–4단 균등 너비의 자동 표 흐름/여러 쪽과 유효한 구분선/쪽 테두리를 보완했다. 기존 명시적/비균등 다단은 유지한다.
- 본문 빈 문단 2개가 접혀 후속 글이 약 42.7px 빨라지던 차이를 수정했다. 본문 공간을 넘는 후속 글은 다음 쪽으로 보낸다. 꼬리말 앞 간격·서식·인라인 표와 기본 쪽 번호를 표시하고 독립 머리말을 보존한다.
- 지원 내부 여백을 글상자 높이 추정에 반영하고, 종이/쪽 기준·후속 셀 문단의 유일한 전체 식별은 엔진 관측으로 보고한다. 모호한 식별·알려지지 않은 여백은 미확인으로 유지한다. 잘못된 꼬리말 글자 모양 시작값의 큰 배열 할당도 차단한다.

`render_flow_adaptations`에 표시 보정을 기록한다. 사본의 공백·문단·큰 측정용 쪽·임시 정의/위치는 저장하지 않는다. SVG·내장 BMP·진단은 같은 뷰를 사용하며 `layout_verified:false`를 유지한다.

프로필: 일상 문장/괄호·기울임·분해형 한글/결합 악센트·장평/자간·복수 문단 6건, 빈 필드 안내 정렬 3건, 40/65/85줄·깊이 2/3·정렬·복수 행/병합 9건, 자동 2–4단/배분/두 쪽/구분선·테두리 6건, 꼬리말 4건.

쪽 이어짐은 원래 색의 실제 한글에서 확인한다. 85줄은 3쪽에서 `L038`, `L078`로 이어지고, 깊이 3의 65줄은 `L037`부터 다음 쪽으로 이어진다. 꼬리말이 본문 공간을 줄이는 65줄 사례는 표가 2쪽에 걸치고 `TAIL`/`END`가 3쪽으로 이동한다. 단순 저장 성공이나 쪽 수 증가만으로 배치 검증을 통과 처리하지 않는다.

검사 중 발견한 차이는 수정 후 다시 검증했다. 첫 전체 로컬 실행의 실패 3개는 새로 모델링한 꼬리말을 여전히 미지원으로 기대한 검사였으며, 지원 사례와 지원 밖 고정 줄 간격의 무저장 거부로 나눴다. 초기 패키지의 장평/자간 줄 차이와 쪽별 정렬/중첩 여백 차이도 최종 패키지의 실제 한글 대조와 구분한다.

## CI·설치·공개

**GitHub Actions 실행 0회.** `workflow_dispatch`만 유지하며 사용자 명시 요청이 있어야 실행한다. 주요 단계/릴리스/시간 초과를 이유로 임의 dispatch 또는 재실행하지 않는다. 이번 변경의 Linux CI 통과를 주장하지 않는다. 새 F3 소스 검사는 기존 직렬 렌더 검사 목록에 추가했으며 전체 행렬/작업 시간/제품 제한은 늘리지 않았다.

Codex는 실제 **0.2.42**, Claude Code·Cursor는 **0.2.19**를 유지한다. 0.2.50 설치·새 채팅·공개 배포/심사는 미실행이다. 원격 0.1.9 코드/ZIP, 이전 ZIP, 기존 스킬의 명시 호출 정책을 보존한다. computer-use **0회**, 네이티브 검사는 신뢰한 합성 파일의 숨김 한글 자동화 API만 사용했다. 파일 선택·UI 클릭·전역 설정 변경은 하지 않았다.

## 재현

```sh
node --test --test-concurrency=1 tests/test_local_f3_closure.mjs
node scripts/package_local_plugin.mjs
node scripts/check-local-f3.mjs outputs/local-f3
python scripts/check-local-f3.py outputs/local-f3
node scripts/render-local-f3.mjs outputs/local-f3
# 선택적 개발 QA: 한글 자동화가 설정된 Windows에서 합성 파일만 사용
python scripts/render-local-f3-native.py outputs/local-f3
python scripts/check-local-f3-native.py outputs/local-f3
```

기존 `outputs/local-f3`가 없을 때 실행한다. 네이티브/이미지 비교에는 개발용 Python·Pillow·Hancom Automation이 필요하다. 제품의 Node/WASM 실행에는 Python/한글/서버를 추가하지 않았다. 근거는 로컬의 `outputs/f3-closure-20261027/`에 보관하며 개인 HWP나 QA 이미지를 저장소에 커밋하지 않는다.
