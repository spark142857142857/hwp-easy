# I3 회전 그룹 글 표시 검증

[남은 작업](remaining-work.md) · [지원 기능](supported-features.md) · [프로젝트 상태](project-status.md)

검증일: **2026년 10월 27일**. **0.5.0-dev.1은 소스·분리 패키지 검증 후보**다. 실제 Codex 설치는 0.2.51, Claude Code·Cursor와 공개 ZIP은 0.2.19를 유지한다. Actions·앱 설치 갱신·심사 제출·게시는 실행하지 않았다.

최종 공개 버전은 사용자 결정에 따라 **0.5.0**을 목표로 한다. 남은 구현·설치 검증을 마친 뒤 직관적인 이름을 결정하고 저장소·패키지·설명/정책 링크를 함께 변경한 다음 심사를 진행한다. 현재 이름은 변경하지 않았다.

## 수정 내용

회전한 그룹의 사각형 글상자는 HWP에 글이 남아 있어도 기존 SVG에는 외곽만 표시됐다. 회전 하위 그룹의 외곽 원점도 종이의 원점으로 잘못 계산됐다. 음의 대각 성분을 가진 180도 변환에서는 기존 글과 새 글이 중복될 수 있었다.

원시 그룹 계층·변환과 사각형 글 목록으로 표시용 장면을 재구성했다. 실제 한글에서 이 프로필의 글은 회전한 외곽의 축 정렬 영역 안에 **수평으로 조판되며 글꼴 크기는 유지**된다. 외곽을 따라 글자 자체를 회전하거나 확대하지 않는다.

- 필드 시작/끝을 단어 경계로 반영해 필드 값과 뒤쪽 본문의 잘못된 줄 결합을 보완했다.
- 종이 기준 전경 부동 그룹은 셀/본문 클립에서 분리해 셀 밖의 글과 외곽도 표시한다. 원래 셀/문단 식별을 결과에 유지한다.
- 원래 여백과 문단 정렬을 적용하고, 저장된 줄 캐시가 없는 가운데/아래 정렬의 내용 높이를 표시용으로 계산한다.
- 같은 위치의 형제 사각형은 전체 후보 수와 그리기 순서가 일치할 때만 연결한다. 모호한 식별은 경고를 유지하며 부분 교체하지 않는다.
- 미리보기·저장 썸네일·배치 관측은 같은 표시 뷰를 사용한다. 원본 글·서식·필드·변환을 표시용 문서로 덮어쓰지 않는다. 이 뷰는 저장/내보내기 API를 노출하지 않는다.

원시 편집·충돌 검사·같은 파일 저장·백업/복구 경로는 유지한다. `@rhwp/core 0.8.6` WASM을 수정하거나 한글을 실행 조건으로 추가하지 않았다. 실제 한글은 합성 문서의 독립 검증에만 사용했다.

## 확정 범위와 경계

| 조건 | 확인한 범위 |
| --- | --- |
| 그룹 변환 | 루트 15/-15/90/180/270도, 하위 그룹 10/-15/90/180도와 크기·위치 변경 |
| 글 목록 | 수평 사각형의 한국어/영문, 저장된 필드 값, 복수 문단, 혼합 크기·굵기, 같은 글의 형제 상자 |
| 정렬/여백 | 검증한 내부 여백, 문단 가운데/오른쪽 정렬, 위/가운데/아래 정렬 |
| 위치/순서 | 본문, 종이 기준 전경 부동 셀·깊이 2 중첩 셀, 두 번째 쪽, 완전히 겹치는 형제의 흰색 채움/그리기 순서 |
| 지원 밖 처리 | 불확실한 변환/식별, 세로쓰기, 내부 표·중첩 개체, 비사각형 글, 추가 셀 기준/뒤쪽 배치, 검증하지 않은 문단 여백·들여쓰기·정렬 프로필은 미보정/경고 |

가운데/아래 정렬의 추가 문단 앞뒤 간격·빈 문단, 측정 불가 문자/글꼴, 크기 한계나 모호한 SVG는 안전하게 보정을 중단한다. 지원 밖 구조의 글 표시를 완료로 간주하지 않는다. 기존 `DRAWING_TEXT_RENDER_UNVERIFIED`·내용 불완전 표시는 계속 사용한다. 보정한 구조도 `DRAWING_TEXT_RENDER_ADAPTED`로 구분한다.

**전체 글꼴·인쇄 배치의 동일성은 인증하지 않는다.** 실제 한글의 함초롬 글꼴과 미리보기 대체 글꼴의 조형·영문 폭에는 차이가 있다. `layout_verified:false`, 글꼴 대체 가능성 및 불확실한 배치 진단을 유지한다. 셀 안 그룹 검증도 문서 전체의 표/쪽 배치 동일성을 뜻하지 않는다.

## 재실행

```powershell
$localFiles = rg --files tests -g 'test_local_*.mjs'
node --test --test-concurrency=4 @localFiles
node --test tests/test_rhwp_bridge.mjs
node scripts/package_local_plugin.mjs
.venv/Scripts/python.exe -X utf8 scripts/archive_local_plugin.py
node scripts/check-local-drawing-render.mjs outputs/i3-new --package
.venv/Scripts/python.exe -X utf8 scripts/check-local-f4.py outputs/i3-new
.venv/Scripts/python.exe -X utf8 scripts/render-local-f4-native.py outputs/i3-new
node scripts/render-local-drawing-pages.mjs outputs/i3-new
```

이미지 검사는 Pillow·NumPy가 있는 Python으로 `scripts/check-local-drawing-images.py outputs/i3-new`를 실행한다. 네이티브 검사는 한글 Automation·pywin32·olefile이 있는 Windows에서 생성된 합성 파일만 읽는다. 운영 실행기나 일반 사용자의 설치 조건은 아니다. 새 출력 디렉터리를 사용한다.

I3는 이 범위에서 마감한다. 다음 순서는 [R3 다른 환경 설치/업데이트/복귀 → R4 공개 패키지 준비 → R5 이름 변경·심사](remaining-work.md#다음-작업)다. Claude Code·Cursor 갱신은 사용자 요청 전까지 보류한다.
