# 제품 범위

[문서](README.md) | [현재 상태](project-status.md) | [아키텍처](architecture.md)

HWP Easy는 에이전트에게 요청해 HWP를 읽고 편집하는 로컬 도구입니다. 현재 버전은 0.5.2이며 Codex, Claude Code와 Cursor에 공통 엔진을 제공합니다. 개발 과정의 제안과 결정 이력은 [이전 기록](archive/README.md)에 분리합니다.

## 요구사항

| 항목 | 기준 |
| --- | --- |
| 문서 처리 | 한글 설치를 필수로 요구하지 않고 Node/WASM으로 HWP를 읽고 편집 |
| 파일 접근 | 사용자가 에이전트와 실행 환경에 허용한 경로를 사용. 제품 정책으로 한 작업 폴더에 영구 제한하지 않음 |
| 호출 | 사용자가 스킬을 선택하거나 명시적으로 호출한 작업에만 적용 |
| 저장 | 검증한 편집을 같은 파일에 저장. 별도 사본 저장은 요청한 경우에만 수행 |
| 복구 | 이전 바이트를 보관하고 복구 직전의 편집본도 유지 |
| 보존 | 비대상 내용과 서식 및 문서 구조를 검사. 충돌이나 불확실한 편집은 저장 전에 거부 |
| 지원 범위 | 문서 구조별 허용 조건과 미지원 처리를 공개. 미리보기와 인쇄 배치의 차이를 구분 |
| 배포 | 공통 엔진 하나로 세 앱 지원. 앱별 차이는 설치 형식과 호출 설정 |

현재 설치에는 Node.js 22 이상과 해당 앱 및 파일 접근 권한이 필요합니다. HWP Easy 서버와 별도 HWP Easy 계정은 필요하지 않습니다. 에이전트의 계정과 이용 조건은 각 서비스를 따릅니다.

## 우선순위와 범위

한국어와 영문 양식의 내용, 표와 개체 편집, 같은 파일 저장과 복구를 우선합니다. 구현한 구조와 제한은 [지원 기능](supported-features.md)을 기준으로 판단합니다. 모든 HWP의 자유 편집이나 외부 프로그램의 전체 글꼴 및 인쇄 조판과 동일함을 약속하지 않습니다.

HWPX, PDF, DOCX 변환과 내보내기는 현재 제품 범위에서 제외합니다. 이전 Windows COM의 기능은 보관한 프로토타입이며 새 엔진의 자동 대체 경로가 아닙니다. 원격 0.1.9의 코드와 배포 ZIP도 유지합니다.

다른 PC 검사는 사용자 요청으로 생략하며 Cursor IDE 채팅은 필수 검사에 포함하지 않습니다. Cloud 전체 흐름은 후순위, 추가 문자 조형은 최후순위입니다. [남은 작업](remaining-work.md)

## 검증과 변경 원칙

실제 문서의 내용을 그대로 테스트에 포함하지 않고 재현 가능한 합성 입력을 사용합니다. 소스 검사, 설치 실행기 검사, 실제 모델 호출과 외부 문서 프로그램의 배치 대조는 별개의 근거로 기록합니다.

작업 중에는 관련 로컬 검사를 수행하고 CI는 사용자 허용 때 실행합니다. 게시한 패키지 내용을 덮어쓰지 않으며 개선 항목별로 코드와 검사 및 문서를 묶습니다. [개발 가이드](developer-guide.md)와 [최신 검증](verification.md)을 따릅니다.
