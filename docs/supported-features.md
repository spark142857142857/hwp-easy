# 지원 기능과 제한

[문서](README.md) | [사용 가이드](quick-start.md) | [지원 조건 상세](reference/support.md)

0.5.2의 세 앱은 같은 실행기와 HWP 엔진을 사용합니다. 지원 여부는 문서 구조와 위치에 따라 달라지며, 확인하지 못한 편집은 읽기 전용으로 처리하거나 저장 전에 거부합니다.

| 대상 | 지원 작업 |
| --- | --- |
| 내용 조회 | 본문과 표 셀 읽기, 검색, SVG 미리보기 |
| 글과 문단 | 텍스트 교체와 범위 편집, 문단 추가와 삭제 및 분리와 병합 |
| 글자 서식 | 글꼴, 크기, 색, 굵기, 기울임, 밑줄과 취소선 |
| 표 | 지원 격자의 행과 열 변경, 셀 병합과 분리, 크기와 여백 및 정렬 |
| 중첩 표 | 내용과 서식 편집, 지원 격자 구조 변경, 높이와 쪽 흐름 조정 |
| 그림 | 지원 위치의 PNG/JPEG 삽입과 교체, 이동과 크기 및 자르기와 회전 |
| 글상자와 그룹 | 지원 내부 글과 문단 및 서식, 하위 그룹 이동과 회전 및 크기 변경 |
| 필드 | 지원 누름틀과 필드의 표시값 및 속성, 지원 위치의 생성과 래퍼 삭제 |
| 저장과 복구 | 충돌 및 보존 검사 후 같은 파일 저장, 이력 조회와 이전 바이트 복구 |

## 표와 개체 배치

검증 가능한 표 구조에서 내용에 맞춘 높이 확장과 명시적 축소, 중첩과 병합 셀 및 형제 표의 동기화, 꼬리말 보호와 쪽 이어짐을 지원합니다. 부동 개체는 지원 위치에서 원래 부동 상태를 유지해 재배치합니다.

임의의 모든 표와 개체 조합을 자동으로 최적화하지 않습니다. 회전과 그룹, 복잡한 글상자, 필드와 개체가 섞인 위치는 각각의 지원 조건을 검사합니다. [표 흐름 조건](reference/support.md#표-흐름)

## 미리보기

지원 원점과 정렬, 원본 글꼴 지표와 혼합 크기, 중첩 표의 쪽 이어짐, 자동 다단과 꼬리말 표시를 보완합니다. 회전 그룹의 지원 가로 글도 표시합니다. 표시 보정은 일회용 입력에 적용하며 원본 HWP의 글이나 서식 및 변환을 덮어쓰지 않습니다.

미리보기의 대체 글꼴과 자형, 줄바꿈과 인쇄 배치가 외부 프로그램과 항상 같지는 않습니다. `layout_verified:false`와 미확인 진단을 유지합니다. [미리보기 조건](reference/support.md#미리보기)

## 필드와 그룹

값과 속성 변경은 문서의 표시값 편집입니다. 명령 실행, 링크 조회, 수식 평가와 자동 정보 갱신은 수행하지 않습니다. 메모와 개인정보 및 목차, 미확인 필드와 중첩 필드 등은 제한합니다.

0.5.2는 필드와 그룹 기대값을 비교할 때 JSON 객체 항목 순서의 영향을 제거했습니다. 배열 순서, 정확한 값과 필요한 키의 검사는 유지합니다. [개체 조건](reference/support.md#개체와-필드)

HWPX, PDF, DOCX 변환은 제품 범위에서 제외합니다. 실제 검증과 알려진 경계는 [검증 기록](verification.md), 이전 구현 단계는 [이전 기록](archive/README.md)을 따릅니다.
