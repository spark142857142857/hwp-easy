# 지원 기능과 제한

[프로젝트 개요](../README.md) · [문서 인덱스](README.md) · [사용 가이드](quick-start.md)

공개 0.2.19의 기본 범위, Codex 설치 0.2.25, 소스·검증 패키지 0.2.32의 추가 범위를 구분합니다. 같은 버전의 앱별 패키지는 공통 로컬 실행기와 지원 조건을 사용합니다. [최신 0.2.32 추가 범위](#소스-0232-추가-기능)에서 현재 재배치 지원 조건을 확인할 수 있습니다.

## 지원 기능

| 대상 | 지원 작업 | 조건 |
| --- | --- | --- |
| 내용 조회 | 본문과 표 셀 읽기, 문구 검색 | 복잡한 개체는 전체 내용을 확인하지 못할 수 있습니다. |
| 본문과 답변 | 문구·부분 수정, 여러 줄 답변 | 선택 위치의 구조와 기존 내용을 증명할 수 있어야 합니다. |
| 문단 | 추가·삭제·분리·병합·복제·이동 | 제어가 포함된 문단 등은 작업별 제한이 있습니다. |
| 표 | 생성·이동, 지원하는 병합 표의 행·열 변경, 셀 병합·분리 | 임의의 모든 표 구조를 바꿀 수 있는 것은 아닙니다. |
| 글자와 배치 | 글꼴·크기·색·굵기·기울임·밑줄·취소선, 지원하는 표·문단 정렬과 간격 | 문서·위치별 서식 조건을 검사합니다. |
| 일반 그림 | 본문·셀의 PNG/JPEG 삽입·교체, 크기·위치·자르기·회전 | 주변 표와 개체 구조가 검증되는 위치에서 작업합니다. |
| 누름틀 | 기존 값 수정·비우기, 지원하는 글자 서식 | 새 누름틀 생성·삭제는 지원하지 않습니다. |
| 중첩 표 | 안쪽 셀 텍스트·글자 서식·검증된 문단의 정렬과 간격 수정 | 안쪽 표의 행·열 등 구조 변경은 지원하지 않습니다. |
| 그림 그룹 | 그룹 전체 이동, 선택한 자식 그림 자르기 | 그룹 그림 교체·회전은 지원하지 않습니다. |
| 저장과 복구 | 같은 파일 저장, 요청한 별도 사본 저장, 이력 조회와 이전 버전 복구 | 검증한 변경만 저장하고 현재 파일과의 충돌을 확인합니다. |

편집 요청은 자연어로 전달합니다. 에이전트가 대상 ID와 내부 요청을 구성하고 저장 전 조건을 검사합니다. 요청 예시는 [사용 가이드](quick-start.md#편집-요청)에 있습니다.

## Codex 0.2.20 추가 기능

다음 기능은 공통 소스·분리 패키지와 Codex 0.2.20 설치본에서 검증했습니다. 공개 ZIP과 Claude Code·Cursor 설치는 0.2.19이며 해당 앱의 갱신·최신 모델 호출은 보류합니다. [검증 기록](local-release-0.2.20.md)

| 대상 | 추가 작업 | 조건 |
| --- | --- | --- |
| 복잡한 본문·중첩 셀 | PNG/JPEG 삽입·교체·삭제·크기·위치·자르기·회전 | 구조가 검증된 일반 그림. 새 그림은 선택 문단의 인라인 개체로 저장합니다. |
| 중첩 표·그림이 있는 표 | 직사각형 표의 행·열 추가·삭제 | 50행·50열·256셀 이하. 병합·영역 속성은 거부하며 개체가 있는 삭제 셀도 거부합니다. |
| 누름틀 | ClickHere 생성·값 변경·삭제 | 생성 위치는 다른 필드 밖이어야 합니다. 삭제는 입력 글자와 서식을 남깁니다. 수식·다른 필드 유형은 제외합니다. |
| 그룹 그림 | 선택한 자식 PNG/JPEG 교체, 부모 그룹 범위 안의 회전 | 교체는 틀·변환을 유지하고 crop을 초기화합니다. 회전은 한 겹 그룹의 한 변환 쌍을 가진 비축척 개체가 부모 틀 안에 남아야 합니다. 중첩 그룹 회전은 거부합니다. |

표의 열 변경은 전체 폭과 남은 열의 비율을 유지합니다. 셀보다 넓어지는 그림·안쪽 표는 거부합니다. 행 변경은 저장된 최소 높이의 비율로 표 틀을 조정하며 실제 표시 높이는 내용에 따라 달라집니다.

고정 바닥글이 있는 짧은 입력란을 장문으로 바꾸면 겹침이 생길 수 있습니다. 저장·복구 검사가 문서의 고정 개체를 자동으로 재배치하는 기능은 아닙니다. 같은 공개 양식에서 이 한계를 재현했고 검증 기록에 남겼습니다.

[0.2.21 검증 기록](local-release-0.2.21.md)을 따릅니다. 이 기능은 0.2.22에도 포함됩니다. Codex 설치본은 0.2.25, Claude Code·Cursor 설치와 공개 ZIP은 0.2.19입니다.

| 병합 중첩 표 | 행·열 추가·삭제 | 겹침 없는 전체 격자와 일관된 너비·저장 높이를 증명해야 합니다. 경계에 걸친 병합 셀의 내용은 남깁니다. |

| 개체가 든 삭제 셀 | 그림·누름틀·안쪽 표와 함께 요청한 행·열 삭제 | 에이전트가 모든 영향받는 셀의 내용과 원시 서브트리 해시를 확인합니다. 이전 그림 바이트와 복구 사본은 남습니다. |
| 표·셀 배치 | 열 너비·저장 행 높이, 셀 여백·세로 정렬, 표 여백·간격 | 병합 범위를 합산하며 좁아진 셀에 남는 개체가 들어가는지 검사합니다. 같은 요청은 재저장하지 않습니다. |
| 예전 형식 셀 | 46바이트·이름 확장 셀 헤더와 텍스트 기록 없는 빈 문단 | 증명한 폭 참조만 바꾸며 새 셀에 기존 셀 이름을 복제하지 않습니다. |

전체가 병합돼 내부 크기가 기록되지 않은 표는 기존 전체 크기와 일치하는 열·행 크기를 지정해 분리할 수 있습니다. 모순된 크기, 영역 속성, 미지원 개체 변환이나 고정 바닥글의 자동 재배치는 지원하지 않습니다.

## 지원 제한과 읽기 전용 처리

문서 구조를 안전하게 확인하지 못하면 일부 본문을 **읽기 전용**으로 보여주거나 작업을 거부합니다. 읽기 전용 결과에는 머리말·글상자 등 일부 개체 내용이 빠질 수 있으므로 문서 전체를 읽었다고 표시하지 않습니다.

머리말·미지원 글상자 등 일부 개체를 보존하면서 검증된 본문·셀만 편집할 수 있습니다. 모델과 원시 텍스트가 일치하지 않는 개별 블록에는 편집 ID를 제공하지 않습니다. 일부 읽기가 가능하다는 것과 편집·저장이 가능하다는 것은 다릅니다. 실제 요청은 저장 전 검사로 판정하며, 지원하지 않는 작업을 우회해 일부만 저장하지 않습니다.

HWPX·PDF·DOCX 변환과 내보내기는 제품 범위에 포함하지 않습니다.

## 미리보기와 최종 배치

기본 SVG 미리보기와 저장 후 재읽기로 **현재 파일 내용**을 확인합니다. 글꼴이나 줄바꿈, 쪽 배치가 외부 HWP 뷰어와 정확히 같다는 인증은 아닙니다.

0.2.19는 저장 후 내장 UTF-16 미리보기 텍스트와 첫 쪽 BMP 썸네일을 갱신합니다. 썸네일 생성이 실패하면 오래된 이미지를 비우고 실패 상태를 보고합니다. 변경 없는 요청은 재저장하지 않고, 복구는 이전 캐시를 포함한 원본 바이트를 그대로 되살립니다.

미리보기 전용 폰트를 사용하므로 문서 글꼴과 다르게 표시될 수 있습니다. 공개 누름틀 3쪽·중첩 표 8쪽의 한컴 수정 전후 비교를 확인했지만 임의 문서의 최종 배치를 보장하지 않습니다. 구체적인 검사와 실패 처리 범위는 [0.2.19 검증 기록](local-release-0.2.19.md)을 참조하세요.

- 셀: 깊이 1–3 사각형, 유일하게 복원되는 후속 행/병합 경계, 여러 평문 문단, 대상 셀의 위/가운데/아래 정렬. 조상 셀은 위 정렬이며 중첩 인라인 표는 첫 문단의 한 줄 접두부를 유지합니다.
- 이동: 목적 문단과 기존 글을 지정해 본문↔셀·셀↔셀·다른 구역으로 전체 앵커/하위 구조를 옮깁니다. 앵커 기준 설정·부동 상태·내용/서식·셀/표 치수는 보존합니다. 셀 목적지는 지원 사각형에 한정합니다.

- 겹침: 기본값은 회피입니다. `overlap_policy:"preserve_existing"`를 명시하면 경계 안의 기존 배치를 무저장으로 보존하며 새 목적지와 함께 사용할 수 없습니다. 의도를 자동 판정하거나 새 겹침을 허용하는 기능은 아닙니다.

**남은 F1:** 가운데/아래 정렬된 조상 셀, 같은 셀 안의 복수 중첩 표/줄이 나뉜 접두부, 셀의 그림/그룹 재배치와 모호한 경로는 아직 거부합니다. 본문이 늘어나 앞선 행의 경계가 달라지는 경우도 확실한 원점을 증명해야 합니다. WASM과 한글의 원점/폰트/쪽 계산 차이인 F3는 그대로 남습니다. 이 한계를 모든 문서에서 자유 편집 가능한 것으로 표현하지 않습니다.

## 소스 0.2.34 추가 기능

`reflow_table`은 확인한 루트 표 전체와 중첩 표의 행 최소 높이를 안쪽부터 늘리고, 가로 위 정렬의 표를 본문과 함께 흐르며 줄 단위로 다음 쪽에 이어 쓰도록 조정합니다. 일반 셀·깊이 2·3·가로 병합·후속 행과 일반 텍스트 꼬리말의 대표 배치를 검증했습니다. 전체 표의 기대 치수·흐름 설정을 대조하고, 열 너비·여백·테두리·반복 제목 설정·내용·서식과 비대상 스트림을 보존합니다.

현재 프로필은 단일 단, 호스트 문단 끝의 단일 표, 가로 위 정렬, 문단별 단일 크기·보통 글자 지표, 100–300% 줄 간격입니다. 세로 병합·정렬 셀·복수 표/뒤쪽 글·아주 좁은 셀·경쟁하는 셀 개체·문단 부동 그림은 저장 전에 거부합니다. 일반 꼬리말 보존과 복잡한 꼬리말 충돌 회피는 구분합니다.

내용 편집 후 묶음의 마지막에 명시적으로 적용해야 합니다. 이후 별도 편집이 자동으로 바깥 행 높이를 다시 맞추지는 않습니다. 높이는 보수적인 최소 공간이며 최종 줄/쪽 계산은 reader가 수행하고 `layout_verified:false`를 유지합니다. 실제 앱 설치는 갱신하지 않았습니다. [검증 범위](local-release-0.2.34.md) · [남은 F2](remaining-work.md#f2-세부-현황)
