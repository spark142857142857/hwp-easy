# 지원 기능과 제한

[프로젝트 소개](../README.md) · [문서 안내](README.md) · [처음 사용하기](quick-start.md)

HWP Easy 0.2.18에서 요청할 수 있는 편집을 정리했습니다. Codex·Claude Code·Cursor는 같은 로컬 실행기를 쓰므로 기본 지원 범위도 같습니다.

## 이런 작업을 요청할 수 있습니다

| 대상 | 지원하는 작업 | 알아둘 조건 |
| --- | --- | --- |
| 내용 조회 | 본문과 표 셀 읽기, 문구 검색 | 복잡한 개체는 전체 내용을 확인하지 못할 수 있습니다. |
| 본문과 답변 | 문구·부분 수정, 여러 줄 답변 | 선택 위치의 구조와 기존 내용을 증명할 수 있어야 합니다. |
| 문단 | 추가·삭제·분리·병합·복제·이동 | 제어가 포함된 문단 등은 작업별 제한이 있습니다. |
| 표 | 생성·이동, 지원하는 병합 표의 행·열 변경, 셀 병합·분리 | 임의의 모든 표 구조를 바꿀 수 있는 것은 아닙니다. |
| 글자와 배치 | 글꼴·크기·색·굵기·기울임·밑줄·취소선, 지원하는 표·문단 정렬과 간격 | 문서·위치별 서식 조건을 검사합니다. |
| 일반 그림 | 본문·셀의 PNG/JPEG 삽입·교체, 크기·위치·자르기·회전 | 주변 표와 개체 구조가 검증되는 위치에서 작업합니다. |
| 누름틀 | 기존 값 수정·비우기, 지원하는 글자 서식 | 새 누름틀 생성·삭제는 지원하지 않습니다. |
| 중첩 표 | 안쪽 셀 텍스트와 글자 서식 수정 | 안쪽 표의 행·열 등 구조 변경은 지원하지 않습니다. |
| 그림 그룹 | 그룹 전체 이동, 선택한 자식 그림 자르기 | 그룹 그림 교체·회전은 지원하지 않습니다. |
| 저장과 복구 | 같은 파일 저장, 요청한 별도 사본 저장, 이력 조회와 이전 버전 복구 | 검증한 변경만 저장하고 현재 파일과의 충돌을 확인합니다. |

예를 들어 “지원 동기 칸을 두 문단으로 채우고 첫 문장만 굵게 해줘”라고 요청할 수 있습니다. 사용자가 내부 요청 JSON이나 편집 대상 ID를 작성할 필요는 없습니다.

## 편집할 수 없는 문서는?

문서 구조를 안전하게 확인하지 못하면 일부 본문을 **읽기 전용**으로 보여주거나 작업을 거부합니다. 읽기 전용 결과에는 머리말·글상자 등 일부 개체 내용이 빠질 수 있으므로 문서 전체를 읽었다고 표시하지 않습니다.

일부 읽기가 가능하다는 것과 편집·저장이 가능하다는 것은 다릅니다. 실제 요청은 저장 전 검사로 판정하며, 지원하지 않는 작업을 우회해 일부만 저장하지 않습니다.

HWPX·PDF·DOCX 변환과 내보내기는 제품 범위에 포함하지 않습니다.

## 미리보기와 최종 배치

기본 SVG 미리보기와 저장 후 재읽기로 **현재 파일 내용**을 확인합니다. 글꼴이나 줄바꿈, 쪽 배치가 외부 HWP 뷰어와 정확히 같다는 인증은 아닙니다.

파일에 내장된 미리보기 텍스트·썸네일은 갱신하지 않습니다. 파일 목록 등의 오래된 썸네일만으로 저장 결과를 판단하지 말고 실제 본문 재읽기나 현재 내용의 미리보기를 확인하세요. 최종 제출 문서는 필요에 따라 외부 HWP 뷰어에서도 배치를 확인할 수 있습니다.
