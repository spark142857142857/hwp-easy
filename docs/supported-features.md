# 지원 기능과 제한

[프로젝트 개요](../README.md) · [문서 인덱스](README.md) · [사용 가이드](quick-start.md)

HWP Easy 0.2.19의 대상별 편집 지원 범위입니다. Codex·Claude Code·Cursor 배포본은 같은 로컬 실행기와 지원 조건을 사용합니다.

<a id="이런-작업을-요청할-수-있습니다"></a>

## 지원 기능

| 대상 | 지원 작업 | 조건 |
| --- | --- | --- |
| 내용 조회 | 본문과 표 셀 읽기, 문구 검색 | 복잡한 개체는 전체 내용을 확인하지 못할 수 있습니다. |
| 본문과 답변 | 문구·부분 수정, 여러 줄 답변 | 선택 위치의 구조와 기존 내용을 증명할 수 있어야 합니다. |
| 문단 | 추가·삭제·분리·병합·복제·이동 | 제어가 포함된 문단 등은 작업별 제한이 있습니다. |
| 표 | 생성·이동, 지원하는 병합 표의 행·열 변경, 셀 병합·분리 | 임의의 모든 표 구조를 바꿀 수 있는 것은 아닙니다. |
| 글자와 배치 | 글꼴·크기·색·굵기·기울임·밑줄·취소선, 지원하는 표·문단 정렬과 간격 | 문서·위치별 서식 조건을 검사합니다. |
| 일반 그림 | 본문·셀의 PNG/JPEG 삽입·교체, 크기·위치·자르기·회전 | 주변 표와 개체 구조가 검증되는 위치에서 작업합니다. |
| 누름틀 | 기존 값 수정·비우기, 지원하는 글자 서식 | 새 누름틀 생성·삭제는 지원하지 않습니다. |
| 중첩 표 | 안쪽 셀 텍스트·글자 서식·검증된 문단의 정렬과 간격 수정 | 안쪽 표의 행·열 등 구조 변경은 지원하지 않습니다. |
| 그림 그룹 | 그룹 전체 이동, 선택한 자식 그림 자르기 | 그룹 그림 교체·회전은 지원하지 않습니다. |
| 저장과 복구 | 같은 파일 저장, 요청한 별도 사본 저장, 이력 조회와 이전 버전 복구 | 검증한 변경만 저장하고 현재 파일과의 충돌을 확인합니다. |

편집 요청은 자연어로 전달합니다. 에이전트가 대상 ID와 내부 요청을 구성하고 저장 전 조건을 검사합니다. 요청 예시는 [사용 가이드](quick-start.md#편집-요청)에 있습니다.

## 지원 제한과 읽기 전용 처리

문서 구조를 안전하게 확인하지 못하면 일부 본문을 **읽기 전용**으로 보여주거나 작업을 거부합니다. 읽기 전용 결과에는 머리말·글상자 등 일부 개체 내용이 빠질 수 있으므로 문서 전체를 읽었다고 표시하지 않습니다.

머리말·글상자 등 일부 개체를 보존하면서 검증된 본문·셀만 편집할 수 있습니다. 모델과 원시 텍스트가 일치하지 않는 개별 블록에는 편집 ID를 제공하지 않습니다. 일부 읽기가 가능하다는 것과 편집·저장이 가능하다는 것은 다릅니다. 실제 요청은 저장 전 검사로 판정하며, 지원하지 않는 작업을 우회해 일부만 저장하지 않습니다.

HWPX·PDF·DOCX 변환과 내보내기는 제품 범위에 포함하지 않습니다.

## 미리보기와 최종 배치

기본 SVG 미리보기와 저장 후 재읽기로 **현재 파일 내용**을 확인합니다. 글꼴이나 줄바꿈, 쪽 배치가 외부 HWP 뷰어와 정확히 같다는 인증은 아닙니다.

0.2.19는 저장 후 내장 UTF-16 미리보기 텍스트와 첫 쪽 BMP 썸네일을 갱신합니다. 썸네일 생성이 실패하면 오래된 이미지를 비우고 실패 상태를 보고합니다. 변경 없는 요청은 재저장하지 않고, 복구는 이전 캐시를 포함한 원본 바이트를 그대로 되살립니다.

미리보기 전용 폰트를 사용하므로 문서 글꼴과 다르게 표시될 수 있습니다. 공개 누름틀 3쪽·중첩 표 8쪽의 한컴 수정 전후 비교를 확인했지만 임의 문서의 최종 배치를 보장하지 않습니다. 구체적인 검사와 실패 처리 범위는 [0.2.19 검증 기록](local-release-0.2.19.md)을 참조하세요.
