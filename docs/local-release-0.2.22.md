# 로컬 0.2.22 그룹·문단 경계·넘침 처리 검증

[프로젝트 상태](project-status.md) · [지원 기능](supported-features.md) · [0.2.21 표 편집 검증](local-release-0.2.21.md)

2026년 10월 13일의 공통 Node/WASM 소스·분리 패키지 검증입니다. Codex 실제 설치는 **0.2.20**, Claude Code·Cursor 설치와 공개 ZIP은 **0.2.19**를 유지합니다. 0.2.22 설치·실제 모델 호출·공개 배포는 별도입니다.

## 변경 범위

| 대상 | 추가 동작 | 보존 및 제한 |

## 한글 호환성 확인과 배치 한계

합성 사례의 수정 전·후·복구본을 기존 한컴 자동화 API로 열어 TEXT와 쪽 이미지를 확인했습니다. 쪽 수는 `MoveDocEnd`로 계산을 끝낸 뒤 관측합니다. 외부 프로그램은 호환성 검사에만 사용하며 computer-use는 사용하지 않았습니다.

한컴 TEXT API가 비 BMP 문자를 UTF-16 숫자 엔티티로 반환하는 경우에는 이를 코드 포인트로 복원한 뒤 대조했습니다. 그룹 전체·내부 회전은 방향을 바꾼 기대 이미지와 비교해 메타데이터만 바뀐 결과를 통과시키지 않았습니다. 큰 부동 그룹의 본문 겹침은 별도 한계로 기록합니다.

그룹의 바깥 회전 메타데이터만 변경한 초기 후보는 한글에서 시각적 회전이 적용되지 않아 제외했습니다. 최종 구현은 자식의 합성 행렬까지 함께 변경하며 실제 이미지 방향·크기·다른 그림 보존을 확인합니다. 합성 그룹 fixture 또한 안쪽 자식의 기존 좌표를 바깥 그룹 좌표계에 맞춰 작성하여 겹친 그림이 회전 결과를 가리지 않게 합니다.

저장 행 높이는 실제 줄바꿈 높이와 같지 않으므로 진단에서 확실한 세로 넘침으로 취급하지 않습니다. 쪽 나눔, 긴 문단의 전체 높이, 고정 바닥글, 부동 개체 겹침과 폰트 대체는 검사 범위 밖입니다. 특히 큰 부동 그룹의 크기 변경이 주변 본문을 자동으로 밀어내는 기능은 아닙니다. `layout_verified:false`를 유지하고 `no_checked_geometry_overflow`를 인쇄 배치 보증으로 표현하지 않습니다.

초기 CI `540f63b`는 9개 작업이 통과했고 Linux 대용량 작업의 모든 검사 단계도 통과했지만 12분 제한에 걸려 작업 전체가 취소됐습니다. 폭 진단과 셀 해시 조회에서 불필요한 전체 쪽 계산·글자 렌더링 조회를 제거하고, 폰트 추정은 검증한 원시 서식 정의를 사용하도록 수정했습니다. 실제 편집과 복잡한 문서의 공개 조회는 기존 모델·원시 서식 대조를 유지합니다. 쪽·글자 조회가 없는 진단 경로도 전용 검사로 확인하며, CI의 대용량 작업에는 마지막 정리까지 가능한 18분 한도를 적용합니다. 개별 실행기 60초·미리보기 5초 제한과 검사 항목은 유지합니다.
