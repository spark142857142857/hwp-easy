이 방침은 사용자가 지정한 파일을 에이전트의 실행 환경에서 처리하는 HWP Easy 로컬 실행판에 적용됩니다. 예전 원격 0.1.9의 처리 방식은 [보관한 정책](archive/remote-0.1.9/privacy-policy.md)에 남겨 두었습니다.

## 처리하는 정보

HWP Easy는 사용자가 선택한 HWP 파일의 내용과 구조, 파일 경로와 현재 내용의 해시, 편집 요청을 읽고 저장에 필요한 검사를 수행합니다. 문서를 읽은 결과와 편집 결과는 사용 중인 에이전트에 반환됩니다. 요청 JSON이나 실행 결과를 에이전트가 파일이나 대화 기록으로 보관할 수 있습니다.

같은 파일에 저장할 때 이전 파일의 전체 바이트와 복구용 메타데이터를 보관합니다. 메타데이터에는 원본 경로, 해시와 생성 시각이 포함됩니다. 파일 충돌을 확인하고 요청한 이전 내용으로 복구하는 데 사용합니다.

HWP Easy 전용 계정이나 운영 서버는 이 로컬 실행판의 사용 조건이 아닙니다. 실행기에는 문서를 개발자의 서버로 전송하거나 사용 통계를 보내는 기능이 없습니다. 개발자가 플러그인 설치만으로 사용자의 파일에 원격 접근할 수 있는 기능도 제공하지 않습니다.

## 처리 위치와 외부 서비스

파일은 에이전트가 실행되는 파일 시스템에서 처리됩니다. 사용자의 PC에서 실행하면 해당 PC에서 처리되며, 다른 실행 환경을 사용하면 그 환경의 파일과 저장소가 사용됩니다. 사용자가 다른 서비스에 직접 첨부한 파일이 개발자에게 전달된다는 뜻은 아닙니다.

에이전트에 반환한 문서 내용이나 파일 경로는 사용 중인 AI 서비스의 대화와 도구 기록에 포함될 수 있습니다. 해당 서비스가 수행하는 전송, 보관과 삭제에는 그 서비스의 정책과 계정 설정이 적용됩니다. HWP Easy의 로컬 처리만으로 대화 기록이나 클라우드 저장소까지 로컬에 남는다고 보장하지 않습니다.

## 보관과 삭제

기본 복구 사본은 선택한 파일과 같은 폴더의 `.hwp-easy-backups`에 저장합니다. 복구 사본에도 원본 문서의 내용이 포함되므로 원본과 같은 수준으로 보호해야 합니다. 자동 만료나 대화 종료에 따른 자동 삭제는 제공하지 않습니다.

사용자는 문서와 복구 사본, 요청 파일과 출력 기록을 해당 실행 환경에서 직접 관리하고 삭제할 수 있습니다. 스킬 제거만으로 문서와 복구 사본이 삭제되지는 않습니다. 호스트 서비스의 대화, 로그와 백업은 그 서비스에서 별도로 관리해야 합니다.

## 문의와 사용자 선택

문의 시 사용자가 자발적으로 제공한 연락처와 오류 설명은 문의 처리에 사용합니다. 문의 이메일은 사용자가 삭제를 요청하거나 운영자가 메일함에서 삭제할 때까지 보관하며 자동 만료는 제공하지 않습니다. 문의 정보의 삭제를 원하면 같은 주소로 요청할 수 있습니다. 공개 GitHub Issues에는 개인 문서, 비밀번호나 인증 정보를 올리지 마세요. 개발자가 보관하지 않는 로컬 파일의 삭제는 해당 파일을 가진 사용자나 실행 환경 관리자가 수행해야 합니다.

사용자는 읽고 편집할 권한이 있는 파일만 지정해야 합니다. 사용 중인 호스트와 AI 서비스의 데이터 처리 조건을 확인하고 필요한 파일 접근 권한만 허용할 수 있습니다.

처리 방식이 바뀌면 이 문서의 대상 버전과 내용을 갱신합니다.
