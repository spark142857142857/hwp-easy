# HWP Easy 개인정보처리방침

게시자: 원석 유 · 시행일: 2026년 10월 10일 · 문의: [spark142857@gmail.com](mailto:spark142857@gmail.com)

이 방침은 HWP Easy의 원격 HWP 읽기·편집·저장 기능에 적용됩니다. ChatGPT·Codex 계정과 대화에 대한 OpenAI의 개인정보 처리에는 해당 서비스의 방침이 별도로 적용됩니다. HWP Easy는 현재 공개 플러그인 출시 준비 단계입니다.

## 처리하는 정보와 목적

- **계정 식별 정보:** 호스팅 플랫폼이 전달한 인증된 사용자 ID와 이메일을 요청의 사용자 확인에 사용합니다. 사용자 ID에서 사이트별 소유자 키를 계산해 문서 접근을 구분합니다. 이메일을 문서 소유자 키에 포함하거나 문서 메타데이터에 저장하지 않습니다.
- **사용자가 전송한 문서:** HWP 전체 파일, 사용자가 지정한 문서 이름, 편집 후 버전과 이전 버전을 읽기·편집·다운로드·복구를 위해 처리하고 저장합니다. 채팅에 첨부한 파일이나 PC의 다른 파일을 자동으로 수집하지 않습니다.
- **작업 기록:** 문서·버전 ID, 파일 크기·해시, 생성·변경 시각, 편집 요청의 재시도 정보와 삭제 처리 기록을 저장합니다. 정확한 대상 확인, 중복 저장 방지, 충돌 검사와 삭제 상태 확인에 사용합니다.
- **문의 정보:** 이메일로 제공한 연락처와 요청 내용을 문의 처리와 결과 안내에 사용합니다. 문의에는 오류 코드와 개인정보 없는 최소 재현만 보내 주세요. 문서 원문·암호·인증 코드는 필요하지 않습니다.

현재 HWP Easy에는 문서 내용을 광고나 사용자 프로파일링에 사용하는 기능이 없습니다.

## 처리 위치와 정보 전달

HWP 파일과 작업 기록은 OpenAI Sites가 제공하는 원격 문서·객체 저장소에서 처리합니다. PC에만 보관되는 서비스가 아닙니다. 사용자가 허용된 파일 링크를 지정하면 해당 파일 호스트에서 HWP를 가져옵니다.

요청한 문서 내용·편집 결과·파일 회수 데이터는 사용자가 이용하는 ChatGPT·Codex 또는 HWP Easy 웹 화면으로 반환됩니다. 에이전트에 문서를 읽게 하면 그 내용이 해당 대화의 일부가 될 수 있습니다. 플랫폼의 계정 정보, 대화, 운영 로그와 자체 백업은 [OpenAI 개인정보처리방침](https://openai.com/policies/privacy-policy/) 등 해당 플랫폼의 정책에 따라 처리됩니다. HWP Easy의 삭제가 플랫폼의 대화나 백업까지 삭제한다는 뜻은 아닙니다.

운영자는 호스팅·저장소 관리 권한을 가집니다. 사용자별 접근 제어를 운영자도 원문에 접근할 수 없는 종단간 암호화로 설명하지 않습니다. 현재 애플리케이션은 문서 원문·토큰·쿠키를 별도 로그로 출력하도록 구성하지 않았으며, 플랫폼 자체의 로그와 보관 기간은 운영자가 모두 통제하지 않습니다.

문서와 이전 버전은 사용자가 명시적으로 삭제할 때까지 보관합니다. 대화 종료, 시간 경과, 앱 연결 해제만으로 문서가 삭제되지 않습니다. 삭제 기능은 해당 문서의 파일과 관련 기록을 정리하고 완료·불확실·실패 상태를 구분합니다. 재시도와 처리 확인에 필요한 삭제 기록은 문서 원문과 구분해 보관할 수 있습니다.

플랫폼 자체 백업의 삭제 기간이나 미참조 객체가 즉시 모두 제거된다고 보장하지 않습니다. 삭제가 불확실하거나 실패한 경우 그 상태를 알리며, 아래 주소로 후속 확인을 요청할 수 있습니다. 문의 이메일의 삭제를 원하면 같은 주소로 요청하세요.
