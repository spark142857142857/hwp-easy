# 프로젝트 상태

[프로젝트 개요](../README.md) · [문서 인덱스](README.md) · [사용 가이드](quick-start.md)

기준일: **2026년 10월 12일**. 현재 메인은 서버 없이 실행하는 **HWP Easy 0.2.18**입니다. 원격 0.1.9는 보관한 이전 경로입니다.

<a id="현재-배포와-실제-설치"></a>

## 배포 및 설치

| 구분 | 확인한 상태 |
| --- | --- |
| 메인 소스·생성 패키지 | 0.2.18. 공통 Node 실행기·의존성·WASM을 포함합니다. |
| Codex용 실제 설치본 | HWP Easy 0.2.17의 설치·활성 상태와 설치 실행기 파일 처리를 확인했습니다. |
| Claude Code·Cursor 개인 스킬 | 0.2.18을 Windows의 각 개인 스킬 폴더에 실제 설치했습니다. |
| 엔진 유지 방식 | 세 앱용 실행기와 WASM의 해시가 같으며 앱마다 엔진을 분기하지 않습니다. |
| 호출 정책 | 스킬 선택, Codex의 명시적 스킬 참조 또는 Claude Code·Cursor의 `/hwp-easy`로 호출합니다. 자동 적용을 금지합니다. |
| 일반 사용자 공개 배포 | 공개 다운로드·디렉터리 게시와 다른 사용자의 설치 흐름은 아직 검증하지 않았습니다. |

<a id="실제로-통과한-검증"></a>

## 검증 결과

| 흐름 | 결과와 근거 |
| --- | --- |
| 설치된 실행기 | 합성 본문·두 문단 셀 편집, 같은 파일 저장, 재읽기, 충돌 거부, 무변경 무저장, 이력과 정확한 복구. [Codex 설치 검증](local-plugin-installation.md) |
| Claude Code 실제 호출 | `/hwp-easy`로 편집·같은 파일 저장·재읽기 후 별도 호출로 원본 복구. [호스트 검증](agent-client-skills.md#검증-범위) |
| Cursor CLI 실제 호출 | 같은 흐름을 설치된 실행기로 수행했습니다. Cursor IDE 채팅 화면과 구분합니다. [호스트 검증](agent-client-skills.md#검증-범위) |
| 독립 판독 | 별도 OLE/레코드 판독으로 수정 내용, 비대상 내용·스트림·서식 보존과 원본 바이트 일치를 확인했습니다. |
| 공개 복잡한 양식 | 12개 조회 성공, 8개는 일부 읽기 전용. 지원 문서 4개의 편집·저장·복구를 확인했습니다. [품질 기록](local-plugin-quality.md) |
| Linux·Windows CI | 0.2.18 코드의 [10개 작업](https://github.com/spark142857142857/hwp-easy/actions/runs/38252416686)이 모두 통과했습니다. |

실제 호스트 시험 버전은 Claude Code 2.1.296과 Cursor CLI 2026.10.01-e373342입니다. 합성 파일과 공개 양식의 검증을 모든 개인 문서·배치의 지원으로 확대하지 않습니다.

## 남은 작업

| 분야 | 후속 작업 |
| --- | --- |
| 앱 사용 흐름 | Cursor IDE 채팅 화면의 호출, Codex 데스크톱 선택 후 실제 전송·실행 |
| 배포 | 일반 사용자가 받을 패키지 배포 경로와 새 설치, 로컬 메인 디렉터리 출시 |
| Cloud | 새 Codex Cloud 작업에 메인 패키지와 파일을 전달하고 편집 결과를 회수하는 전체 흐름 |
| 문서 확인 | 내장 미리보기 텍스트·썸네일 갱신, 필요한 양식의 최종 쪽 배치 확인 |
| 편집 확장 | 중첩 표 구조·문단 서식, 그림이 있는 셀의 표 구조, 누름틀 생성·삭제, 그룹 그림 교체·회전 등 |

위 편집 확장은 현재 지원 완료가 아닙니다. 지금 요청 가능한 기능은 [지원 기능과 제한](supported-features.md)을 따릅니다.

<a id="이전-기록을-읽을-때"></a>

## 이전 구현 및 기록

원격 업로드·OAuth·Sites·D1/R2 검증과 기존 0.1.9 심사는 [이전 MVP 이력](mvp-status.md), [원격 출시 기록](public-plugin-release.md)에 남아 있습니다. 로컬 메인을 사용하기 위해 원격 서버를 준비할 필요는 없습니다.

개별 기록의 “후보”, “미설치”, “심사 중”은 검사를 수행한 시점의 관측입니다. 최신 배포·설치 상태는 이 문서에서 관리하고 상세 검사 근거는 연결된 기록에 보관합니다.
