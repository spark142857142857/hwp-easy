F1 부동 재배치, F2 표 흐름, F3 미리보기, F4 추가 개체와 I3 회전 그룹 글의 확정 범위는 구현했습니다. 임의의 모든 HWP 구조나 외부 프로그램과 같은 인쇄 배치를 보증하지 않습니다. [지원 기능과 제한](supported-features.md)을 따릅니다.

0.5.1의 새 Codex 채팅에서 발견한 B7은 이번 패치에 반영했습니다. 당시 세 합성 문서의 저장과 복구, 실제 한글 9개 파일과 10쪽 및 복구 3쪽 픽셀 대조도 확인했습니다. 0.5.2 설치 실행기 검사와 과거 모델 호출 결과를 구분한 근거는 [검증 기록](verification.md)에 있습니다.

후속 문서 정리는 로컬 링크 검사로 확인하며, 위 CI의 검사 커밋과 구분합니다. 이전 버전과 원격 0.1.9는 [이전 기록](archive/README.md)에 보관합니다.

공개 이후 개발 소스는 역할별 도구 분류와 공통 모듈 분리를 진행했습니다. 로컬 빌드와 검사는 `legacy/` 의존성 없이 실행하며, 새 경로의 검증 결과는 [소스 구조 정리](verification.md#소스-구조-정리)를 따릅니다. 공개 패키지와 현재 PC의 설치본은 기존 0.5.2를 유지하며 이번 소스 정리로 다시 게시하거나 교체하지 않았습니다.
