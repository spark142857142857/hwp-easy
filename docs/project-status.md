| 구분 | 확인한 상태 |
| --- | --- |
| 개발 후보 | 공통 소스·Codex 형식 패키지 0.2.20. 복합 양식 편집과 지원 개체 확장을 검증했습니다. 공개 배포·앱 설치 갱신과 구분합니다. [후보 검증](local-release-0.2.20.md) |
| 공통 배포본 | Codex·Claude Code·Cursor 모두 0.2.19. 같은 실행기·엔진·미리보기 자원을 포함합니다. |
| 실제 설치 | 유지관리자의 Windows에서 세 앱의 0.2.19 설치본을 확인하고 설치된 실행기의 편집·저장·복구를 검증했습니다. |
| 호출 정책 | Codex 스킬 선택 또는 명시적 스킬 참조, Claude Code·Cursor의 `/hwp-easy` 호출. 자동 적용은 금지합니다. |

## 검증 결과

| 흐름 | 결과와 근거 |
| --- | --- |
| Codex 실제 호출 | 0.2.19 설치 스킬을 새 app-server 대화에 정식 선택 참조로 전달했습니다. 모델이 본문·두 문단 셀을 편집하고 같은 파일 저장·재읽기·별도 호출의 정확한 복구를 수행했습니다. 데스크톱 클릭 검사가 아닙니다. |
| Claude Code·Cursor | 0.2.18의 실제 `/hwp-easy` 모델 호출이 통과했습니다. 0.2.19는 실제 설치본의 파일 처리와 독립 판독을 다시 통과했습니다. Cursor 검증 대상은 CLI이며 IDE 채팅 검사는 이번 범위에서 제외했습니다. |
| 공개 복잡한 양식 | 고정된 공개 원본 12개에서 각각 검증 가능한 한 대상을 수정·같은 사본 저장·복구했습니다. 일부 개체와 개별 블록은 여전히 읽기 전용입니다. |
| 미리보기 캐시 | 수정 후 UTF-16 텍스트와 첫 쪽 BMP 썸네일을 갱신합니다. 공개 12개에서 두 자원의 갱신을 독립 판독했습니다. |
| 한컴 배치 확인 | 공개 누름틀 문서 3쪽과 중첩 표 문서 8쪽의 수정 전후 22쪽, 합성 원본 1쪽을 자동화 API로 렌더링했습니다. 쪽 수와 예상한 내용 이동을 확인했습니다. |
| 회귀 및 설치 검사 | 로컬 회귀 353개, 스킬 설치·업데이트 검사 17개 통과. 설치본과 공개 사례는 별도 Python OLE/레코드 판독으로 확인했습니다. |
| 대용량 및 배포 재설치 | 8만 코드 포인트 편집 6개와 정확한 복구를 통과했습니다. GitHub ZIP 세 개를 다시 받아 체크섬 대조 후 새 경로의 실행기·독립 판독을 통과했습니다. |

검사 방식, 한계와 재현 명령은 [0.2.19 검증 기록](local-release-0.2.19.md)에 정리합니다. 배포 코드 `ef12b12`의 [Windows·Linux CI 10개 작업](https://github.com/spark142857142857/hwp-easy/actions/runs/38343187666)이 모두 통과했습니다. 이후 변경의 상태는 [Actions](https://github.com/spark142857142857/hwp-easy/actions)에서 확인합니다.

## 남은 작업

| 분야 | 후속 작업 |
| --- | --- |
| 최신 클라이언트 호출 | 사용자 요청으로 보류. 기능 업데이트가 정리된 뒤 Claude Code·Cursor 패키지 갱신과 실제 AI 호출 재확인. 0.2.18 실제 호출·0.2.19 설치 실행기 검증은 통과 |
| 다른 사용자 설치 | 다른 PC·새 사용자 환경에서 설치·업데이트·Node 실행 조건을 확인. 현재 유지관리자의 새 폴더 설치·업데이트 검증은 통과 |
| 양식 복합 작업 | 0.2.20 후보에서 공개 12개 복합 편집·같은 파일 저장·복구와 독립 판독을 통과. 고정 바닥글·인쇄 배치 등 실제 양식별 최종 검토는 계속 필요 |
| 편집 확장 | 0.2.20 후보에서 제한된 직사각형 중첩 표·그림 셀의 축 변경, ClickHere 생성·삭제, 그룹 자식 교체·범위 안 회전을 추가. 병합 중첩 표·개체가 있는 셀 삭제·중첩 그룹 회전·그룹 크기 변경은 남아 있음 |
| 디렉터리 출시 | 로컬판 개인정보처리방침·약관 준비와 확정 후 URL 연결. 스킬 검사는 통과했으며 접수 제한 해제 후 심사·게시 진행 |
| Cloud | 우선순위를 낮춘 별도 작업. 새 환경에 패키지·파일 전달, 편집과 결과 회수 전체 흐름 |

복잡한 문단의 정렬·간격은 0.2.19에서 지원합니다. 0.2.20의 기능 검증과 앱 업데이트·배포는 별도이며, 임의 문서의 전체 배치를 지원한다고 표시하지 않습니다. 현재 요청 가능한 작업은 [지원 기능과 제한](supported-features.md)을 따릅니다.

<a id="이전-기록을-읽을-때"></a>

## 이전 구현 및 기록

원격 업로드·OAuth·Sites·D1/R2와 기존 심사는 [이전 MVP 이력](mvp-status.md), [원격 출시 기록](public-plugin-release.md)에 보관합니다. 원격 0.1.9 코드와 ZIP은 유지하며 로컬 메인을 사용하기 위해 원격 서버를 준비할 필요는 없습니다.

개별 기록의 “후보”, “미설치”, “심사 중”은 해당 검사 시점의 관측입니다. 최신 상태는 이 문서, 상세 근거는 연결된 검증 기록에서 관리합니다.
