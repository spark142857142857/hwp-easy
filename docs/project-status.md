## 남은 작업

**[남은 작업](remaining-work.md)**에서 완료·미완료·보류를 나누어 관리합니다. B1·B2·I1은 0.2.26, 지원 글상자의 이동·크기 변경은 0.2.27, I2 지원 프로필·B3는 0.2.28에서 완료했습니다. I2의 추가 기준/내부 여백·F1의 조상 정렬·같은 셀의 복수 중첩 표·셀 그림/그룹·F2/F4 기능, 실제 Codex 0.2.31 설치·새 채팅(R1), 다른 사용자 환경(R3), 공개 준비(R4)가 남아 있습니다. 소유자 없는 이전 형식 잠금의 자동 회수, 중첩 표 장문 자동 분할과 추가 배치 프로필은 완료 범위에 포함하지 않습니다.

Claude Code·Cursor 갱신은 사용자 요청으로 보류하며 Cloud는 후순위, Cursor IDE 채팅 검사는 제외합니다. 디렉터리는 마지막 포털 확인이 10월 13일이므로 정책 URL과 접수 가능 여부를 다시 확인해야 합니다. 현재 요청 가능한 편집 범위는 [지원 기능과 제한](supported-features.md)을 따릅니다.

## 이전 구현 및 기록

원격 업로드·OAuth·Sites·D1/R2와 기존 심사는 [이전 MVP 이력](mvp-status.md), [원격 출시 기록](public-plugin-release.md)에 보관합니다. 원격 0.1.9 코드와 ZIP은 유지하며 로컬 메인을 사용하기 위해 원격 서버를 준비할 필요는 없습니다.

개별 기록의 “후보”, “미설치”, “심사 중”은 해당 검사 시점의 관측입니다. 최신 상태는 이 문서, 상세 근거는 연결된 검증 기록에서 관리합니다.
