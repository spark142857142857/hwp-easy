# 프로젝트 상태

[프로젝트 개요](../README.md) · [문서 인덱스](README.md) · [사용 가이드](quick-start.md)

기준일: **2026년 10월 13일**. 현재 메인은 서버 없이 실행하는 **HWP Easy 0.2.19**입니다. 원격 0.1.9는 보관한 이전 구현입니다.

<a id="현재-배포와-실제-설치"></a>

## 배포 및 설치

| 구분 | 확인한 상태 |
| --- | --- |
| 공통 배포본 | Codex·Claude Code·Cursor 모두 0.2.19. 같은 실행기·엔진·미리보기 자원을 포함합니다. |
| 실제 설치 | 유지관리자의 Windows에서 세 앱의 0.2.19 설치본을 확인하고 설치된 실행기의 편집·저장·복구를 검증했습니다. |
| 호출 정책 | Codex 스킬 선택 또는 명시적 스킬 참조, Claude Code·Cursor의 `/hwp-easy` 호출. 자동 적용은 금지합니다. |
| 공개 패키지 | [0.2.19 릴리스](https://github.com/spark142857142857/hwp-easy/releases/tag/hwp-easy-local-v0.2.19)에 앱별 ZIP과 SHA-256을 제공합니다. |
| OpenAI 디렉터리 | 기존 원격 제출은 심사 중·미게시입니다. 로컬판 업로드·검사·심사·게시는 공개 ZIP 배포와 별개입니다. |

<a id="실제로-통과한-검증"></a>

## 검증 결과

| 흐름 | 결과와 근거 |
| --- | --- |
| Codex 실제 호출 | 0.2.19 설치 스킬을 새 app-server 대화에 정식 선택 참조로 전달했습니다. 모델이 본문·두 문단 셀을 편집하고 같은 파일 저장·재읽기·별도 호출의 정확한 복구를 수행했습니다. 데스크톱 클릭 검사가 아닙니다. |
| Claude Code·Cursor | 0.2.18의 실제 `/hwp-easy` 모델 호출이 통과했습니다. 0.2.19는 실제 설치본의 파일 처리와 독립 판독을 다시 통과했습니다. Cursor 검증 대상은 CLI이며 IDE 채팅 검사는 이번 범위에서 제외했습니다. |
| 공개 복잡한 양식 | 고정된 공개 원본 12개에서 각각 검증 가능한 한 대상을 수정·같은 사본 저장·복구했습니다. 일부 개체와 개별 블록은 여전히 읽기 전용입니다. |
| 미리보기 캐시 | 수정 후 UTF-16 텍스트와 첫 쪽 BMP 썸네일을 갱신합니다. 공개 12개에서 두 자원의 갱신을 독립 판독했습니다. |
| 한컴 배치 확인 | 공개 누름틀 문서 3쪽과 중첩 표 문서 8쪽의 수정 전후 22쪽, 합성 원본 1쪽을 자동화 API로 렌더링했습니다. 쪽 수와 예상한 내용 이동을 확인했습니다. |
| 회귀 및 설치 검사 | 로컬 회귀 351개, 스킬 설치·업데이트 검사 17개 통과. 설치본과 공개 사례는 별도 Python OLE/레코드 판독으로 확인했습니다. |

검사 방식, 한계와 재현 명령은 [0.2.19 검증 기록](local-release-0.2.19.md)에 정리합니다. 이전 CI는 [0.2.18의 10개 작업](https://github.com/spark142857142857/hwp-easy/actions/runs/38252416686)이 통과했습니다. 현재 코드의 CI 상태는 [Actions](https://github.com/spark142857142857/hwp-easy/actions)에서 확인합니다.

## 남은 작업

| 분야 | 후속 작업 |
| --- | --- |
| 디렉터리 출시 | 로컬판 포털 자동 검사, 필요한 보완, 심사와 승인 후 게시 |
| 다른 사용자 설치 | 유지관리자의 새 폴더 설치·업데이트 검증을 다른 사용자의 환경으로 확대 |
| 편집 확장 | 중첩 표 행·열 구조 변경, 그림이 있는 셀의 표 구조, 누름틀 생성·삭제, 그룹 그림 교체·회전 |
| 문서별 배치 | 필요한 실제 양식에서 긴 답변·여러 칸 수정 후 최종 글꼴·줄바꿈·쪽 배치 확인 |
| Cloud | 우선순위를 낮춘 별도 작업. 새 환경에 패키지·파일 전달, 편집과 결과 회수 전체 흐름 |

복잡한 문단의 정렬·간격은 0.2.19에서 지원합니다. 위 편집 확장과 임의 문서의 전체 배치 지원은 완료로 표시하지 않습니다. 현재 요청 가능한 작업은 [지원 기능과 제한](supported-features.md)을 따릅니다.

<a id="이전-기록을-읽을-때"></a>

## 이전 구현 및 기록

원격 업로드·OAuth·Sites·D1/R2와 기존 심사는 [이전 MVP 이력](mvp-status.md), [원격 출시 기록](public-plugin-release.md)에 보관합니다. 원격 0.1.9 코드와 ZIP은 유지하며 로컬 메인을 사용하기 위해 원격 서버를 준비할 필요는 없습니다.

개별 기록의 “후보”, “미설치”, “심사 중”은 해당 검사 시점의 관측입니다. 최신 상태는 이 문서, 상세 근거는 연결된 검증 기록에서 관리합니다.
