# 프로젝트 상태

[프로젝트 개요](../README.md) · [문서 인덱스](README.md) · [사용 가이드](quick-start.md) · [개선·남은 작업](remaining-work.md)

갱신일: **2026년 10월 27일**. 소스와 현재 PC의 Codex 설치는 **0.5.0**입니다. HWP Easy 이름과 저장소를 유지하고, 설명과 로컬 정책을 정리해 [제출 전 검토](release-review-0.5.0.md)를 준비했습니다. 포털 업로드와 메타데이터 검사 결과를 확인했으나 스킬 전용 접수 제한이 표시됐습니다. 스킬 검사는 아직 진행 중이며 심사 신청과 공개 게시는 하지 않았습니다. [포털 결과](portal-check-0.5.0.md) Claude Code와 Cursor, 공개 ZIP은 0.2.19를 유지합니다. Actions는 실행하지 않았습니다.

## 남은 작업

**[남은 작업](remaining-work.md)**에서 완료·미완료·보류를 구분합니다. F1은 0.2.33, F2 핵심은 0.2.42, F3 핵심 지원 범위는 0.2.50, F4 추가 개체 편집은 0.2.51에서 마감했습니다. Codex 0.2.51 설치·새 채팅(R1 후속)도 완료했습니다. 다음은 다른 사용자 환경(R3), 공개/심사(R4·R5)이며 회전 하위 그룹의 SVG 글 표시(I3)는 후속 개선으로 남습니다. Claude Code·Cursor는 계속 보류합니다. 모든 HWP의 조판 일치와 미지원 프로필을 완료로 표시하지 않습니다.

아랍어·인도계·태국어·ZWJ 이모지 등의 조형은 최후순위로 두며 현재 F2 완료·설치 갱신의 필수 조건에 넣지 않습니다. 한국어·영문 양식의 구조·배치·저장/복구와 설치·공개를 우선합니다. Claude Code·Cursor 갱신은 사용자 요청으로 보류하며 Cloud는 후순위, Cursor IDE 채팅 검사는 제외합니다. 디렉터리는 마지막 포털 확인이 10월 13일이므로 정책 URL과 접수 가능 여부를 다시 확인해야 합니다. 현재 요청 가능한 편집 범위는 [지원 기능과 제한](supported-features.md)을 따릅니다.
