# 로컬 HWP Easy 0.2.28 셀 글상자 위험 진단

[남은 작업](remaining-work.md) · [지원 기능](supported-features.md) · [프로젝트 상태](project-status.md)

2026년 10월 18일, **I2의 지원 프로필**에 셀·중첩 셀 글상자의 세로 경계·긴 내용·주변 본문 겹침 진단을 추가했다. 소스·분리 검증 패키지는 **0.2.28**이며 실제 Codex 설치는 **0.2.25**, Claude Code·Cursor 설치와 공개 ZIP은 **0.2.19**다. 자동 크기 맞춤·개체 이동·중첩 표 분할·실제 앱 설치 갱신을 수행한 기록이 아니다.

## 진단 범위

| 구분 | 확인하는 위험 | 결과의 의미 |
| --- | --- | --- |
| 표시된 셀과 사각형 | 셀 위/아래 경계, 일반 본문 글자와의 교차 | `engine_render`: 현재 WASM 좌표에서 관측한 위험. 외부 한글의 실제 잘림 보증은 아님 |
| 글상자 내용 | 글자 크기·줄바꿈·문단 간격에 따른 상자/셀 높이와 본문 겹침 | `font_estimate`: 내용의 확장·잘림 가능성. 지원하는 내부 여백 없는 단순 문단에 한정 |
| 일반 셀 흐름 | 부동 상자를 제외한 셀 텍스트·중첩 표의 추정 높이와 이후 본문 위치 | `font_estimate`: 엔진만 셀을 키워 본문을 밀어낸 경우의 위험도 비교. 추정 위치를 네이티브 좌표로 표시하지 않음 |
| 불확실한 구조 | 종이/쪽 기준, 내부 여백, 복잡한 프레임·경로·쪽 계산 | `cell_text_boxes.limitations`와 `inconclusive`. 해당 범위를 깨끗한 배치로 인증하지 않음 |

표시 위치 비교는 **셀 첫 문단의 문단/단 기준·절대 크기·위/왼쪽 정렬·회전/뒤집기 없는 사각형**에서 수행한다. 최상위 표는 원시 대상 ID와 표시 ID를 대조한다. 중첩 표는 현재 엔진이 경로 일부를 생략하므로 원시 계층과 포함된 표시 프레임이 유일하게 일치할 때만 비교한다. 중복 후보는 추정으로 선택하지 않고 진단 불확실로 남긴다.

저장된 셀 높이는 최소값일 수 있으므로 그 값만으로 잘림을 판정하지 않는다. 글상자 자신의 글자·빈 앵커 줄은 주변 본문 검사에서 제외한다. 중첩 표의 네이티브 쪽 계산은 기존처럼 미검증이며 `layout_verified:false`를 유지한다.

`layout`의 geometry/rendered 결과와 편집 결과에 `cell_text_boxes` 검사 범위·한계를 제공한다. 기본 `report`는 위험과 함께 명시한 편집을 저장할 수 있다. **`reject_new_risk`는 새로 생기거나 악화된 위험을 저장·백업 전에 거부**한다. `reject_new_overflow`의 원시 기하 검사와 구분한다. 동일하게 식별한 개체·상대 본문의 위험이 줄어든 경우에는 새 위험으로 세지 않으며, 다른 본문과의 새 겹침은 기존 위험으로 상쇄하지 않는다. 무변경은 무저장이고 복구는 원래 바이트를 사용한다.

## B3 개체 식별 필드 정정

I2의 엄격 정책 검사에서 실제 개체를 미확인으로 처리해 안전한 수정도 거부하는 문제를 재현했다. 공통 개체 헤더의 **24바이트 위치는 z-order, 실제 인스턴스 ID는 36바이트 위치**다. [한컴 HWP 5.0 형식 표 69](https://cdn.hancom.com/link/docs/%ED%95%9C%EA%B8%80%EB%AC%B8%EC%84%9C%ED%8C%8C%EC%9D%BC%ED%98%95%EC%8B%9D_5.0_revision1.3.pdf)와 엔진의 독립 속성 조회를 대조해 식별·새 그림 할당 경로를 수정했다.

새 그림에는 기존 문서의 실제 ID와 겹치지 않는 0이 아닌 값을 할당하고 표시 순서는 별도로 보존한다. 이전 파일의 0/중복 ID를 자동으로 고치지 않으며 계속 보수적으로 처리한다. 기존 B2의 개체 간 위험 교환·번호 변경·삭제 후 재삽입 보호도 회귀 검사했다.
