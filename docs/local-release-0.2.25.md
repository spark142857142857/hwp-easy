# 로컬 HWP Easy 0.2.25 공개 양식 재검증

[프로젝트 상태](project-status.md) · [지원 기능](supported-features.md) · [개선·남은 작업](remaining-work.md) · [0.2.24 기록](local-release-0.2.24.md)

2026년 10월 15일, 설치된 **0.2.24**로 공개 12개 양식을 다시 검사하고 발견한 문제를 **0.2.25 소스·검증 패키지**로 보완했다. Codex 설치는 0.2.24, Claude Code·Cursor 설치와 공개 ZIP은 0.2.19를 유지한다. 설치 갱신·새 채팅·공개 게시·포털 작업은 이번 범위에 포함하지 않았다.

## 공개 12개

출처는 [rhwp 고정 커밋](https://github.com/edwardkim/rhwp/tree/1a76570e833917d15817415a53c09ad61ab3203f)의 공개 표본이다. 0.2.20부터 사용한 카탈로그의 URL·크기·SHA-256을 대조했다. 원본은 읽기만 하고 복사본에서 누름틀 또는 두 칸의 답변·글자/문단 서식·그림을 묶어 편집했다.

**0.2.24 기준 검사:** 12개 모두 같은 파일 저장·정확한 복구·마지막 실패의 원자적 거부·독립 OLE 판독을 통과했다. 한컴 2020 자동화 API로 원본·편집본·복구본 36개 파일·155쪽을 열고 모든 쪽을 이미지로 만들었다. 복구한 50쪽은 원본과 픽셀이 같았다. 요청한 합성 문구도 모두 확인했다.

이 결과만으로 배치 성공을 선언하지 않았다. 지도 그룹이 답변을 덮는 사례와 중첩 표 안의 장문이 쪽 아래로 잘리는 두 사례를 실제 이미지에서 확인했다. 원래부터 배치가 불안정한 표본의 기존 겹침도 남아 있다.

| 표본 | 최종 복합 검사 쪽 수 | 확인 사항 |
| --- | --- | --- |
| 01·02 누름틀 표지 | 각각 3→3 | 두 필드·서식·그림, 원래 장식 보존 |
| 03·04·06 도형 양식 | 각각 1→1 | 텍스트·서식·그림과 도형 보존 |
| 05 벡터 지도 그룹 | 1→1 | 복합 편집 후 겹침을 재현하고 별도 위치 이동으로 해소 |
| 07 중첩 셀 페이지 | 17→19 | 긴 답변의 네이티브 쪽 이동과 전체 복구 |
| 08 좁은 중첩 표 | 1→2 | 짧은 합성 답변의 실제 배치 확인. 장문은 별도 엄격 정책에서 저장 거부 |
| 09 중첩 표·캡션 | 12→12 | 답변·서식·그림과 원래 표/그림 보존 |
| 10 중첩 표 흐름 | 1→1 | 짧은 합성 답변의 실제 배치 확인. 장문은 별도 엄격 정책에서 저장 거부 |
| 11 누름틀 셀 | 1→1 | 두 필드·서식·그림, 셀 식별 유지 |
| 12 혼합 중첩 셀 | 8→9 | 답변과 후속 내용의 쪽 이동, 원래 콘텐츠 보존 |

0.2.25의 최종 12개 복합 검사는 08·10에 **명시적으로 짧은 시험 답변**을 사용했다. 제품이 장문을 자동으로 줄인 결과가 아니다. 같은 장문 요청을 `reject_new_risk`로 실행하면 `NEW_LAYOUT_RISK`로 거부하며 파일과 백업 수가 변하지 않는다. 중첩 표 장문의 자동 쪽 분할은 해결한 것으로 처리하지 않는다.

한컴은 시험 환경에만 설치되어 있으며 제품 실행 조건이 아니다. 위 최종 네이티브 검사의 합계는 **90개 파일·237쪽**, 복구 픽셀 비교는 **76쪽**이다. 같은 파일의 반복 검사를 별도 문서 종류로 세지 않는다. 이 확인은 해당 시험 문서·요청·폰트 환경에 한정된다.

CI 상태는 [프로젝트 상태](project-status.md)에서 검증한 커밋과 실행 링크로 관리한다.

## 패키지와 재현

패키지는 25개 허용 파일, **5,579,564바이트**다. 소스 검증용 ZIP이며 공개 다운로드와 구분한다. 이전 0.2.24 ZIP을 보존한다.

| 자원 | SHA-256 |
| --- | --- |
| 0.2.25 ZIP | `746b3a7c420a9b40e2b0d017a45c204f4bdc6d4d3d021498bcd4ffcef8aeccb3` |
| 실행기 | `3477d0e2141dc9f0fb99760dc81713cd2ffdbf5a98d57dd4802fc494b554cd2f` |
| core 0.8.6 WASM | `8000e4ce320b7994dca6bcd58be0c862144c7b805576504e523a420439da658b` |

```bash
node scripts/package_local_plugin.mjs
python scripts/archive_local_plugin.py
node scripts/check-local-compound.mjs <pinned-corpus> <baseline-output> <installed-0.2.24-runner>
python scripts/check-local-compound.py <baseline-output>
node scripts/check-local-compound.mjs <pinned-corpus> <candidate-output> <candidate-runner> --short-answers=8,10
python scripts/check-local-compound.py <candidate-output>
node scripts/check-local-public-layout.mjs <baseline-output> <fresh-layout-output>
python scripts/check-local-public-layout.py <fresh-layout-output>
node scripts/check-local-placement.mjs <fresh-placement-output>
python scripts/check-local-placement.py <fresh-placement-output>
```

선택적 Windows 네이티브 검사는 `check-local-public-native.py`, `render-local-reflow-native.py`, `check-local-public-layout-native.py`, `check-local-placement-native.py`를 사용한다. 이미지 비교에는 Pillow가 필요하다. 생성 원본·답변·이미지·실행 로그는 무시된 `outputs/public-024-20261015/`에 두고 공개 저장소·플러그인 ZIP에 넣지 않는다.

## 남은 제한

중첩 표 장문의 자동 분할, 다단/셀 부동 개체의 자동 위치 탐색, 필드·그림이 든 복잡한 꼬리말, 그룹 내부 글상자·개별 하위 그룹 편집, 네이티브와 동일한 쪽 계산은 후속 작업이다. 저장·복구 검증과 쪽 배치 인증을 구분한다. 다음 설치·공개 순서는 [남은 작업](remaining-work.md)에서 관리한다.
