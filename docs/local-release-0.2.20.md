# 로컬 0.2.20 후보 검증

[프로젝트 상태](project-status.md) · [지원 기능](supported-features.md) · [이전 0.2.19](local-release-0.2.19.md)

2026년 10월 13일의 공통 엔진 개발 후보입니다. 공개 배포 ZIP과 실제 Codex·Claude Code·Cursor 설치본은 **0.2.19**입니다. 이번 작업은 복합 양식 편집과 필요한 개체 지원 확장에 집중했으며, Claude Code·Cursor 업데이트·모델 호출, 포털 등록과 공개 릴리스 갱신은 진행하지 않았습니다.

검증한 Codex 형식 ZIP은 `outputs/plugin-package/hwp-easy-0.2.20.zip`입니다. SHA-256: `d9d64f2baa2ccdb6c876e71c77e881ef2fdebd6f0980b4cdcdf0077e3c2b005e`. 실행기 SHA-256은 `19d81435749b0e1b181ea8204b7309fa9f91a78e628bc0e50946fb46df785ea5`이며 엔진 WASM은 0.2.19와 같습니다. 후보 ZIP 생성은 앱 설치·공개 배포·심사 제출이 아닙니다.

## 변경 범위

| 대상 | 추가한 동작 | 제한 |
| --- | --- | --- |

표의 열 변경은 전체 폭과 남은 열의 비율을 유지합니다. 행 변경은 저장된 셀 최소 높이의 비율로 표 틀 높이를 조정합니다. 표시 높이는 내용에 따라 늘어날 수 있습니다. 새 너비에 들어가지 않는 그림·안쪽 표와 삭제 셀의 숨은 개체는 저장 전에 거부합니다.

누름틀과 그림의 시작 위치를 바꾸면서 기존 제어 기록의 순서가 어긋나지 않도록 원시 앵커 순서와 제어 헤더를 대조합니다. 새 필드를 만든 뒤 일반 문서가 복잡한 문서 프로필로 바뀌거나, 마지막 필드를 지워 일반 프로필로 돌아가더라도 처음 선택한 블록을 같은 묶음에서 추적합니다. 삭제된 대상에 대한 후속 작업은 전체 묶음을 거부합니다.

## 실제 한컴 배치 확인

파일 선택·편집·저장·복구에는 computer-use를 사용하지 않았습니다. 한컴 자동화 API로 신뢰한 공개·합성 사본을 숨김 상태에서 열어 페이지 이미지를 만들었고 한컴에서 파일을 저장하지 않았습니다. 최종 18개 사본의 페이지 이미지 46개를 생성했습니다.

- 공개 누름틀 문서: 짧은 값·서식·인라인 그림을 함께 변경한 뒤 **3쪽 유지**. 수정한 값과 그림 위치, 고정 바닥글을 확인했습니다.
- 공개 중첩 표 문서: 두 긴 답변과 서식·그림을 함께 변경한 뒤 **8→9쪽**. 요청한 12줄은 한컴 텍스트 판독에도 존재하며 답변의 다음 쪽 이동과 표 경계를 확인했습니다.
- 위 두 문서의 복구본: 원본 바이트와 **11쪽의 렌더링 픽셀**이 각각 정확히 같습니다.
- 합성 사례: 누름틀 생성·삭제, 3단 표의 행 추가, 그림 셀의 행 추가 후 crop, 그룹 그림 교체와 지원 회전을 확인했습니다. 한 겹 그룹의 선택 그림은 실제 화면에서 90도 회전하며 이웃 그림은 유지됩니다.

내부 모델의 각도·행렬만 바꾸면 한컴에서 보이는 회전이 바뀌지 않는 사례를 발견했습니다. [고정 RHWP 파서](https://github.com/edwardkim/rhwp/blob/1a76570e833917d15817415a53c09ad61ab3203f/src/parser/control/shape.rs)의 행렬 합성과 실제 한컴 결과를 구분해 검사했습니다. 검증된 한 겹·한 변환 쌍만 회전을 허용하고 **중첩 그룹 회전은 거부**합니다. 중첩 그룹의 그림 교체·자르기는 별도로 지원합니다.

## 확인한 배치 한계

짧은 회사명·작성자 입력란에 각각 6줄 장문을 넣는 스트레스 시험은 내용·저장·복구를 통과했지만, 고정된 바닥글과 겹침이 생겼습니다. 짧은 값을 사용하는 복합 사례에서는 이 겹침이 없습니다. 고정 개체를 자동으로 이동하거나 페이지 디자인을 재작성하는 기능으로 확대하지 않습니다.

이전 형식의 공개 문서 7은 한컴에서 원본·편집본·복구본 모두 열리고 새 12줄을 읽었지만, 전체 페이지 이미지 생성에 실패했습니다. 원본에서도 발생한 동일 제한이며 문서 7의 전체 배치를 검증 완료로 표시하지 않습니다. 행 추가·열 거부와 내용 보존은 별도 파일 판독 결과입니다.

이모지·대체 글꼴·인쇄 배치와 임의 문서의 모든 쪽은 인증하지 않았습니다. 병합 중첩 표, 개체가 있는 셀 삭제, 그룹 크기 변경·중첩 그룹 회전, 복잡한 문단 경계 변경과 다른 필드 유형은 남은 범위입니다.

## 재현

저장소 개발 환경에서 공통 패키지를 만들고 합성 사례를 검사합니다. 결과 폴더는 새 경로를 지정하며 생성 HWP·이미지는 Git에서 제외합니다.

```sh
node scripts/package_local_plugin.mjs
node scripts/check-local-complex-editing.mjs outputs/local-complex-editing-check
python scripts/check-local-complex-editing.py outputs/local-complex-editing-check
```

고정된 공개 원본 폴더에는 `sources.json`과 해당 SHA-256의 12개 HWP가 있어야 합니다. 원본 준비 과정은 [0.2.19 공개 코퍼스 기록](local-release-0.2.19.md)을 따릅니다.

```sh
node scripts/check-local-compound.mjs <pinned-public-corpus> outputs/local-compound-check
python scripts/check-local-compound.py outputs/local-compound-check
node scripts/check-local-public-table-axes.mjs <pinned-public-corpus> outputs/local-public-axes-check
python scripts/check-local-complex-editing.py outputs/local-public-axes-check
```

CI에는 합성 새 기능·독립 판독을 추가했습니다. 한컴 배치와 고정 공개 코퍼스 검사는 유지관리자의 별도 로컬 실행입니다. 다른 사용자의 설치, 실제 클라이언트 모델 호출, Cloud 전체 흐름과 디렉터리 심사는 이번 결과에 포함하지 않습니다.
