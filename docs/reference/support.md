# 지원 조건 상세

[지원 기능](../supported-features.md) | [검증](../verification.md)

F2부터 F4에서 확정한 구조별 조건입니다. 현재 0.5.2에 적용하며, 과거 구현 버전과 현재 설치 상태는 구분합니다.

## 표 흐름

### 표와 문단

| 항목 | 확정한 범위 |
| --- | --- |
| 선택 단위 | 명시적 `reflow_table`로 전체 루트 트리 또는 같은 본문 호스트의 루트 묶음을 선택. 원본 해시·대상 글·전체 표 기대 설정 대조 |
| 구조 | 검증 가능한 가로 표, 깊이 1–3, 선택 묶음 최대 16개 표. 표당 최대 32행·16열, 셀 간격 0, 본문 폭 안의 너비. 미확인 헤더·격자·앵커는 거부 |
| 쪽/단 | 해당 구역의 검증 가능한 가로 쪽 정의 1개·단 1개. 다단·세로 쪽 등 추가 프로필은 이 범위에 포함하지 않음 |
| 문단/문자 | 가로 셀의 일반 문단·위/가운데/아래 정렬. 검증한 일반 줄 간격/여백 프로필, 한글·영문·혼합 크기·지원 결합 문자. 선택 셀 전체 글 100,000자, 문단별 10,000자 이내의 기존 실행기 제한 유지 |
| 병합/중첩 | 가로·세로 병합, 중첩/조상 높이와 형제 표 위치 동기화. 표 사이·뒤쪽 글, 한 호스트 복수 중첩 표와 복수 본문 루트의 명시적 문단 분할·글/서식/앵커 순서 보존 |
| 필드/인라인 | 검증한 ClickHere 누름틀과 회전 없는 인라인 그림·지원 짧은 단순 글상자. 별도 문단·줄 간격 영향·대상/필드 범위 추적. 기타 필드·그룹 내부 등은 후속 확장 |
| 꼬리말 | 검증한 여러 문단·혼합 서식·쪽 번호·인라인 표·홀짝 적용 프로필의 하단 보호와 위치/내용 보존 |

장문은 안쪽 셀부터 필요한 높이를 계산해 조상에 반영하고 줄 단위 쪽 이어짐을 요청한다. 열 너비·셀 여백·테두리·정렬·글/글자 서식과 비대상 제어/스트림을 보존한다. 글/폰트·셀 문단·지원 필드/개체·선행 본문을 편집하면 완전한 흐름 프로필을 저장 전에 다시 동기화하며, 재열기 후에도 적용한다. 최초 흐름 조정은 명시적 요청이다.

### 부동 배치와 높이 축소

| 항목 | 확정한 동작 |
| --- | --- |
| 독립 부동 개체 | 표 뒤의 별도 빈 본문 앵커에 놓인 회전 없는 그림·지원 짧은 단순 글상자. 부동 상태·가로 위치·크기·crop/이미지·상자 글/서식을 보존하고 문단에 세로 공간 예약 |
| 같은 쪽 활용 | 선행 표/본문 높이와 개체 예약 높이·후속 여유가 확인된 한 쪽에 들어가면 재사용. 공간 부족·불확실한 다중 쪽 잔여 위치·미확인 뒤쪽 구역 원점은 새 쪽 분리 |
| 기존 쪽 나눔 | 기본 보존. 명시적 `floating_page_breaks:"recompute_managed"`만 정확히 일치하는 관리형 빈 앵커를 재계산. 작성 이력을 판별하지 않으므로 같은 프로필의 수동 나눔도 대상이 될 수 있음 |
| 최소 높이 | 기본 `row_height_policy:"preserve"`는 글을 줄여도 저장된 최소 높이 유지 |
| 내용 맞춤 | 높이/빈 공간 축소 요청에만 `row_height_policy:"content_fit"`. 내용·여백·중첩/병합 제약으로 선택 묶음의 최소 총높이를 계산하며 행당 최소 100 HWPUNIT. 원래 의도한 큰 최소 높이도 줄일 수 있음 |
| 후속 편집 | 내용 맞춤은 지속 설정이 아니다. 이후 일반 편집은 축소한 높이에서 필요하면 확장. 부동 앵커 나눔 재계산은 별도 명시 옵션 |

### 공개 표본에서 확인한 경계

고정 공개 표본은 12개이며, 같은 원본에 추가 요청을 실행한 사례를 별도 문서 종류로 세지 않았다.

| 공개 표본 | 확인한 결과 |
| --- | --- |
| 01–06 | 복합 글/필드·서식·그림 편집과 복구 확인. F2 루트 표 컨텍스트는 없음. 05의 기존 지도 겹침은 별도 명시적 위치 이동으로 해소하고 이미지 대조 |
| 07 | 글 편집·저장/복구 가능. 5개 루트는 미지원 헤더이므로 F2 흐름 컨텍스트 읽기 전용 |
| 08·09 | 검증한 글 편집·복구 가능. 해당 표의 `reflow_table`은 `TABLE_REFLOW_PROFILE_UNSUPPORTED`로 거부 |
| 10 | 명시적 흐름 조정을 조합한 실제 중첩 셀의 한글 답변 **65줄·3쪽 표시**, 이후 8줄·내용 맞춤으로 **1쪽 복귀**. 원본과 장문 상태 각각 정확한 복구. 흐름 조정 없이 장문만 넣는 기존 위험 요청은 엄격 정책에서 거부 |
| 11 | 글/필드 편집·복구 가능. 별도 부동 루트를 단독 흐름 조정하는 요청은 `TABLE_REFLOW_OTHER_FLOATING_TABLE_UNSUPPORTED`로 거부 |
| 12 | 글 편집·복구 가능. 해당 쪽 정의의 F2 흐름 조정은 `TABLE_REFLOW_PAGE_PROFILE_UNSUPPORTED`로 거부 |

추가 필드·제어를 감싼 필드·글 혼합/셀 안 부동 앵커·그룹/회전·복잡한 상자 내부·불확실한 다중 쪽의 정밀 공간 재사용은 후속 확장이다. 추가 외국어/이모지 조형은 D3 최후순위다. WASM과 외부 한글의 모든 폰트/줄바꿈 일치를 보증하지 않으며 `layout_verified:false`를 유지한다.

### 검증 근거

표 흐름 조건은 [0.2.42 마감 기록](https://github.com/spark142857142857/hwp-easy/blob/baad6d4513b9918bd718bb5f1f3beb5027d43edb/docs/f2-closure-0.2.42.md)에서 확정했습니다. 현재 실행기와 배포본의 해시 및 회귀 결과는 [최신 검증](../verification.md)을 따릅니다.

| 원점·정렬 | 지원 빈 부동 앵커, 깊이 2/3 중첩 표, 원래 경로를 구분한 형제 표·정규화된 복수 문단/호스트, 상위 셀 위/가운데/아래 정렬 |

문단 여백/들여쓰기·앞뒤 간격 0, 지원 가로 줄 간격 100–300% 등 기존 정규화 조건은 그대로다. 꼬리말 앞 간격은 별도로 지원한다. 32쪽·20,000개 렌더 항목과 기존 저장/미리보기 작업자 제한을 유지한다. 실제 검증한 사례와 허용한 판독 범위의 모든 조합을 전수 검사했다는 뜻은 아니다.

### 원본 보존

편집 대상과 저장 모델은 항상 원본 HWP에서 읽는다. 사본 입력의 공백·문단 분할·NFC·여백·표 흐름·큰 측정용 쪽은 렌더 전용이며, 저장 또는 내보내기 메서드가 없는 뷰로 감싼다. SVG·내장 첫 쪽 BMP·렌더 진단은 같은 뷰를 사용한다.

계속되는 셀은 원래 표/셀/문단/문자 위치로 보고한다. 페이지마다 반복하던 음수 좌표의 앞부분과 인접 쪽의 중복 줄을 제거한다. 빈 안내는 `render_virtual_field_guide`와 원래 필드 ID로 표시하고 편집 가능한 본문 문자 위치를 꾸며내지 않는다. `render_flow_adaptations`는 빈 문단·쪽 분할·자동 다단·꼬리말 보정의 적용 내역을 담는다.

같은 파일 저장은 기존 기대 해시/대상·계획 후보 대조·백업·충돌 검사를 사용한다. 복구는 원본 바이트와 일치해야 한다. 렌더 성공을 원본 저장 검증이나 실제 한글 배치 검증으로 대체하지 않는다.

### 지원 밖의 조건

아래 조건은 알려진 경계이며 완료로 바꾼 기능이 아니다. 확정 프로필을 벗어나면 `render_unadapted_tables`/`render_unadapted_cells`, 진단 제한 또는 안전한 저장 거부로 보고한다.

- 제목 셀 내용의 실제 반복, 복잡한 다중 루트/형제 트리의 행 내부 동시 분할, 명시적 쪽 나눔과 자동 다단의 복합 재조합.
- 임의 문단 여백/들여쓰기·고정/여백형 줄 간격·세로쓰기·비정규화 호스트, 임의 필드/회전·그룹/복잡한 개체의 혼합. F1 조상 한 문단 안의 혼합 크기 배치는 여전히 제한한다.
- 외부/임의 글꼴의 전체 조형·커닝·자소 내부 혼합 서식, 추가 외국어/ZWJ 이모지 조형. 원본의 지표가 없는 글자를 대체 폭으로 확정하지 않는다. 추가 문자 조형은 D3 최후순위다.
- 복잡한 머리말/꼬리말 제어·세로 정렬/다른 번호 형식, 알려지지 않은 내부 여백 레코드·자동 크기·모호한 개체 식별.
- 실제 한글과의 모든 글꼴 모양·인쇄 배치·쪽 계산 동일성. 제품 실행에 한글을 요구하지 않으며 네이티브 비교는 개발 환경의 별도 QA다.

이 경계에서 원래 HWP를 임의로 정규화하거나, 글을 줄이고 글꼴을 축소해 잘림을 숨기지 않는다. 엔진 관측과 폰트 추정은 구분하고, 확인할 수 없으면 `inconclusive` 및 `layout_verified:false`를 유지한다.

### 검증 근거

28개 합성 프로필의 계획, 같은 파일 저장과 재열기, 무변경 이력과 정확한 복구, 독립 OLE 판독 및 실제 한글의 쪽과 줄 대조로 기본 범위를 마감했습니다. [F3 기록](https://github.com/spark142857142857/hwp-easy/blob/baad6d4513b9918bd718bb5f1f3beb5027d43edb/docs/local-release-0.2.50.md)

회전 그룹의 지원 가로 글 표시는 후속 I3에서 보완했습니다. [I3 기록](https://github.com/spark142857142857/hwp-easy/blob/baad6d4513b9918bd718bb5f1f3beb5027d43edb/docs/local-release-0.5.0-dev.1.md)의 조건을 따르며 임의 그룹 조합의 표시를 보증하지 않습니다. 현재 설치와 호출 및 배치 대조는 [최신 검증](../verification.md)을 따릅니다.

| 개별 하위 그룹 | 직계 부모 좌표에서 이동·회전·크기 변경. 부모 안에 들어가는 결과만 허용 | 선택한 변환과 필요한 정규 루트 좌표계 보정. 형제의 실제 위치·이후 변환 쌍·내용 보존 |
| 최상위 그룹 | 검증된 프레임의 회전·크기 변경. 바깥 부동 앵커 이동은 기존 재배치 기능 | 원래 부동 상태·내용·그룹 계층 유지 |
| 추가 필드 | 하이퍼링크·범위 책갈피·날짜·문서 날짜/경로·메일 병합·참조·수식·요약/사용자 정보의 검증된 평문 표시값 | 명령·필드 ID·이름·부가 속성·메타데이터 꼬리 보존 |
| 필드 속성 | 누름틀 이름/안내, 다른 지원 필드 이름/명령의 명시 변경 | 값과 요청하지 않은 속성 보존. 명령 실행·링크 접속·외부 자료 조회 없음 |
| 필드 생성·삭제 | 글상자 안 누름틀, 본문/셀/개체 문단의 하이퍼링크·범위 책갈피 생성. 지원 래퍼 삭제 | 삭제할 때 표시값·서식 유지. 새 대상은 다시 읽어서 선택 |

날짜·수식 등의 `cache_only:true`는 **저장된 표시값 편집**을 뜻한다. 외부 프로그램이 필드를 다시 계산할 수 있다. 수식 계산·참조 해결·메일 병합·자동 갱신까지 구현했다는 뜻이 아니다. 일반 지점 책갈피와 범위 필드 책갈피도 구분한다.

### 대상 식별과 저장

그룹 내부 글은 현재 엔진의 일반 커서/필드 목록에서 빠지거나 같은 렌더 경로를 공유할 수 있다. 따라서 화면 문구나 렌더러의 셀 경로로 대상을 추측하지 않는다. 원본 레코드의 제어 순서와 그룹 자식/문단 경로를 읽고, 해당 글 목록을 **일회용 본문에 투영해 텍스트와 글자 서식을 대조**한다. 이 임시 문서나 렌더용 정의는 저장하지 않는다.

`text_boxes`, `drawing_groups`, `fields`의 버전 결합 대상 ID를 사용한다. `find`도 읽을 수 있는 글상자 문단을 포함한다. 문단 구조 변경 뒤의 배치 대상은 원본 레코드 출처로 추적하며, 확인할 수 없는 대상은 저장 전에 거부한다. 원본 스트림을 직접 패치하고 다시 읽어 검사한 뒤 같은 파일에 저장한다. 기존 충돌 검사·이전 바이트 보관·정확한 복구 계약을 그대로 사용한다.

### 지원 밖의 조건

- 세로쓰기, 잘못된 목록/텍스트/서식 기록, 검증되지 않은 내부 원점은 읽기 전용 또는 불투명 보존이다.
- 글 목록은 최대 32문단, 64개 상자·256개 개체 노드·24개 경로 요소의 안전 한도를 둔다. 한도 안의 임의 구조 전체를 검증했다는 뜻은 아니다.
- 하위 그룹 변형은 역행렬과 직교 축이 확인되는 양의 크기 프레임을 요구한다. 뒤집힘·기울어진 축·특이 행렬·불명확한 회전·부모 밖 이동은 거부한다. 상위 내용 경계가 달라지면 한글이 형제까지 늘려 그릴 수 있다. 앞/뒤 겹침 방식의 독립 부동 개체이며 검증된 1:1 정규 루트에서는 바깥 프레임/원점과 자손 좌표계를 함께 보정하고 비대상 실제 변환을 검사한다. 이때 형제 행렬의 좌표 표현은 바뀌어도 실제 위치는 유지한다. 비정규 루트·깊은 조상 경계·정수로 확인되지 않는 경계의 보정은 거부한다. 계획의 `drawing_frame_normalization`과 바뀐 부모 원점을 후속 단계에 반영한다. 형제 간 충돌 회피나 그룹 해제/재그룹은 자동으로 수행하지 않는다.
- 그룹 크기 변경과 글상자의 내재 줄바꿈 폭 변경은 구분한다. 원래 텍스트 방향/크기 관련 플래그를 보존하며 임의 글상자의 자동 맞춤을 약속하지 않는다.
- 메모·개인정보·목차·알 수 없는 필드, 중첩/개체를 감싼 필드 범위는 값 편집에서 제외한다. 기존 명령의 의미를 해석하지 않고 보존한다. 이름 메타데이터의 종류/길이나 누름틀 안내의 명령 구조를 확인할 수 없으면 해당 속성 변경을 거부하며 원본을 덮어쓰지 않는다.
- 내부 글상자 높이 초과는 **내재 내용 프레임의 글꼴 추정 경고**다. 바깥 셀/쪽 좌표로 잘못 환산하지 않는다. 그룹·회전·임의 필드의 전체 미리보기와 실제 한글 조판 일치는 별도 한계다.

`layout_verified:false`를 유지한다. 이번 네이티브 검증은 명시한 합성 프로필의 편집 결과·원래 색의 실제 쪽·복구 비교이며 모든 HWP의 인쇄 배치를 보증하지 않는다.
