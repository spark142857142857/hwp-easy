# 로컬 HWP Easy 0.2.46 검증 기록

[남은 F3](remaining-work.md#f3-세부-현황) · [지원 기능](supported-features.md#소스-0246-추가-기능) · [프로젝트 상태](project-status.md)

검증일: **2026년 10월 23일**. F3-B2의 **누름틀·인라인 개체 혼합 호스트와 명시적 다단**을 보완한다. 소스·검증 패키지는 **0.2.46**, 실제 Codex 설치는 **0.2.42**, Claude Code·Cursor 설치·공개 ZIP은 **0.2.19**다. 앱 설치·인증·모델 호출과 공개/포털 갱신은 진행하지 않았다.

## 변경

기존 일회용 렌더 입력은 필드·그림·글상자가 있는 셀을 통째로 제외했다. 값이 있는 ClickHere 필드의 정의/경계와 인라인 개체의 원래 제어·전체 셀 경로를 대조해 지원 정규화 호스트를 추가한다. 개체가 차지하는 줄 높이를 상위 셀의 위/가운데/아래 정렬과 다음 표의 원점에 반영한다. 글상자 내부 글을 엉뚱한 셀 문단으로 보고하던 표시 식별도 원래 글상자 ID·문단·호스트 경로로 복원한다.

고정 WASM은 명시적인 단 나눔을 다음 단의 원점에 반영하지 않았다. 한 구역·한 쪽의 지원 단을 별도 일회용 단일 단 문서로 계산한 뒤, 원래 단 너비/간격과 위치를 확인하여 한 SVG로 합성한다. 원래 문단·표/개체 식별을 복원하고 SVG 리소스 ID를 단별로 구분한다. 합성 뷰에는 내보내기 메서드가 없다. SVG·썸네일·진단은 같은 뷰를 사용하며 원본 편집·저장·복구 경로와 분리된다.

## 지원 조건과 남은 범위

| 구분 | 범위 |
| --- | --- |
| 필드 호스트 | 값이 있는 편집 가능한 ClickHere 필드, 검증된 시작/끝과 정의, 정규화된 셀 문단. 줄바꿈 없는 문단별 단일 크기·일반 가로 문단과 충분한 폭 |
| 인라인 개체 | 독립 문단의 단일 그림/지원 단순 글상자. 호스트 10pt·160% 줄 간격, 줄 간격 영향 켬, 절대 크기·바깥 여백/오프셋 0·회전 없음. 최대 32개 |
| 다단 | 한 가로 구역·한 쪽, 왼쪽→오른쪽 2–4단, 균등 또는 대조 가능한 비례 너비/간격, 명시적 단 나눔. 각 임시 뷰 전체가 해당 단의 본문 경계 안에 들어와야 함 |
| 원본 보존 | 원래 부동 상태·문단/필드/그림/글상자·셀 정렬/여백·DocInfo와 다른 스트림 보존. 임시 문단/공백·쪽/단 설정·추가 정의는 저장하지 않음 |
| B2 추가 범위 | 빈 필드 안내, 비정규화 문단 안의 개체/다른 글자 크기·줄 간격, 자동 단 채우기/균등 배분·다중 쪽·구분선/쪽 장식·반복/부분 행은 미확인 |
| F3-C | 좁은 셀 내부 여백·글꼴 대체·혼합 크기·줄바꿈 및 `pageBreak:2` 행 내부 쪽 분할은 미완료 |
| F3-D | 표 뒤 빈 본문 문단·후속 글과 고정 꼬리말 간격은 미완료. 이번 이미지에서도 빈 본문 문단 2개가 접혀 후속 글이 약 42.7px 일찍 표시됨을 재확인 |

이번 보완은 **렌더링 지원 확장**이다. `reflow_table`의 한 단 조건을 바꾸지 않는다. 다단 편집 검사는 기존 고정 높이와 `pageBreak:1` 안에서 8→12줄을 작성하며, 자동 표 확장/다단 쪽 이어짐을 제공한 것으로 해석하지 않는다. 필드/개체 프레임의 일치를 전체 글꼴·인쇄 배치 인증으로 취급하지 않고 `diagnostics_complete:false`, `layout_verified:false`, 미지원 이유를 유지한다. 추가 외국어/이모지 조형은 계속 D3 최후순위다.
