검증일: **2026년 10월 27일**. **F3-C1 좁은 말단 셀의 내부 여백·한글/영문 줄 경계**를 보완한다. 소스·검증 패키지는 **0.2.47**, 실제 Codex는 **0.2.42**, Claude Code·Cursor 설치·공개 ZIP은 **0.2.19**다. 실제 앱 설치·인증·모델 호출과 포털/공개 갱신은 하지 않았다.

## 변경

고정 렌더러는 좁은 중첩 셀의 내부 여백을 줄여 한글·영문을 원래 한글보다 한 줄에 더 많이 표시했다. 단일 문단 말단 셀의 원래 전체 경로·글자/서식 ID와 고정 엔진의 정확한 글꼴 지표를 대조해 기본 글자 폭을 얻는다. 양쪽 정렬에서 추가한 자간은 기본 폭으로 사용하지 않는다. 영문 단어가 들어가면 유지하고 긴 단어·한글은 글자 경계에서 나누며 원래 공백과 LF는 보존한다.

일회용 입력에서만 합성 LF를 넣고 가로 셀 여백을 문단 여백으로 옮긴다. 사본은 왼쪽 정렬로 관측한다. 원문 역투영·모든 글자 서식·실제 사본 줄과 시작 위치를 재검사하며 실패하면 원래 뷰를 유지한다. 반환하는 문자 위치는 원본 UTF-16 위치다. SVG·내장 BMP·진단의 `render_cell_wraps`와 `render_unadapted_cells`는 같은 근거를 공유하고, 명시적 다단 합성에서는 원래 문단/셀 경로로 다시 매핑한다.

HWP에 저장되는 글·문단/글자 정의·셀 여백·부동 플래그는 기존 원본 경로를 따른다. 합성 LF와 여백용 추가 문단 정의는 저장하지 않는다. 엔진 교체·폰트 설치·서버·한글 의존성을 추가하지 않는다.

## 지원 조건과 남은 작업

한 구역·한 쪽의 기존 정규화 중첩 렌더 범위, 단일 평문 문단 말단 셀, 충분한 저장 높이, 기본 10pt·보통 문자 속성·장평/상대 크기 100%·자간/위치 이동 0을 대상으로 한다. 완성형 한글·영문/숫자·공백·LF와 원본에 정확히 연결되는 엔진 글꼴 지표만 보정한다. 칸당 1,024자·합계 4,096자 이내다. 네이티브 대조 표본의 원래 글꼴은 함초롬바탕이다.

이번 6건은 **상위 셀 위 정렬과 말단 셀 위/가운데/아래 정렬**을 검증한다. 글리프 모양·원래 양쪽 정렬의 자간·모든 기준선·인쇄 배치 전체 일치를 인증하지 않는다. `layout_verified:false`, `diagnostics_complete:false`를 유지한다.

| B4 | **새 오류·미수정 / 다음 순서** | `pageBreak:2`, 한 문단 접두부+중첩 표와 큰 여유 높이를 가진 상위 셀의 가운데/아래 정렬. `nestedRenderFixture({lines:3,room:10000,alignment:1})` 및 아래 정렬 변형의 첫 탐색 코퍼스에서 native/preview 테두리 원점 불일치 재현. C1 표본은 상위 위 정렬로 이 차이를 분리했으며 완료로 합치지 않음 |

공용 측정의 후속 관측: 원본 함초롬바탕 `A`의 정확한 기본 폭은 706 HWPUNIT이지만 `createNaturalTextMeasurer`의 빈 문서 측정은 502.5 HWPUNIT이다. 이번 렌더 보정은 원본 trace를 사용하며 기존 공용 측정 함수는 바꾸지 않았다. F1/F2 배치·표 높이에 미치는 영향은 아직 재현/수정하지 않았으므로 C2에 남긴다. 근거는 `measurement-audit.json`이며 클리핑/저장 손상이 확인됐다는 뜻은 아니다.
