# 로컬 HWP Easy 0.2.43 검증 기록

[남은 F3](remaining-work.md#f3-세부-현황) · [지원 기능](supported-features.md#소스-0243-추가-기능) · [프로젝트 상태](project-status.md)

검증일: **2026년 10월 23일**. **F3-A — 지원 빈 부동 앵커의 렌더링 높이·그림 원점 보정**을 추가했다. 소스·검증 패키지는 **0.2.43**, 실제 Codex 설치·새 채팅은 **0.2.42**, Claude Code·Cursor 설치와 공개 ZIP은 **0.2.19**다. F3 전체 완료를 뜻하지 않는다.

## 문제와 변경

0.2.42 설치 검증의 중첩 표 뒤 그림·BOX 글상자는 실제 한글에서 분리되어 있었지만 WASM 미리보기에는 그림·글상자·뒤쪽 본문이 겹쳤다. WASM이 글자 없는 부동 앵커 문단의 고정 줄 높이를 건너뛰는 것을 재현했다. 글상자 다음 그림의 원점이 자신의 문단 줄보다 앞에 놓이는 현상도 별도로 확인했다.

SVG 미리보기·저장 썸네일·렌더 좌표 진단에 같은 **일회용 렌더 문서**를 사용한다. 검증한 빈 앵커에만 보이지 않는 공백을 메모리에서 넣어 원래 고정 줄 높이를 반영하고, 필요한 그림은 자신의 문단 줄 원점과 대조해 그 임시 문서의 세로 오프셋만 보정한다. 이 문서는 편집·대상 선택·HWP 내보내기·저장에 사용하지 않으며 작업 뒤 폐기한다. 원본/편집본 HWP의 앵커 글·개체 위치·정의에는 공백이나 보정 오프셋이 들어가지 않는다.

지원 조건은 가로·한 단·고정 크기·바깥 여백 0·회전 없는 그림/단순 사각형, 고정 줄 높이를 가진 **빈 본문 문단의 단일 부동 앵커**다. 기존 F2의 명시적 쪽 나눔과 예약 높이는 원래 값으로 읽는다. 최대 128개 앵커, 그림 원점 대조는 32쪽·20,000개 항목으로 제한한다. 글이 있는 호스트·셀 안·그룹/회전·비정상 예약 높이·다단 등은 이 보정의 범위 밖이다.

`render_adaptations`는 구역/문단·예약 높이와 필요 시 `picture_origin_correction`(HWPUNIT)을 보고한다. `render_unadapted_anchors`는 발견했지만 보정하지 못한 프로필을 구분한다. 진단에서 임시 공백의 글자 상자는 제외하며 실제 기존 충돌은 계속 보고한다. `EMPTY_FLOATING_ANCHOR_RENDER_ADAPTED`/`EMPTY_FLOATING_ANCHOR_RENDER_UNVERIFIED`를 한계로 남기고 **`diagnostics_complete:false`, `layout_verified:false`를 유지**한다.

## 패키지와 재현

검증 ZIP은 **25개 파일·5,623,509바이트**, SHA-256은 `fa5535a747e8b6eca2bd7d3e16bc46b04604e8a43db34f44f652ff7b2f6f7985`다. runner는 `198894f72234673abe0e48cb3cc58962af1cd0504018d282af73df68a4b67744`, 고정 `@rhwp/core 0.8.6` WASM은 `8000e4ce320b7994dca6bcd58be0c862144c7b805576504e523a420439da658b`다. WASM 바이너리는 변경하지 않고 로컬 JS 렌더 경로를 보완했다. 이전 0.2.42 ZIP·설치본과 명시적 스킬 호출 정책을 유지한다.

```powershell
node --test tests/test_local_render_view.mjs
node scripts/check-local-render-view.mjs <새-출력-폴더>
python scripts/check-local-render-view.py <새-출력-폴더>
```

선택적 신뢰 문서 네이티브 QA는 `render-local-table-reflow-native.py` 다음 Pillow 환경의 `check-local-table-floating-native.py`를 사용한다. 실제 입력/편집/복구 HWP·요청 결과·원시 판독·SVG/이미지·로그는 ignored `outputs/f3-043-20261023/`에 보관한다. 최종 배포 자원 검사는 `package-final/`, 집계는 `summary.json`을 따른다. 중간 시도는 완료 집계에 더하지 않는다.

## 남은 F3

이번 보정 후에도 **중첩 셀의 미리보기 원점·접두부 표시, 글꼴/줄바꿈·표 실제 높이와 꼬리말 간격**은 실제 한글과 다르다. 네이티브 QA의 성공은 이 여섯 합성 문서의 저장/배치 확인이고 임의 문서의 표시 인증이 아니다. F3-B·C·D와 후속 Codex 설치 갱신, 다른 사용자 환경·공개는 [남은 작업](remaining-work.md)에 구분한다. Claude Code·Cursor는 계속 보류한다.
