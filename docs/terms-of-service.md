## 제공 기능

HWP Easy는 사용자가 지정한 HWP 파일을 읽고 지원하는 문서 내용을 편집합니다. 저장 전 대상과 현재 내용을 확인한 뒤 같은 파일에 저장하고 이전 파일을 복구용으로 보관합니다. 사용자가 요청하면 별도 사본으로 저장할 수도 있습니다.

파일 접근 권한과 Node.js 22 이상이 있는 실행 환경이 필요합니다. 문서 엔진은 패키지에 포함됩니다. 현재 검증한 구조와 제한은 [지원 기능](supported-features.md)에 설명합니다. 모든 HWP 구조를 편집할 수 있는 것은 아니며, 지원 여부를 확인할 수 없는 편집은 거부할 수 있습니다. HWPX, PDF와 DOCX 변환은 제공 범위에 포함되지 않습니다.

## 파일과 이용 권한

사용자는 읽고 수정할 권한이 있는 파일을 지정해야 합니다. 다른 사용자의 접근 제한이나 실행 환경의 권한을 우회해서는 안 됩니다. 스킬은 사용자가 명시적으로 호출한 작업에만 적용하도록 배포합니다. 파일과 작업 결과의 처리 방식은 [개인정보처리방침](privacy-policy.md)을 따릅니다.

## 저장과 복구

같은 파일 저장은 선택한 원본을 변경합니다. 저장 전 버전 확인과 복구 사본으로 일반적인 충돌과 오편집을 줄이지만, 모든 외부 프로그램의 동시 쓰기나 저장 장치의 실패를 막는 것은 아닙니다.

복구 사본은 기본적으로 원본과 같은 폴더의 `.hwp-easy-backups`에 보관합니다. 해당 사본을 삭제하거나 접근 권한을 잃으면 이전 내용으로 복구하지 못할 수 있습니다. 스킬 제거와 대화 종료만으로 복구 사본을 자동 삭제하지 않습니다.

문서 내용과 저장 바이트 검사가 모든 글꼴, 표와 쪽 배치의 동일성을 보증하지는 않습니다. 제출하거나 공유할 중요한 문서는 실제 사용할 문서 프로그램에서 결과를 확인해야 합니다.
