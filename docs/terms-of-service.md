이 약관은 HWP Easy의 원격 HWP 처리 기능을 이용할 때 적용됩니다. ChatGPT와 Codex, 호스팅 플랫폼의 이용 조건은 별도로 적용됩니다. 현재는 공개 플러그인 출시 준비 단계이며 모든 계정에서 설치할 수 있는 상태는 아닙니다.

## 제공 기능과 범위

HWP Easy는 지원하는 HWP의 본문과 표 셀을 읽습니다. 사용자가 지정한 내용을 수정하고 검사한 뒤 같은 원격 문서의 새 버전으로 저장합니다. HWP 다운로드와 이전 버전 복구를 제공하며 한글 프로그램 설치는 필요하지 않습니다.

현재 원격 처리 범위는 파일 4 MiB 이하, 본문과 표 셀 합계 400,000 UTF-16 단위 이하입니다. 이 범위 안의 모든 문서가 지원되는 것은 아닙니다. 지원하지 않는 문서나 변경은 거부하며, 요청 내용을 임의로 줄여 일부만 저장하지 않습니다. 새 문단, 표 행 생성, 파일 형식 변환, 암호 해제, 매크로 실행과 외부 기관 자동 제출은 제공 범위에 포함되지 않습니다.

원격 저장은 PC 원본 파일을 변경하지 않습니다. 중요한 원본과 결과는 별도로 보관하세요. 텍스트, 바이트 검사가 글꼴, 표, 페이지 배치의 완전한 동일성을 보장하지 않으므로, 중요한 제출물은 외부 HWP 뷰어에서도 확인하세요. 인증 만료 시 재연결이 필요할 수 있고 자동 갱신의 지속 동작은 아직 조사 중입니다.

## 문서와 이용 권한

사용자는 읽기, 수정, 전송할 권한이 있는 문서만 제공합니다. 다른 사용자의 문서 접근을 우회하거나, 서비스 보호와 처리 한도를 우회하는 요청을 해서는 안 됩니다. 문서 처리에 필요한 업로드는 [개인정보처리방침](privacy-policy.md)에 설명된 원격 저장과 사용 중인 대화로의 결과 전달을 포함합니다.

주민등록번호 등 정부 발급 식별자, 의료정보, 결제카드 정보, 비밀번호, API 키, 인증 코드가 포함된 파일을 업로드하지 마세요. 공개 지원 게시판에는 개인 HWP와 인증 정보를 올리지 마세요.

## 저장과 복구, 삭제

저장 요청은 선택한 대상, 기존 내용과 현재 버전을 확인한 뒤 수행합니다. 이전 버전을 유지해 복구할 수 있지만, 사용자가 해당 문서를 삭제한 뒤에도 복구가 가능하다고 약속하지 않습니다. 삭제는 사용자가 명시적으로 요청한 문서와 관련 버전을 대상으로 하며, 완료, 불확실, 실패 상태를 확인해야 합니다. 연결 해제나 대화 종료는 문서 삭제가 아닙니다.
