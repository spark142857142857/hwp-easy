# 로컬 메인 0.2.16 후속 검증

2026년 10월 12일, 설치된 HWP Easy 0.2.16으로 파일 처리와 공개 복잡한 양식의 지원 범위를 확인했다. 일반 파일 선택·읽기·편집·저장·복구는 파일 도구와 Node/WASM으로 수행한다. computer-use는 화면에서만 확인할 수 있는 배치 문제에 필요한 최소한의 확인으로 제한한다.

## 복잡한 문서의 읽기 보완

0.2.15는 머리말·글상자·일부 그림 그룹 때문에 복잡한 대상 매핑을 증명하지 못하면 본문 조회도 거부했다. 0.2.16은 해당 구조의 제한 오류에 한해 엔진이 확인할 수 있는 본문과 최상위 표 셀을 **읽기 전용**으로 반환한다.

이 결과는 `partial_read_only:true`, `target_mapping_verified:false`, `content_complete:false`를 표시한다. 모든 블록의 편집 대상은 없고 편집·서식 후보도 비활성화된다. 이어 읽기가 끝나도 문서 전체를 읽었다는 뜻은 아니다. 머리말·글상자 등 일부 개체 내용은 빠질 수 있다. 계획·저장·편집 좌표 검색에는 이 완화 경로를 적용하지 않는다. 잘못된 파일, 오래된 해시와 cursor 검사는 그대로 수행한다.

[읽기 회귀 검사](../tests/test_local_partial_read.mjs)는 지원되지 않는 머리말, 분할 읽기 조합, 잘못된 cursor, 손상된 입력, 계획·편집·검색 거부와 원본 무변경을 확인한다. 기본 미리보기는 현재 HWP 바이트를 렌더링하며 `preview_source:current_document_render`, `embedded_preview_cache:not_used`를 표시한다. 내장 `PrvText`와 `PrvImage` 갱신은 구현하지 않았다.

## 원래 복잡한 객체가 있는 공개 양식

개인 문서에 합성 객체를 삽입한 기존 검사와 별도로, [rhwp 고정 커밋](https://github.com/edwardkim/rhwp/tree/1a76570e833917d15817415a53c09ad61ab3203f)의 공개 HWP 12개를 내려받아 사본으로 시험했다. 원본·문서 바이너리는 저장소에 넣지 않았으며, 내려받은 바이트의 해시를 대조했다.

| 검사 범위 | 결과 |
| --- | --- |
| 12개 공개 문서 조회 | 모두 조회 성공. 8개는 일부 본문을 읽기 전용으로 제공한다. |
| 중첩 셀을 편집할 수 있는 3개 | 여러 줄 부분 수정, 저장 전 무변경, 같은 사본 저장, 재읽기와 정확한 원본 복구 통과. |
| 누름틀 값을 편집할 수 있는 1개 | 여러 줄 값 수정, 같은 사본 저장, 재읽기와 정확한 원본 복구 통과. |
| 독립 판독 4개 | Python OLE·UTF-16·제어 레코드 판독으로 요청한 기록만 달라졌고 다른 스트림과 비대상 기록이 동일함을 확인. |

읽기 전용 8개를 편집 지원으로 집계하지 않는다. 공개 자료의 수정·복구 결과와 출처·해시는 ignored `outputs/local-improvements-20261012/`에 보관한다.

## 설치와 새 채팅

정식 Codex CLI로 메인 하나를 0.2.16으로 갱신하고 설치·활성 상태를 확인했다. [설치된 패키지 검사](../scripts/check-installed-plugin.mjs)와 [독립 판독](../scripts/check-installed-plugin.py)은 본문·여러 문단 표 셀, 같은 파일 저장, 충돌 거부, 동일 요청 무저장, 이력, 정확한 원본 복구와 편집본 재복구를 통과했다. 원격 0.1.9 코드와 ZIP은 보존한다.

별도 Codex 채팅의 최초 스킬 목록에는 설치 스킬이 나타나지 않았다. 공식 `skills/list`에서는 `hwp-easy:edit-local-hwp`가 활성화된 설치 경로로 발견됐다. 그 정확한 경로의 스킬을 명시적으로 읽어 적용한 후 파일 수정·저장·복구를 통과했다. 최초 목록 주입이나 화면 메뉴 선택 성공으로 표시하지 않는다. 기본 호출 문구는 실제 등록된 이름 `$hwp-easy:edit-local-hwp`로 맞췄고 자동 적용 금지는 유지한다.

한국어를 먼저 두고 영어를 아래에 두는 원본 메타데이터를 유지한다. 현재 호스트의 발견 결과는 짧은 설명과 기본 프롬프트의 줄바꿈을 공백으로 정규화하므로 실제 화면의 두 줄 표시는 별도 확인이 필요하다.

전체 로컬 단위 339개와 공통 엔진 34개를 통과했다. 앞서 한글 2020에서 합성 본문/셀, 누름틀 세 줄과 글자 서식, 중첩 셀의 줄바꿈과 서식, 두 그림의 그룹 결과를 확인했다. 좁은 셀에서는 긴 문구가 추가로 줄 바뀐다. 이 제한된 화면 확인은 임의 문서의 전체 쪽 배치 인증이 아니다.

## 남아 있는 항목

- 새 채팅의 최초 스킬 목록·메뉴 선택과 다른 사용자의 새 설치 흐름.
- 최신 메인 패키지를 새 Codex Cloud 작업에 전달해 수정 결과를 회수하는 전체 흐름.
- 내장 미리보기 텍스트·썸네일을 최신 내용으로 갱신하는 처리.
- 중첩 표 구조·문단 서식, 그림이 있는 셀의 표 구조, 누름틀 생성·삭제와 그룹 그림 교체·회전 등 편집 지원 확장.
- 로컬 메인 패키지의 공개 디렉터리 제출·심사·게시. 기존 원격 심사와 구분한다.
