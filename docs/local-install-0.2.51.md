# Codex 설치·새 채팅 검증 — 0.2.51

2026년 10월 27일, **기존 검증 ZIP을 재생성하지 않고** 실제 Codex 설치를 0.2.42에서 **0.2.51**로 갱신했다. 새 로컬 채팅에서 설치 스킬을 명시적으로 읽고 일반 문서·중첩 표·그룹 문서 세 개를 편집·같은 파일 저장·정확히 복구했다. 별도의 독립 판독과 실제 한글 대조까지 확인해 **R1 후속을 완료**했다.

## 설치와 발견

ZIP을 새로운 영구 마켓플레이스 폴더에 준비하고, Codex CLI **0.157.1**의 `plugin marketplace remove/add`·`plugin add`로 HWP Easy 등록 참조와 설치본을 갱신했다. 기존 설치 전체 사본·영구 마켓플레이스·ZIP은 보관했다. 직접 설정 파일을 편집하거나 원격 MCP를 등록하지 않았으며, CLI가 바꾼 설정은 요청한 HWP Easy 마켓플레이스 참조뿐이다. ## 새 채팅의 실제 편집·복구

| 합성 문서 | 요청과 확인 |
| --- | --- |
| 일반 본문·셀 | 본문 한 곳과 답변 셀 변경. 새 답변 두 줄은 실제 두 HWP 문단이며 이모지·비대상 글/서식 유지 |
| 중첩 표 쪽 이어짐 | 깊이 2의 답변 **8줄→65줄**, 같은 문단 내 LF와 표 높이/흐름 반영. 실제 한글과 설치 미리보기 모두 **1쪽→2쪽**, 두 번째 쪽은 **L038**부터 이어짐 |
| 그룹 내부 편집 | 내부 누름틀 값·이름·안내, 형제 글상자 글 변경. 첫 하위 그룹만 이동·회전·축소하고 상위 좌표계 보정 후 비대상 형제의 실제 위치 유지 |

각 파일을 모든 커서까지 읽어 대상과 기대값을 선택했다. 파일마다 한 operations 배열로 계획하고 **한 번 같은 경로에 저장**했다. 계획 전후 원본 해시·백업 목록 불변, 계획/저장의 검증 후보 해시·저장 경로·출력 해시·재읽기·원본 백업을 대조했다.

편집본을 증거 사본으로 보관한 다음 **별도의 restore 요청 JSON**으로 같은 파일을 복구했다. 세 파일 모두 최초 원본과 전체 바이트가 일치하며 편집본도 복구 이력에 보관됐다. 최종 백업은 **6개**다. 일반 본문의 무변경 저장은 파일과 백업을 바꾸지 않았다. 새 채팅은 저장소 소스 실행기·빌드 폴더로 대체하지 않았다.

부모 검증에서는 독립 OLE/원시 레코드 판독으로 모든 요청한 글·문단·필드 속성, 기존 글꼴/스타일 정의·비대상 제어/목록/스트림을 확인했다. 그룹 좌표계 보정은 비대상 실제 행렬도 독립 계산했다. 새 채팅의 원본/편집/복구 사본 **9개 파일·10쪽**을 별도 숨김 한글에서 무저장으로 열었다. 복구 **3쪽**은 원본 픽셀과 일치한다. 중첩 답변의 **81개 물리적 줄**(8+65+복구 8)의 쪽 소속, 그룹 도형 모서리 **32곳**과 비대상 형제 영역 픽셀도 확인했다. 부모가 검사한 뷰의 SVG는 실제 설치 실행기가 새 채팅에 반환한 모든 편집 후 SVG와 일치했다.

## 확인한 제한

**I3: 회전된 하위 그룹의 글이 SVG 미리보기에서 누락된다.** 설치 실행기의 읽기와 저장된 HWP에는 요청한 글/필드 값이 존재하며 실제 한글에서도 정상 표시된다. 이 표시 차이는 후속 지원 확장으로 남겼다. 문서 내용 손실이나 복구 실패로 취급하지 않으며 미리보기가 완전하다고 보고하지도 않는다.

시험의 종이 기준 그룹은 왼쪽 본문 여백보다 바깥에 놓여 있어 원본과 편집본 모두 `FLOATING_OBJECT_OUTSIDE_BODY`를 보고한다. 회전/그룹·불투명 개체 전체의 표시와 임의 배치를 인증하지 않는다. 중첩 표의 미리보기에도 네이티브 페이지 분할 미확인 제한이 남지만, 이번 합성 사례는 부모가 실제 한글의 줄/쪽과 별도로 대조했다. `layout_verified:false`를 유지한다.

새 채팅 자체는 한글 앱을 실행하지 않았다. 네이티브 대조는 부모의 별도 개발 QA이며 제품 실행의 필수 조건이 아니다. 첫 SVG 문자열 감사는 글자별 요소를 완성 문자열로 가정해 실패했고, 도우미만 고쳐 숨기지 않은 텍스트 요소의 순서로 65줄을 다시 검사했다. 그 실패를 통과로 기록하거나 문서를 다시 편집하지 않았다.
