# HWP Easy MVP 진행 상태

갱신일: 2026년 10월 5일. 소유자 전용 비공개 개발 연결을 기준으로 한다. 아래의 완료 표시는 명시한 문서·사용자·실행 범위에만 적용한다. 일반 문서 호환성과 공개 서비스 준비를 뜻하지 않는다.

## 확인한 흐름

- [x] 한글 없는 Windows·Linux 실행, 합성 HWP 20종과 별도 국소 편집 사례의 읽기·저장·재열기·보존 검사.
- [x] 지원 본문·최상위 표 셀의 이어 읽기, 대상별 편집 제한, 저장 전 생성·보존 검사.
- [x] 같은 원격 문서 저장, 버전 충돌·정확한 재시도 처리, 이전 버전 유지와 복구. 삭제 계약과 실패 주입 검사는 모의 신원의 실제 로컬 저장소에서 확인.
- [x] 실제 Codex Desktop와 저장소 Codex Cloud에서 한 사용자·고정 합성 HWP의 입력·편집·저장·바이트 회수·재열기. Cloud의 보호된 링크로 PC 다운로드 확인.
- [x] 실제 로그인 브라우저의 합성 HWP 선택·업로드·기본 미리보기·다운로드 및 같은 계정 MCP 조회.
- [x] 내 문서 목록과 저장본 다시 열기, 이전/현재 버전 구분, 한국어 앱 소개와 사용 안내. 마지막 기능 변경의 344개 Node 검사와 Windows·Ubuntu CI 4개 작업 통과.

## 다음 작업의 우선순위

순서는 제안이며 완료 조건을 대신하지 않는다. 첫 사용 문서 범위와 추가 클라이언트의 제공 시점은 아직 확정하지 않았다.

| 순서 | 남은 작업 | 완료를 판단할 근거 |
| --- | --- | --- |
| 1 | **첫 지원 양식과 호환성 범위 확정** | 실제 사용 양식의 구조를 읽기 전용으로 분류하고, 지원 대상·읽기 전용 대상·거부 사유를 구분한다. 기존 개인 시험 파일을 업로드하거나 수정하지 않는다. 대표 구조의 비개인 합성 사례로 국소 편집·비대상 보존을 재현하고, 허용된 별도 환경에서 HWP 열기와 내용을 비교한다. 복잡한 모든 양식 지원이나 정확한 조판을 약속하지 않는다. |
| 2 | **문서를 에이전트에게 전달하는 마지막 단계와 파일럿 사용 흐름** | 정확한 저장본의 보기 링크·요청 예시를 쉽게 전달한다. 이미 수동 복사 안내는 있다. 문서 읽기·요약·대상 지정·수정·반복 편집·복구에서 누락, 다른 셀 선택, 불필요한 사용자 조작과 실패 설명을 확인한다. 원래 파일 이름을 보관하지 않는 목록의 식별 편의도 검토한다. |
| 3 | **남은 실제 클라이언트 연결** | ChatGPT 일반 문서 사용, Claude Desktop·Claude Code의 연결·인증·HWP 입력·결과 회수를 각각 기록한다. 기존 ChatGPT Work 고정 합성 진단을 일반 문서 지원으로 집계하지 않는다. Cloud 결과 첨부 UI는 출력 경로 권한 문제로 미검증이며, 이미 확인된 바이트 회수·보호된 링크 다운로드와 구분한다. |
| 4 | **운영과 데이터 보호 검증** | 실제 두 OAuth 사용자 격리·접근 철회, 원문을 남기지 않는 운영 로그, 기록된 버전 외 미게시 바이트 정리, 삭제·백업 경계와 장애 대응을 확인한다. 현재 소유자 전용 접근을 확대하기 전 별도 검증이 필요하다. 모의 두 owner 검사와 실제 두 계정 검증을 구분한다. |
| 5 | **배포 범위와 사용 한도 마무리** | 첫 지원 문서·클라이언트 범위를 명시하고, 반복 작업의 시간·메모리·저장 비용, 4 MiB·문서별 128버전 한도 및 실패 안내를 정한다. 일반 사용자용 연결 안내와 최종 배포 형태를 확정한다. 현재 비공개 파일럿에 필요한 항목과 다른 사용자에게 제공하기 전 필요한 항목을 구분한다. |

첫 양식 범위의 확인은 현재 편집 제한을 넓히는 약속이 아니다. 이름 있는 필드, 중첩 표, 머리말·꼬리말, 이미지 편집, 혼합 글자 스타일 수정, 새 문단·셀·표 구조 생성은 지원 완료로 표시하지 않는다. 필요한 양식이 현재 계약을 벗어나면 기능 확대와 첫 범위 축소 중 어느 쪽을 택할지 검토한다.

실제 사용자 격리와 공개 운영 준비를 끝낼 때까지 현재 소유자 전용 비공개 배포 범위를 유지한다. 소유자용 파일럿의 기능 확인만으로 다중 사용자 서비스를 완료 처리하지 않는다. 정확한 글꼴·줄바꿈·페이지 배치는 별도 검증이며, 현재 기본 미리보기의 완료 조건을 임의로 전체 조판 인증으로 확대하지 않는다.

## 현재 범위 밖

- Dots는 사용자 결정으로 MVP에서 제외한 추후 확장 항목이다.
- HWPX·PDF·DOCX 변환과 내보내기는 새 제품 범위에 없다.
- 기존 Windows COM용 EXE·GUI 배포안은 참고 자료이며 새 제품의 우선 개발 순서가 아니다.
- PC 원본 직접 저장은 별도로 허용된 로컬 연결이 필요하다. 현재 원격 저장과 다운로드를 PC 원본 자동 갱신으로 설명하지 않는다.
