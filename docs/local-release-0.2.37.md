# 로컬 HWP Easy 0.2.37 검증 기록

[남은 F2](remaining-work.md#f2-세부-현황) · [지원 기능](supported-features.md#소스-0237-추가-기능) · [프로젝트 상태](project-status.md)

검증일: **2026년 10월 22일**. F2-B3의 표 사이·뒤쪽 글과 한 본문 문단의 복수 루트 표를 추가했다. 소스·검증 패키지는 0.2.37이며 실제 Codex 설치는 0.2.25, Claude Code·Cursor 설치와 공개 ZIP은 0.2.19다.

## 구현과 보존 범위

`reflow_table`은 표 사이/뒤쪽 글이 있는 호스트와 복수 루트 표를 가진 본문 호스트를 **글·표별 문단으로 나눈다**. 기존 문단 경계가 바뀌는 명시적 구조 조정이다. 글과 표를 다른 순서로 옮기거나 답변을 축약하지 않는다. 원래 UTF-16 글/앵커 단위·글자 서식·문단 서식을 그대로 조각에 배분하고, 새 문단을 다시 읽어 내용·서식을 대조한다. 셀 문단 수와 마지막 문단 플래그도 갱신한다.

같은 본문 호스트의 루트 표는 `scope:"whole_body_host_forest"` 문맥 하나로 노출한다. `root_table_ids`와 전체 `expected_tables`를 대조한 뒤 하위 표까지 조정한다. 표 밖의 너비·안팎 여백·테두리·병합·인스턴스 ID·비대상 컨트롤/스트림은 보존한다. 중복 루트 인스턴스 ID는 이후 자동 동기화의 대상을 확정할 수 없어 저장 전에 거부한다.

분할 문단의 표는 Square·LeftOnly 흐름을 사용해 뒤쪽 글이 표 옆으로 흐르지 않도록 한다. 공통 속성은 [한컴 HWP 5.0 형식의 표 70](https://cdn.hancom.com/link/docs/한글문서파일형식_5.0_revision1.3.pdf)을 기준으로 하며, 설정 값만으로 배치를 판정하지 않고 실제 한글에서 순서·프레임·잉크를 대조한다. 초기 배치 조사에서는 문단 분할만으로 글이 겹치는 경우를 확인해 최종 흐름에 반영했다.

분할된 원래 호스트 문단의 대상은 무효화한다. 새로 읽어 조각을 선택해야 한다. 보존되는 셀·필드·그림 등의 대상은 원래 레코드를 따라 매핑하며, 같은 글을 가진 표를 해시로 추측해 연결하지 않는다. 흐름 조정 뒤 같은 묶음에서 셀을 편집하거나 비대상 필드를 수정하는 경우, 파일을 다시 연 뒤 높이 동기화와 앵커 뒤에 새 글을 넣는 자동 분할을 검사했다.

본문 편집을 WASM의 일반 재직렬화 경로로 처리하면 복수 표의 셀 리스트 보존 검사가 실패하는 경우가 있었다. 흐름 표가 있는 구역의 본문도 검증된 원시 편집 경로로 처리한다. 앵커 전용 본문 문단의 범위/구조 편집 가능 표시도 이 경로와 맞췄다. 전체 글 교체 가능 여부와 앵커를 보존하는 범위 편집은 구분한다.

네이티브 검사는 원래 색의 쪽 이미지를 먼저 만든 뒤 메모리에서만 글의 색을 구분해 추가 이미지를 만든다. 검색 결과가 있다는 이유만으로 표시 완료로 판정하지 않는다. 표시된 답변 줄 수·각 쪽 검색 위치·실제 셀 세로 프레임·글/표 순서를 확인하며, HWP 파일은 저장하지 않는다. 복구 픽셀은 원래 색 이미지끼리 비교한다. 마지막 읽기 가용 표시 정정 후 최종 패키지의 HWP 입력이 네이티브 검증 입력과 같은 바이트인지도 대조한다.

최종 로컬 증거는 무시된 `outputs/f2-037-20261022/final-text/`의 `cases.json`, `summary.json`, `independent-summary.json`, `native/results.json`, `native/summary.json`, `native-input-match.json`과 `final-table.log`, `final-complex.log`다. `probe`, `square`, `verified-text`, `release-text`, `margins` 등 조사/중간 결과는 최종 수치에 중복 합산하지 않는다. 개인 문서는 사용하지 않았다.

이번 증분 단계는 수동 `scope:table-text`의 관련 Windows/Linux 2개 작업을 실행한다. 기존 표 소스 회귀와 새 패키지·독립 판독을 포함한다. 전체 기본 CI는 새 글/본문 호스트 작업을 분리해 기존 모든 명령을 유지한 **16개 작업**이며, 이번 부분 실행의 성공을 전체 16개 성공으로 기록하지 않는다. 검사 커밋·실제 결과는 [Source checks](https://github.com/spark142857142857/hwp-easy/actions/workflows/checks.yml)와 로컬 `outputs/f2-037-20261022/ci-result.json`으로 연결한다.

## 남은 범위

분할 대상 호스트 안의 필드/다른 개체, 아주 좁은 셀·혼합 글자 크기·복잡한 문자 조형, 독립 부동 개체와 성장 표의 충돌 회피, 행 최소 높이 축소·빈 공간 최적화가 남는다. 기존 깊이·너비·작업량/높이 한도를 유지하며 대표 배치 검사와 모든 reader의 동일한 폰트/쪽 계산 인증을 구분한다. `layout_verified:false`를 유지한다. 실제 설치·새 채팅과 공개 상태는 [남은 작업](remaining-work.md)에서 별도로 관리한다.
