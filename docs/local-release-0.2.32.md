# 로컬 HWP Easy 0.2.32 검증 기록

[프로젝트 상태](project-status.md) · [지원 기능](supported-features.md) · [남은 작업](remaining-work.md)

2026년 10월 18일. 소스·분리 패키지의 F1-A·F1-C 지원 범위를 확장했다. 실제 Codex 설치는 0.2.25, Claude Code·Cursor 설치와 공개 ZIP은 0.2.19를 유지한다. F1-B가 남으므로 F1 전체 완료로 표시하지 않는다.

## 변경 내용

- **조상 셀 정렬:** 고정 격자에 단일 지원 인라인 표 문단을 가진 조상의 가운데/아래 정렬을 유지한다. 안쪽 표의 원래 높이와 위아래 바깥 여백으로 원점을 계산하고, 깊이 2·3·여백·좌우 셀을 검사한다.
- **셀 그림·그룹:** 일반/중첩 셀의 지원 PNG/JPEG 그림과 그림 그룹을 부동 상태로 옮긴다. 원시 단·최상위 본문 문단 기준을 유지하고 오프셋과 매핑된 줄 캐시만 변경한다. 앵커 이동 시에는 기존의 원시 하위 구조·호스트/서식 위치 보존 경로를 사용한다. 이미지 바이트·crop·공통 크기·자식 행렬은 정확히 보존한다.
- **프레임 검증:** 그림의 행렬 범위가 공통 틀과 일치하는지, 그룹의 자식 범위가 공통 틀 안에 있는지 검사한다. 회전·자르기가 있는 대표 사례도 확인한다. 알 수 없는 범위나 틀 밖 자식은 저장 전에 거부한다. 지원 형제 개체도 장애물로 투영한다.
- **진단과 대상 추적:** 단 기준 오프셋을 그림/그룹의 셀 내부 폭에 더하던 잘못된 넘침 판정을 보완한다. 정렬 조상에서는 선택 부동 개체를 제외한 표 흐름으로 진단한다. 이동 뒤 같은 묶음의 그룹 자식을 원래 대상으로 추적하며, 단독 그림은 재읽기 후 새 호스트를 선택해야 한다.

한 공통 Node/WASM 엔진을 유지한다. 제품 실행에 서버나 한글 설치를 추가하지 않는다. 실제 한글 확인은 신뢰한 합성 파일의 Windows 호환성 검사이며 computer-use 호출은 0회다.

## 검증 중 보완한 문제

WASM은 셀 부동 오프셋을 조상 정렬 높이에 포함해 실제 한글과 다른 표 원점을 만들 수 있었다. 이 표시 결과를 실제 HWP 위치로 사용하지 않도록 선택 개체를 제외한 흐름과 원시 높이·여백을 대조한다. `NESTED_FLOATING_RENDER_ORIGIN_DISAGREEMENT`, `engine_checked:false`, `native_layout_verified:false`, `layout_verified:false`는 유지한다. 합성 사례의 네이티브 통과가 다른 문서의 조판 인증을 뜻하지 않는다.

회귀에서 단순 문서에는 없는 글상자 목록을 새 진단이 참조하는 문제를 발견해 빈 목록으로 처리했다. 기존 본문·그룹·필드·꼬리말·흐름 회귀도 다시 검사한다.

동시에 죽은 잠금을 회수하는 실행기 사이에서 디렉터리 존재 확인과 `lstat` 사이에 다른 실행기가 디렉터리를 지워 `ENOENT`가 노출되는 경쟁을 발견했다. 사라진 경로는 기존의 원자적 디렉터리 게시를 다시 시도하며, 파일·심볼릭 링크·살아 있는 소유자 보호는 유지한다. 실제 저장 경쟁 10회, 총 50개 실행에서 회당 한 개만 저장하는 것을 확인했다.

## 남은 범위

**F1-B:** 같은 셀의 복수 중첩 표·여러 줄/자동 줄바꿈 접두부·여러 문단을 가진 정렬 조상은 아직 지원하지 않는다. 앞선 글/표의 높이와 전체 제어 경로가 필요하다. 동일 크기와 글의 중첩 표 두 개는 원점을 임의로 고르지 않고 계획·편집 모두 원본과 이력을 바꾸지 않도록 검사했다.

추가 읽기 전용 재현에서 WASM은 같은 셀의 두 표를 같은 줄에 나란히 표시했지만, 실제 한글은 둘째 표를 다음 줄로 내리고 바깥 셀을 늘렸다. 렌더링 결과를 제어 순서로 구분하는 것만으로 실제 원점을 증명할 수 없다. 이 재현은 F1-B의 구현·편집 통과로 집계하지 않는다.

F2의 장문 중첩 표 자동 쪽 분할, F3의 WASM SVG/썸네일·폰트·쪽 배치 차이, F4의 그룹 내부 글상자 등은 별도다. 실제 앱 설치 갱신·새 채팅·공개·포털 제출도 이 기록의 완료 범위에 포함하지 않는다.
