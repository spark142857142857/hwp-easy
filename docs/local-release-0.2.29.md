## F1 부동 상태를 유지하는 재배치

`reposition_floating_object`의 지원 프로필을 확장했다. 개체를 글자처럼 취급하도록 바꾸거나 크기를 줄이지 않고, 선택한 개체의 부동 설정·감싸기·여백·이미지·그룹 행렬·실제 인스턴스 ID를 보존한다.

| 범위 | 동작 | 지원 조건 |
| --- | --- | --- |
| 다단 | 한 단 안의 빈자리 탐색, 지정한 단으로 이동 | 세로 용지·보통 균등 1–8단. 원시 단 수/간격과 표시 경계를 대조한다. 대표 한글 검사는 2·3단 |
| 다른 쪽 | 전체 앵커·하위 구조를 지정한 본문 문단으로 이동 | 같은 구역의 문단 ID와 기존 글을 함께 지정한다. 그 문단이 속한 쪽으로 이동하며 기존 쪽 나눔·본문·글자 서식을 보존한다. 지정 단과 함께 사용 가능 |
| 셀 안 | 지원 사각형 글상자를 현재 셀 안에서 재배치 | 일반 셀 첫 문단·위 정렬·병합 없음·문단/단 기준·글 앞으로. 회전/배율·내부 여백이 없고 내용 높이 추정이 프레임 안에 들어가는 프로필 |

셀은 **선택한 상자를 메모리에서 제외한 배치**를 기준으로 검사한다. 부동 상자 때문에 엔진이 늘려 놓은 셀 높이를 빈 공간으로 오인하지 않는다. 셀/표의 저장 크기를 바꾸지 않으며 재표시한 셀 경계가 달라지는 후보도 저장하지 않는다. 빈자리나 대상 식별을 확인하지 못하면 거부한다.

다른 쪽 이동은 `destination_target_id`와 `expected_destination`을 함께 받는다. 문단 맨 끝에 앵커를 붙이고, 내용·서식 위치와 후속 대상 ID를 다시 대조한다. 선택 상자/그룹의 후속 편집과 앞선 문단 삽입 이후 목적지 추적도 검사했다. 동일한 상자가 남아 있어도 확인한 레코드 매핑을 해시 추정으로 덮어쓰지 않는다. 그림은 문단이 대상 ID이므로, 이동 후 같은 배치에서 예전 문단으로 그림을 다시 고르는 요청은 `BATCH_RELOCATED_PICTURE_REQUIRES_READ`로 거부한다. 저장 후 다시 읽어 새 위치를 선택한다.

## 남은 프로필과 재현한 문제

**중첩 셀 자동 재배치는 미완료다.** 엔진에서는 안쪽 셀 안에 들어가는 후보가 한글에서는 바깥 셀의 원점에 붙어 안쪽 셀 경계를 넘는 합성 사례를 재현했다. 현재는 `PLACEMENT_CELL_NESTED_ANCHOR_UNVERIFIED`로 계획·저장 전에 거부한다. 기존의 명시적 `transform_text_box`와 I2 진단을 자동 배치 완료로 취급하지 않는다.

구역 간·셀 간·본문/셀 간 앵커 이동, 비균등/비보통 다단, 셀 후속 문단·가운데/아래 정렬·병합 셀·비사각형/그룹의 셀 자동 배치도 후속 범위다. 불명확한 페이지/프레임 식별, 본문 범위 밖 표와 셀 내용의 프레임 초과 가능성은 저장 전에 거부한다. 의도한 겹침을 임의로 판단하거나 임의 문서를 자동 최적화하지 않는다. `layout_verified:false`, `native_layout_verified:false`를 유지한다.
