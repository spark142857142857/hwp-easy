# 공개 사용자 안내

초기 출시 준비에서 정리한 처리 사실은 [개인정보처리방침](privacy-policy.md)과 [이용약관](terms-of-service.md)에 반영했습니다. 게시자는 OpenAI Platform에서 확인된 개인 신원이며 개인정보 문의 주소는 사용자가 공개하도록 지정한 주소입니다.

일반 사용 흐름은 [사용 안내](quick-start.md), 아직 완료되지 않은 심사·설치·다른 계정 검증은 [공개 플러그인 출시 준비](public-plugin-release.md)를 확인하세요. 정책 문서 게시와 플러그인의 디렉터리 게시를 구분합니다.
