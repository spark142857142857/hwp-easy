# 공개 사용자 안내 초안

공개 출시 전 검토용이다. 게시자 신원·실제 지원 연락처·정책 확인이 끝나기 전에는 확정 약관이나 이미 게시된 개인정보 정책으로 설명하지 않는다. 아래 내용은 현재 코드와 검증 범위를 설명하며 법적 게시자, 지원 응답 기한, 플랫폼의 보관 기간이나 인증 안정성을 추정하지 않는다.

## 홈페이지와 첫 사용

HWP Easy는 한글을 설치하지 않고 에이전트로 기존 HWP의 지원하는 본문과 표 셀을 읽고 수정하는 도구입니다. 연결을 설치하고 본인 계정으로 인증한 뒤 HWP를 직접 업로드하세요. 파일 선택만으로 전송하지 않으며 업로드 버튼을 눌러 전송합니다. 채팅 첨부가 자동으로 서버에 전달되는 것은 아닙니다.

파일은 최대 4 MiB이며 본문·표 셀 합계는 최대 40만 UTF-16 단위입니다. 지원하지 않는 문서, 대상, 줄바꿈 추가와 저장 공간 조건은 저장 전에 거부합니다. 수정은 같은 원격 문서의 새 버전으로 저장하며 PC 원본은 바뀌지 않습니다. 이전 버전 복구와 HWP 다운로드를 제공합니다. 중요한 원본과 결과는 내려받아 별도로 보관하세요. 새 문단·표 행·서식 생성과 PDF·DOCX·HWPX 변환을 제공하지 않습니다. 미리보기와 내용 검사만으로 모든 외부 HWP 프로그램의 서식 일치를 보장하지 않습니다. 인증이 만료되면 재연결이 필요할 수 있습니다.

## 개인정보 안내에 포함할 사실

- 사용자가 직접 전송한 HWP 전체 바이트, 편집 후 버전, 선택한 표시 이름을 저장합니다. 문서 ID·버전 ID·해시·시각·재시도 요청 정보와 삭제 기록은 안전한 조회·저장·복구를 위해 처리합니다.
- Sites가 인증한 사용자 ID에서 사이트별 소유자 키를 해시로 생성합니다. 현재 Worker는 플랫폼의 사용자 ID와 이메일 헤더가 모두 있어야 요청을 허용합니다. 이메일 값은 이 소유자 키 계산에 포함하지 않으며 애플리케이션 문서 메타데이터에 이메일을 저장하는 기능은 없습니다. 이 사실이 플랫폼 자체의 계정·로그 처리를 설명하는 것은 아닙니다.
- 전송·저장은 OpenAI Sites의 D1/R2를 사용합니다. 에이전트가 요청한 문서 내용·검사 결과·HWP 회수 바이트는 사용하는 ChatGPT 또는 Codex로 반환됩니다. 사용자가 전달한 허용 파일 호스트의 링크에서는 그 HWP를 가져옵니다. 보관 데이터가 PC에만 있는 서비스로 설명하지 않습니다.
- 애플리케이션은 문서와 이전 버전을 사용자가 명시적으로 삭제할 때까지 보관합니다. 연결 해제나 작업 종료가 문서 삭제를 뜻하지 않습니다. 삭제 요청의 완료·불확실·실패를 구분하며 미참조 객체 정리와 플랫폼 백업의 삭제 기간까지 검증됐다고 약속하지 않습니다.
- 현재 코드에 문서 원문·토큰·쿠키를 별도로 출력하는 애플리케이션 로그 기능은 넣지 않았습니다. 운영자에게 저장소 관리 권한이 있으므로 계정별 도구 접근 보호를 운영자에게도 불가능한 암호화로 설명하지 않습니다. 플랫폼 자체의 접근·운영 로그와 보관 정책은 실제 제공자 정책 확인이 필요합니다.
- 사용자에게 HWP 다운로드·이전 버전 복구·명시적 문서 삭제를 제공하고, 연결 해제와 삭제의 차이를 안내합니다. 개인정보 열람·삭제 등 문의 창구는 게시자가 실제 운영할 연락처를 확정한 뒤 기재합니다.
- 주민등록번호 등 정부 발급 식별자, 의료정보, 결제카드 정보, 비밀번호·API 키·인증 코드가 든 파일은 업로드하지 않도록 전송 전에 안내합니다. 공개 심사와 검증에는 개인정보 없는 합성 문서만 사용합니다.

## 이용 조건 초안에 포함할 내용

사용자는 처리 권한을 가진 HWP만 전송하고 필요한 기존 칸의 편집을 요청합니다. HWP Easy는 지원하는 문서와 텍스트 편집 범위만 처리하며 우회·암호 해제·매크로 실행·자동 제출은 지원하지 않습니다. 지원하지 않는 변경을 임의로 줄이거나 일부만 저장하지 않습니다. 삭제는 사용자가 명시적으로 요청한 해당 문서와 기록된 버전을 대상으로 합니다. 개인정보 정책과 지원 창구를 확인한 뒤 이용하도록 안내합니다. 서비스 요금·구매·구독 약정을 임의 추가하지 않습니다.

## 지원 안내

실제 지원 URL과 게시 주체는 미정입니다. 신고에는 문제 발생 시각, 사용 클라이언트, 고정 오류 코드와 개인정보 없는 최소 재현만 요청합니다. 토큰·쿠키·암호·인증 코드나 개인 HWP를 공개 게시판에 보내도록 요구하지 않습니다. 사이트의 비공개 버그 링크나 OpenAI의 기존 지원건을 HWP Easy 일반 사용자 지원 창구로 대신 기재하지 않습니다.
