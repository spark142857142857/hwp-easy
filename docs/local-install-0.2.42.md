# Codex 설치·새 채팅 검증 — 0.2.42

[설치 절차](local-plugin-installation.md) · [확정 지원 범위](f2-support-0.2.42.md) · [남은 작업](remaining-work.md)

2026년 10월 23일, F2 마감에 사용한 **기존 0.2.42 ZIP을 재생성하지 않고** Codex 설치본을 0.2.25에서 0.2.42로 갱신했다. 실제 새 로컬 채팅에서 설치 스킬을 명시적으로 호출해 세 합성 문서를 편집·같은 파일 저장하고, 부모의 독립 검사 뒤 별도 후속 요청으로 정확히 복구했다. **R1 완료**다.

## 설치와 호출

새 영구 마켓플레이스 폴더를 준비하고 정식 `codex plugin marketplace remove/add`·`plugin add`로 등록 경로와 설치본을 갱신했다. 실제 캐시는 `~/.codex/plugins/cache/hwp-easy/hwp-easy/0.2.42`이며 `installed:true`, `enabled:true`다. 이전 0.2.25 설치 전체 사본과 ZIP을 보관했다.

| 검사 | 결과 |

| 패키지 대조 | 설치된 **25개 파일 전부** 검증 ZIP과 바이트 일치. 실행기·WASM·미리보기 자원 포함 |

## 새 채팅의 실제 편집·복구

| 합성 문서 | 실제 요청과 확인 |
| --- | --- |
| 일반 본문·셀 | 본문 한 곳과 답변 셀을 수정. 셀의 두 줄은 실제 두 HWP 문단이며 이모지·비대상 글/서식 보존 |
| 중첩 표 높이 축소 | 깊이 2의 답변 **65줄→8줄**, 명시적 `content_fit`으로 대상/조상 높이 축소. 실제 **2쪽→1쪽**, 꼬리말·셀 틀·모든 답변 줄·후속 본문 확인 |
| 부동 개체와 표 | 깊이 2의 답변 **8줄→20줄**, `recompute_managed` 흐름 재계산. 그림·BOX 글상자 **부동 상태 유지**, 실제 **1쪽 유지**와 표/개체 비겹침·꼬리말·후속 본문 확인 |

각 파일을 전체 읽고 실제 대상/기대 값을 선택했다. 계획 전후 원본 해시·백업 목록 불변을 확인하고 관련 변경을 묶어 **파일마다 한 번 같은 경로에 저장**했다. 계획/저장의 편집 후보 해시, 저장 경로·출력 해시·재읽기와 원본 백업을 대조했다. 부모의 별도 OLE/원시 레코드 판독으로 글/서식/앵커 순서, 중첩 높이, 그림/글상자·테두리·꼬리말·정의·비대상 스트림을 검사했다.

편집 검사가 끝난 뒤 같은 새 채팅에 **별도 복구 요청**을 보냈다. 세 파일 모두 최초 원본과 **전체 바이트 일치**, 복구 직전 편집본도 별도 백업으로 보존했다. 최종 백업은 **6개**다. 원본·편집본·복구본 **9개 파일·11쪽**을 한글에서 새로 열어 이미지·실제 표시를 확인했고 복구 **4쪽**은 원본과 픽셀이 같았다. 위 쪽 수는 이 세 합성 사례의 결과다.

스킬 발견과 명시적 파일 읽기·실제 모델 실행을 확인했다. 메뉴 클릭이나 선택 참조의 자동 주입은 이번에 검사하지 않았다. 부동 문서의 WASM 렌더에는 편집 전후 모두 겹침 경고 3건이 남았고 실제 한글 이미지의 비겹침과 구분해 보관했다. 이는 F3 표시/좌표 차이의 후속 범위다. 제품의 `layout_verified:false`는 유지하며 해당 사례의 네이티브 QA를 임의 HWP의 인쇄 배치 보증으로 확대하지 않는다. 개인 문서는 사용하지 않았다.

## 자원과 검사 근거

ZIP은 **5,620,740바이트·25개 파일**, SHA-256은 `71eb12337d8f0bf75bb50faa8f7461a898b96c7066419d377df2b3dd9870f32f`다. runner는 `493d1cd6f339f408259f081fb464ab965ed05ac05c72f598dee734961dbd52d4`, `@rhwp/core 0.8.6` WASM은 `8000e4ce320b7994dca6bcd58be0c862144c7b805576504e523a420439da658b`다.

기능 소스 `f767f12666190e2aabcf42e138b55ad861a2ab6b`의 [전체 Windows/Linux CI 18개 작업](https://github.com/spark142857142857/hwp-easy/actions/runs/39925496320)은 성공했다. 이번 설치본의 실행기/패키지 내용이 그 검증 자원과 같음을 대조했다. 이번 변경은 설치·검증 기록/문서이며 엔진·ZIP을 바꾸지 않아 전체 CI를 다시 실행하지 않았다. 이후 문서 커밋을 새 기능 CI 통과로 기록하지 않는다.

요청/응답·설치 메타데이터·원본/편집/복구 HWP·독립 판독·실제 페이지 이미지는 ignored `outputs/codex-0.2.42-20261023/`에 보관한다. `installation.json`, `skill-discovery.json`, `installed-runner/`, `fresh-chat/`, `fresh-native/`, `summary.json`이 근거다. 실행 재현은 [설치 절차](local-plugin-installation.md#개발자가-재현하기)를 따른다. 공개 ZIP·OpenAI 포털·Cloud·다른 사용자 환경은 이번에 갱신/검증하지 않았다.
