# 로컬 HWP Easy 0.2.42 검증 기록

[남은 F2](remaining-work.md#f2-세부-현황) · [지원 기능](supported-features.md#소스-0242-추가-기능) · [프로젝트 상태](project-status.md)

검증일: **2026년 10월 23일**. F2-D2에 명시적 행 높이 축소·빈 공간 정리를 추가한다. 소스·검증 패키지는 0.2.42이며 Codex 실제 설치는 0.2.25, Claude Code·Cursor 설치와 공개 ZIP은 0.2.19다.

## 구현과 지원 경계

`reflow_table.row_height_policy`는 기본 `preserve`와 명시적 `content_fit`를 받는다. 일반 편집은 글을 줄여도 저장된 행/셀 최소 높이를 유지한다. 사용자가 높이·빈 공간 축소를 요청한 경우에만 내용·셀 여백·중첩 표/바깥 여백을 안쪽부터 계산해 선택 루트 전체를 내용에 맞춘다. 가로·세로 병합 셀은 걸친 행의 합을 제약하며, 누적 행 경계의 최장 경로로 모든 제약을 만족하는 최소 총높이를 계산한다. 각 행은 최소 100 HWPUNIT이다. 정규화하는 한 본문 호스트의 복수 루트에도 같은 정책을 전달한다.

저장 높이에는 신뢰할 작성 이력이 없다. 내용 맞춤은 과거 자동 확장뿐 아니라 원래 양식에 의도적으로 지정한 큰 최소 높이도 줄일 수 있다. 사용자 요청 없이 글을 삭제했다는 이유만으로 선택하지 않는다. 문서에 지속되는 설정이 아니며 이후 일반 편집은 축소된 높이에서 필요하면 다시 확장한다. 글과 내용 맞춤을 묶을 때는 글 변경 뒤에 실행하고, 흐름 대상 문단 자체를 바꿨다면 변경 뒤의 `expected_old`를 사용한다. 원본 해시와 전체 표 기대 설정 검사는 유지한다.

열 너비·테두리·여백·가로/세로 정렬·글/글자 서식·필드·이미지와 비대상 스트림을 보존한다. 형제 표 위치도 새 높이로 갱신한다. 부동 배치는 줄어든 루트 높이를 사용하지만 기존 명시적 쪽 나눔은 기본 보존한다. 관리형 빈 앵커의 나눔까지 다시 계산하라는 요청은 `floating_page_breaks:"recompute_managed"`를 조합한다. 이 옵션도 작성 이력 판별 기능은 아니다. 지원 밖 구조·알 수 없는 정책·오래된 기대 설정은 저장 전에 거부한다.

## 남은 범위

F2 핵심 마감은 **대표 양식의 마감 회귀·지원 범위/버전 확정 한 묶음**이다. 추가 필드/앵커·그룹/회전과 불확실한 다중 쪽의 세밀한 공간 재사용은 후속 확장으로 관리한다. 외부 한글과 WASM의 모든 폰트/줄바꿈 일치를 보증하지 않으며 `layout_verified:false`를 유지한다. Claude Code·Cursor와 실제 Codex 설치 갱신·공개 패키지 갱신은 이번 작업에 포함하지 않는다.
