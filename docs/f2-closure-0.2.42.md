# F2 마감 회귀 — 0.2.42

[확정 지원 범위](f2-support-0.2.42.md) · [남은 작업](remaining-work.md) · [0.2.42 구현 기록](local-release-0.2.42.md)

2026년 10월 23일, 제품 엔진을 변경하지 않고 **0.2.42의 F2 핵심 지원 프로필을 마감 검증**했다. 공개 원본은 고정 카탈로그 12개이며 복사본에서만 편집했다. 추가 5건은 같은 공개 원본의 후속 요청이고, 합성 110건은 기능별 시나리오다. 실제 설치·앱별 호출·공개는 별도다.

공개 복합 12건의 네이티브 검사는 전체 쪽 이미지·요청 글 존재·복구 픽셀을 확인한다. 모든 기존 개체의 비겹침을 보증하는 검사는 아니다. 공개 05의 기존 지도 겹침은 후속 위치 이동 사례에서, 표본 10의 F2 장문/축소는 셀 프레임과 원래 글 픽셀 검사에서 별도로 확인했다. 합성 F2는 기능별 실제 답변 줄·셀/상자 틀·그림·후속 본문·꼬리말 검사로 지원 프로필을 검증한다.

## 보완한 검증 도구

기존 공개 회귀가 파생 미리보기 유무까지 포함한 최종 출력 해시만 비교하던 부분을, 다른 F2 검사와 동일한 `verified_edit_sha256` 후보 대조로 맞췄다. 원본 해시·요청 내용·무저장 계획·복구 검사는 유지한다. 공개 중첩 셀의 첫 LF 추가를 독립 원시 판독에서 정확히 허용하고, 꼬리 본문 표식이 없는 원본도 원래 픽셀/셀 프레임·커서 줄로 검사하도록 QA를 확장했다. 제품 엔진 오류는 발견되지 않았다.

전체 CI는 새로 늘어난 F2 패키지가 한 작업에 몰리지 않도록 기존 부동/문자 지표/글 작업에 배분했다. 전체 소스 검사 파일의 중복 횟수와 표 패키지 묶음의 합집합/횟수, **18개 Windows/Linux 실행·기존 시간 제한**은 보존했다. 앱별 설치·모델 호출은 실행하지 않는다. 실제 검사 커밋과 전체 CI 결과는 [Source checks](https://github.com/spark142857142857/hwp-easy/actions/workflows/checks.yml) 및 로컬 `outputs/f2-close-042-20261023/ci-result.json`에서 구분한다.

## 재현과 자원

기존 [개발 가이드](developer-guide.md)의 8개 F2 패키지 검사·독립 판독·네이티브 검사를 사용한다. 공개 복합은 `check-local-compound.mjs`의 명시적 `--short-answers=8,10` 조건, 추가 공개 배치는 `check-local-public-layout.mjs`, 실제 F2 경계/장문/축소는 `check-local-f2-public.mjs <현재 공개 복합 결과> <새 출력 폴더>`로 재현한다. 공개 표본은 [고정 rhwp 커밋](https://github.com/edwardkim/rhwp/tree/1a76570e833917d15817415a53c09ad61ab3203f)의 기존 카탈로그 URL·SHA를 대조했다. 개인 `testdocs`는 사용하지 않았다.

실행 로그·모든 입력/편집/복구 HWP·독립 판독·실제 페이지 이미지는 무시된 `outputs/f2-close-042-20261023/`에 보관한다. `summary.json`, `frozen-package.json`, `ci-coverage-audit.json`이 각각 검증 집계·기존 ZIP/25개 내용 대조·CI 범위 대조 근거다. ZIP·실행기·WASM 해시는 [확정 지원 범위](f2-support-0.2.42.md#확정-자원)를 따른다. 실제 Codex 0.2.25·Claude Code/Cursor 0.2.19·공개 상태는 갱신하지 않았다.

## 마감 판정

**F2 핵심 지원 프로필은 0.2.42에서 완료했다.** 후속 필드/앵커·그룹/회전·다중 쪽 공간 최적화는 별도 확장이고 F3 표시 차이도 남는다. 지원 밖 요청의 안전한 거부를 유지한다. 후속 [Codex 0.2.42 설치·새 채팅 검증](local-install-0.2.42.md)으로 R1도 완료했다. 다음 설치/공개 검증은 다른 사용자 환경(R3)이며 Claude Code·Cursor(D1)는 사용자 요청으로 계속 보류한다.
