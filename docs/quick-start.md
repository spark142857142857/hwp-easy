# HWP Easy 사용 안내

HWP Easy 0.2.18은 에이전트가 접근할 수 있는 HWP를 직접 편집하고 **같은 파일에 저장**하는 메인 패키지다. HWP Easy 서버나 별도 계정, 웹 업로드는 필요하지 않다. 엔진은 패키지에 포함되며 실행 환경에 파일 접근 권한과 Node.js 22 이상이 있어야 한다. Claude Code와 Cursor에서는 `/hwp-easy`로 호출한다. [앱별 설치와 검증](agent-client-skills.md)

## 파일을 지정하고 요청하기

설치한 뒤 새 Codex 채팅의 스킬 메뉴에서 **HWP Easy**를 선택한다. Codex CLI에서는 `$`를 입력한 뒤 `HWP`를 검색하거나 `/skills`에서 선택한다. 정식 등록 이름은 `$hwp-easy:edit-local-hwp`다. 다른 작업에서 자동 적용되지는 않는다. 설치 상태와 검증 범위는 [로컬 설치 안내](local-plugin-installation.md)에 정리했다.

에이전트가 말하는 기본 스킬 목록에 없어도 설치 실패는 아니다. HWP Easy는 자동 호출을 금지하므로 그 목록에서 숨겨진다. 도구로 새 채팅을 만드는 요청에 호출 이름만 넣는 방식과 실제 메뉴 선택은 다르다. 메뉴에서도 검색되지 않으면 [스킬 발견 진단](local-skill-discovery.md)을 따른다.

파일의 실제 경로나 현재 실행 환경에서 접근 가능한 첨부 파일을 지정하고 바꿀 곳과 내용을 말한다.

> $hwp-easy:edit-local-hwp 이 HWP를 끝까지 읽고 질문과 기입할 칸을 정리해줘. 파일은 수정하지 마.

> $hwp-easy:edit-local-hwp 이 HWP의 지원 동기 칸을 아래 내용으로 채우고 같은 파일에 저장해줘. 다른 칸은 유지해줘.

> $hwp-easy:edit-local-hwp 이 보고서의 두 번째 본문 문단을 아래 내용으로 바꾸고 같은 파일에 저장해줘.

에이전트는 대상과 기존 내용, 파일 버전을 확인하고 저장 가능한지 먼저 검사한다. 여러 수정을 함께 요청하면 전부 검사한 뒤 한 번 저장하며, 한 작업이 실패하면 일부만 저장하지 않는다. 같은 문구가 여러 위치에 있을 때는 표의 위치나 앞뒤 내용을 함께 알려 준다.

PC의 원본 경로를 지정하면 해당 파일을 바꾼다. 첨부 사본을 지정하면 현재 실행 환경의 첨부 사본을 바꾼다. 첨부만으로 PC 원본을 자동으로 찾아 덮어쓰지는 않는다. Cloud 작업에서도 그 작업에 전달된 파일을 처리하며 PC 파일과 자동 동기화하지 않는다.

## 저장한 파일 확인하기

에이전트가 실제 저장한 경로와 변경 내용을 알려 준다. 읽기, 검색, 미리보기와 저장 전 계획만 수행하면 파일을 저장하지 않는다. 편집은 같은 파일 저장이 기본이며 다른 이름으로 저장하려면 그렇게 요청한다.

저장 전에 원래 파일을 옆의 `.hwp-easy-backups` 폴더에 복구용으로 보관한다. 다른 프로그램이나 작업이 파일을 바꿨다면 오래된 버전의 저장을 거부한다. 변경할 내용이 없으면 새 저장이나 복구 사본을 만들지 않는다.

기본 SVG 미리보기와 저장 후 재읽기로 내용을 확인할 수 있다. 지원 여부는 문서 구조에 따라 달라지며 최종 쪽 배치가 외부 HWP 뷰어와 정확히 같다는 인증은 아니다. [지원 범위와 문서별 조건](local-file-editing.md)을 참고한다.

복잡한 문서는 확인 가능한 본문만 읽기 전용으로 보여줄 수 있다. 이 경우 빠진 개체 내용과 편집 제한을 안내하며, 문서 전체를 읽거나 수정할 수 있다고 표시하지 않는다. 기본 미리보기는 현재 파일 내용으로 만들지만 파일에 내장된 미리보기 텍스트·썸네일은 갱신하지 않는다.

## 이전 내용으로 복구하기

같은 파일을 지정해 복구 이력을 확인하거나 되돌릴 시점을 말한다.

> $hwp-easy:edit-local-hwp 이 HWP의 복구 이력을 보여줘. 아직 복구하지 마.

> $hwp-easy:edit-local-hwp 이 HWP를 방금 수정하기 직전 내용으로 복구해줘.

에이전트는 선택한 파일의 검증된 복구 사본을 확인해 같은 경로로 복구한다. 복구할 때도 현재 파일을 보관하므로 복구 직전의 편집본을 다시 되살릴 수 있다. 다른 파일의 사본이나 손상된 복구 파일은 사용하지 않는다. 복구 폴더를 지우면 그 안의 이전 버전은 복구할 수 없다.

## 보관한 원격 방식

원격 0.1.9는 기본 설치에서 제외했다. 서버 업로드와 다운로드를 사용하는 기존 방식이 필요하면 [원격 사용 기록](remote-quick-start.md)과 [기존 출시 기록](public-plugin-release.md)을 참고한다. 이번 메인 전환은 운영 사이트 종료, 원격 문서 삭제나 심사 철회를 수행한 작업이 아니다.
