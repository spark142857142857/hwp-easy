# HWP Easy 사용 가이드

[프로젝트 개요](../README.md) · [문서 인덱스](README.md) · [지원 기능](supported-features.md)

HWP Easy 0.2.19의 스킬 호출, 파일 지정, 편집·저장·복구 절차입니다. 실행 환경에는 Node.js 22 이상과 파일 접근 권한이 필요합니다. 클라이언트별 설치 상태는 [프로젝트 상태](project-status.md)에 기록합니다.

<a id="1-앱에서-스킬을-호출하세요"></a>

## 스킬 호출

| 클라이언트 | 호출 방법 | 설치 안내 |
| --- | --- | --- |
| Codex | 스킬 메뉴에서 **HWP Easy** 선택. CLI에서는 `$` 입력 후 `HWP` 검색 | [Codex 설치](local-plugin-installation.md) |
| Claude Code | `/hwp-easy` 입력 또는 스킬 선택 | [개인 스킬 설치](agent-client-skills.md) |
| Cursor | `/hwp-easy` 입력 또는 스킬 선택 | [개인 스킬 설치](agent-client-skills.md) |

스킬은 명시적으로 호출한 작업에만 적용됩니다. 일반 작업이나 스킬의 설명·설치 요청으로 문서 편집이 자동 실행되지 않습니다.

<a id="파일을-지정하고-요청하기"></a>
<a id="2-어떤-파일을-바꿀지-지정하세요"></a>

## 파일 지정

대상 HWP의 실제 경로와 수정 위치, 새 내용을 함께 지정합니다. 같은 문구가 여러 곳에 있으면 표 위치나 주변 문장으로 대상을 구분합니다.

| 입력 | 저장 대상 |
| --- | --- |
| PC에서 접근 가능한 원본 경로 | 해당 경로의 HWP |
| 채팅에 전달한 첨부 사본 | 에이전트 실행 환경의 첨부 사본 |
| Cloud 작업에 전달한 파일 | 해당 Cloud 환경의 파일 |

첨부 사본과 Cloud 파일은 PC 원본과 자동 동기화되지 않습니다. 새 Cloud 작업에서 로컬 메인을 사용하는 전체 흐름은 추가 검증 대상입니다.

<a id="3-먼저-읽거나-바로-수정을-요청하세요"></a>

## 편집 요청

Codex에서는 HWP Easy를 선택한 뒤 요청합니다. Claude Code·Cursor에서는 아래 요청 앞에 `/hwp-easy`를 붙입니다.

### 내용 조회

```text
C:\문서\지원서.hwp를 읽고 질문과 작성할 칸을 정리해줘. 파일은 수정하지 마.
```

### 표 셀 수정

```text
C:\문서\지원서.hwp의 지원 동기 칸을 "지역사회 문제를 해결하는 경험을 쌓고 싶습니다."로 채우고 같은 파일에 저장해줘. 다른 칸은 유지해줘.
```

### 본문과 글자 서식 수정

```text
C:\문서\보고서.hwp의 두 번째 본문 문단을 "이번 분기 목표는 상담 대기 시간 단축입니다."로 바꾸고, 바꾼 문장만 굵게 해줘. 같은 파일에 저장해줘.
```

에이전트는 대상·기존 내용·현재 파일 버전을 확인하고 저장 전 검사를 수행합니다. 여러 수정은 전체 검사를 통과한 뒤 한 번 저장하며, 한 작업이라도 실패하면 일부만 저장하지 않습니다. 작업별 편집 조건은 [지원 기능과 제한](supported-features.md)을 따릅니다.

<a id="저장한-파일-확인하기"></a>
<a id="4-저장-결과를-확인하세요"></a>

## 저장

기본 저장 대상은 지정한 파일의 원래 경로입니다. 별도 사본 저장은 “다른 이름으로 저장해줘” 등 명시적인 요청에만 수행합니다. 읽기·검색·미리보기·계획 검사만 수행하면 파일을 저장하지 않습니다.

저장 결과에는 실제 경로와 변경 내용이 포함됩니다. 현재 내용은 재읽기와 기본 미리보기로 확인합니다. 파일에 내장된 썸네일과 최종 쪽 배치의 제한은 [미리보기 안내](supported-features.md#미리보기와-최종-배치)를 참조하세요.

이전 바이트는 파일 옆의 `.hwp-easy-backups`에 보관합니다. 다른 프로그램이나 작업이 현재 파일을 바꾼 경우 오래된 버전의 저장을 거부합니다. 실제 변경이 없으면 저장과 새 백업을 만들지 않습니다.

<a id="이전-내용으로-복구하기"></a>
<a id="5-이전-내용으로-복구하세요"></a>

## 복구

같은 파일의 이력을 조회하고 복구할 버전을 지정합니다.

```text
C:\문서\지원서.hwp의 복구 이력을 보여줘. 아직 복구하지 마.

C:\문서\지원서.hwp를 방금 수정하기 전 내용으로 복구해줘.
```

복구 시 현재 편집본도 보관하므로 해당 편집본을 다시 복구할 수 있습니다. 복구 폴더를 삭제하면 그 안의 이전 버전은 복구할 수 없습니다.

<a id="막히면-어디를-보면-되나요"></a>

## 문제 해결

| 증상 | 확인 사항 |
| --- | --- |
| Codex 기본 스킬 목록에 항목 없음 | 명시적 선택 메뉴에서 검색합니다. 메뉴에도 없으면 [호출 진단](local-skill-discovery.md)을 확인합니다. |
| 일부 읽기 전용 결과 | [지원 제한](supported-features.md#지원-제한과-읽기-전용-처리)을 확인합니다. 일부 개체 내용이 누락될 수 있습니다. |
| 파일 버전 충돌 | 최신 파일을 다시 읽고 변경 의도에 맞는 새 계획을 생성합니다. |
| 쪽 배치·글꼴 차이 | [미리보기와 최종 배치](supported-features.md#미리보기와-최종-배치)의 검증 범위를 확인합니다. |
