# HWP Easy 처음 사용하기

[프로젝트 소개](../README.md) · [문서 안내](README.md) · [지원 기능](supported-features.md)

HWP Easy로 **파일을 읽고 → 수정 내용을 요청하고 → 같은 파일에 저장하고 → 필요하면 복구**하는 방법입니다. 현재 로컬 메인은 0.2.18이며 HWP Easy 서버나 웹 업로드가 필요하지 않습니다.

## 1. 앱에서 스킬을 호출하세요

| 앱 | 시작 방법 | 설치 관련 안내 |
| --- | --- | --- |
| Codex | 새 채팅의 스킬 메뉴에서 **HWP Easy** 선택. CLI에서는 `$`를 입력하고 `HWP` 검색 | [Codex 설치 상태](local-plugin-installation.md) |
| Claude Code | `/hwp-easy` 입력 또는 스킬 선택 | [개인 스킬 설치](agent-client-skills.md) |
| Cursor | `/hwp-easy` 입력 또는 스킬 선택 | [개인 스킬 설치](agent-client-skills.md) |

스킬은 호출한 작업에만 적용됩니다. 실행 환경에 파일 접근 권한과 Node.js 22 이상이 필요합니다. 배포 준비 상태는 [현재 상태](project-status.md)를 확인하세요.

<a id="파일을-지정하고-요청하기"></a>

## 2. 어떤 파일을 바꿀지 지정하세요

파일 경로와 바꿀 곳, 넣을 내용을 함께 알려 주세요. 같은 문구가 여러 곳에 있으면 표의 위치나 주변 문장도 설명합니다.

| 지정한 파일 | 실제로 바뀌는 파일 |
| --- | --- |
| PC에서 접근 가능한 원본 경로 | 그 경로의 HWP |
| 채팅에 전달된 첨부 사본 | 현재 실행 환경의 첨부 사본 |
| Cloud 작업에 전달한 파일 | 해당 Cloud 환경의 파일 |

첨부 사본이나 Cloud 파일이 PC 원본과 자동으로 동기화되지는 않습니다. 새 Cloud 작업에서 로컬 메인을 사용하는 전체 흐름은 아직 별도 검증 대상입니다.

## 3. 먼저 읽거나 바로 수정을 요청하세요

스킬을 선택한 뒤 아래와 같이 요청합니다. Claude Code·Cursor에서는 요청 앞에 `/hwp-easy`를 붙입니다.

**내용부터 확인하기**

> C:\문서\지원서.hwp를 읽고 질문과 작성할 칸을 정리해줘. 파일은 수정하지 마.

**답변 작성하기**

> C:\문서\지원서.hwp의 지원 동기 칸을 “지역사회 문제를 해결하는 경험을 쌓고 싶습니다.”로 채우고 같은 파일에 저장해줘. 다른 칸은 유지해줘.

**본문과 서식 바꾸기**

> C:\문서\보고서.hwp의 두 번째 본문 문단을 “이번 분기 목표는 상담 대기 시간 단축입니다.”로 바꾸고, 바꾼 문장만 굵게 해줘. 같은 파일에 저장해줘.

에이전트는 대상·기존 내용·현재 파일 버전을 확인하고 저장 전 검사를 합니다. 여러 수정은 모두 검사를 통과한 뒤 한 번 저장합니다. 한 작업이라도 실패하면 일부만 저장하지 않습니다.

<a id="저장한-파일-확인하기"></a>

## 4. 저장 결과를 확인하세요

저장 뒤에는 실제 저장 경로와 바뀐 내용을 확인합니다. 기본 미리보기와 재읽기로 현재 내용을 확인할 수 있습니다.

같은 파일 저장이 기본입니다. 별도 사본이 필요하면 “다른 이름으로 저장해줘”라고 요청하세요. 읽기·검색·미리보기·계획 검사만 요청하면 파일을 저장하지 않습니다.

이전 바이트는 파일 옆의 `.hwp-easy-backups`에 보관합니다. 다른 프로그램이나 작업이 파일을 바꾸면 오래된 버전으로 덮어쓰지 않고 충돌을 알립니다. 변경할 내용이 없으면 새 저장이나 백업을 만들지 않습니다.

<a id="이전-내용으로-복구하기"></a>

## 5. 이전 내용으로 복구하세요

같은 파일을 지정하고 먼저 이력을 확인하거나 되돌릴 시점을 말합니다.

> C:\문서\지원서.hwp의 복구 이력을 보여줘. 아직 복구하지 마.

> C:\문서\지원서.hwp를 방금 수정하기 전 내용으로 복구해줘.

복구할 때도 현재 편집본을 보관하므로 그 편집본을 다시 복구할 수 있습니다. 복구 폴더를 삭제하면 그 안의 이전 버전을 되살릴 수 없습니다.
