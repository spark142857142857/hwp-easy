# HWP Easy 사용 안내

**현재 원격 처리 제한:** 원격 서버에는 본문과 표 셀의 합산 길이 최대 40만 단위(예: 😀는 2단위, 👩‍💻는 5단위)가 적용됩니다. 한도를 넘는 파일이나 한도를 넘기는 수정·복구는 저장하지 않습니다. 기존 문서와 이전 버전은 유지됩니다. 같은 요청을 반복하거나 재인증해도 이 제한은 해결되지 않습니다. 120만 자 파일의 서버 CPU 초과를 막기 위한 제한이며, 한도 이내의 모든 양식이 처리된다는 보장은 아닙니다. 2026년 10월 6일 운영 버전 45에 반영했고 실제 기능 조회에서 제한을 확인했습니다. 정확한 경계 크기의 모든 양식 저장·조판은 검증하지 않았습니다.

현재 계정에서 사용하는 소유자 전용 비공개 MVP입니다. Codex Desktop의 실제 연결에서 HWP 가져오기·전체 조회·편집·저장·복구·다운로드를 확인했습니다. 대표 45셀 합성 양식의 셀 수정·빈칸 채우기·비우기와 기본 미리보기도 확인했습니다. Codex Cloud는 고정 합성 HWP로 검증한 범위이며, 임의 지원서나 복잡한 양식의 호환성과 정확한 서식·페이지 배치는 아직 검증하지 않았습니다.

## 파일을 올리고 요청하기

1. 연결된 HWP Easy와 같은 계정으로 [HWP 업로드 화면](https://hwp-easy-runtime-probe.spark142857.chatgpt.site/documents/upload)을 엽니다.
2. `.hwp` 파일을 선택하고 **업로드**를 누릅니다. 파일은 최대 4 MiB이며, 선택만으로 업로드되지는 않습니다. 지원하지 않거나 손상된 파일은 저장하지 않습니다.
3. 저장된 버전의 보기 화면에서 **링크와 읽기 요청 복사**를 누르고, HWP Easy가 연결된 에이전트 대화에 붙여 넣습니다. 자동 복사가 안 되면 **요청 확인 · 직접 복사**에서 선택된 내용을 복사하세요. 이 주소는 공개 공유 링크가 아니며 같은 계정의 접근 권한이 필요합니다.

복사한 요청은 지금 보고 있는 저장본을 끝까지 읽고 요약하도록 요청하며 파일을 수정하지 않습니다. 변경하고 싶은 내용은 대화에서 이어서 요청하세요. 이전 저장본에서 복사하면 그 이전 버전을 읽습니다. 현재 파일을 수정하려는 경우 **현재 저장본 보기**를 먼저 열어 주세요.

예를 들어 다음처럼 요청할 수 있습니다. `[보기 링크]`를 실제 주소로 바꿔 주세요.

> HWP Easy로 [보기 링크]의 지원하는 내용을 끝까지 읽고 요약해줘. 읽지 못한 부분이 있으면 알려줘. 파일은 수정하지 마.

> HWP Easy로 [보기 링크]의 표에서 ‘지원 동기’에 해당하는 셀을 찾아 아래 내용으로 바꿔줘. 다른 부분은 유지하고 같은 문서에 저장해줘. 저장된 버전의 보기 링크와 HWP 다운로드를 알려줘.

같은 문구가 여러 곳에 있으면 표의 위치나 앞뒤 내용을 함께 지정하세요. 에이전트는 지원 대상과 현재 버전을 확인하고, 내용을 안전하게 보존할 수 없는 수정은 저장하지 않습니다. 요약과 글 작성은 사용 중인 에이전트가 담당합니다.

## 결과 확인과 이전 버전

보기 링크를 놓쳤다면 같은 계정으로 [내 문서](https://hwp-easy-runtime-probe.spark142857.chatgpt.site/documents)를 열어 다시 찾으세요. 마지막 저장 시각 순으로 표시하며, 20개를 넘으면 **이전 문서 더 보기**로 이어 볼 수 있습니다. 문서를 열면 목록을 조회한 시점의 현재 저장본으로 이동합니다.

**이름이나 문서 번호로 찾기**에 직접 붙인 이름의 일부나 문서 번호를 입력하면 같은 계정의 문서에서 찾습니다. 검색 결과가 20개를 넘으면 같은 검색어로 다음 목록을 이어 볼 수 있습니다. **검색 지우기**로 전체 목록으로 돌아갑니다. HWP 본문과 원래 파일 이름은 검색하지 않습니다.

보기 화면의 **문서 이름 설정**에서 구분하기 쉬운 이름을 80자 이내로 붙일 수 있습니다. 이름을 비우면 짧은 문서 번호로 표시합니다. 직접 입력한 이름만 문서와 함께 보관하고 원래 파일 이름은 자동 수집하지 않습니다. 이름 변경은 HWP 내용과 저장 버전을 바꾸지 않습니다. 다른 화면에서 이미 이름을 바꿨다는 안내가 나오면 화면을 새로 열어 확인한 뒤 변경하세요.

에이전트가 반환한 **저장된 버전의 보기 링크**에서 수정 결과와 기본 미리보기를 확인하고 HWP를 내려받습니다. 기존 보기 링크는 그 버전을 계속 보여 주므로, 후속 수정 후에는 새 결과 링크를 열어 주세요. 현재 버전 표시와 저장 시각으로 구분할 수 있습니다.

보기 화면에는 **이 저장본의 편집 가능 범위**가 표시됩니다. 본문과 표 셀 안의 문단별로 편집 후보와 읽기 전용 대상을 구분하고, 혼합 서식이나 미지원 구조 등 읽기 전용인 이유를 알려줍니다. 후보로 표시돼도 요청한 수정의 저장 전 검사를 통과해야 저장할 수 있습니다. 표 셀에 문단이 여러 개 있으면 각각을 별도 대상으로 셉니다. 이 화면을 보는 것만으로 문서가 수정되지는 않습니다.

서로 다른 글자 서식이 섞인 문단도 안내된 후보에서 제한적으로 치환할 수 있습니다. 예를 들어 굵은 `성명: ` 뒤의 `김철수`를 `홍길동`으로 바꾸고 기존 서식은 유지합니다. 한 서식 구간 안에서 글자 수와 각 위치의 문자 길이를 유지해야 하며, 이모지를 일반 한 글자로 바꾸는 수정도 거부됩니다. 거부되면 기존 저장본을 유지하고 내용을 임의로 줄이거나 일부만 저장하지 않습니다. 같은 요청을 반복하기보다 안내된 제한을 확인하세요.

이미 저장된 버전이 새 처리 한도를 넘는 경우에도 처리 제한 안내 화면에서 **이 버전 HWP 다운로드**와 **저장 버전** 목록을 사용할 수 있습니다. 그 저장본의 내용 조회·편집·미리보기와 읽기 요청 복사는 제공하지 않습니다. 내려받은 HWP를 외부 HWP 프로그램에서 확인하거나, 목록에서 처리 가능한 다른 저장본을 선택하세요. 기존 문서·버전은 유지되며 화면을 보는 것만으로 복구하거나 일부 저장하지 않습니다. 운영 버전 45에 반영했습니다. 새 화면의 실제 로그인 브라우저 검증은 남아 있습니다.

브라우저에서 내려받는 HWP 파일 이름에는 문서 번호와 저장본 번호가 들어갑니다. 서로 다른 버전이 같은 `document.hwp` 이름으로 구분 없이 저장되는 일을 줄입니다. 직접 붙인 문서 이름은 목록과 보기 화면의 표시 이름입니다.

이전 버전으로 돌아가고 싶으면 해당 보기 링크를 전달하며 다음처럼 요청하세요.

> HWP Easy로 이 문서의 이전 버전을 확인하고, [되돌릴 버전의 보기 링크]의 내용으로 같은 문서를 복구해줘. 복구 결과 링크를 알려줘.

이전 버전과 복구 전 버전은 유지됩니다. 원격 문서에 저장해도 PC 원본은 자동으로 바뀌지 않습니다. 내려받은 HWP의 세부 서식과 최종 제출 상태는 사용할 수 있는 외부 HWP 뷰어에서도 확인해 주세요. 기본 미리보기로 정확한 페이지 배치까지 확인한 것은 아닙니다.

빈 칸에 긴 답변을 넣으면 표와 문서의 페이지 수가 늘어날 수 있습니다. 저장과 내용 보존 검사를 통과해도 제출 페이지 제한을 충족했다는 뜻은 아닙니다. 분량 제한이 있다면 결과를 확인하고 필요한 수정 내용을 따로 요청하세요. 에이전트가 문구를 임의로 줄이거나 일부만 저장하지 않습니다.

## 업로드가 끝났는지 불확실할 때

연결이 끊기거나 응답이 늦어 완료 여부를 확인하지 못한 경우, **같은 화면에서 같은 파일로 재시도**하세요. 화면을 새로 고침하거나 파일을 다시 선택하면 요청 정보가 사라져 새 문서가 만들어질 수 있습니다. 같은 화면의 재시도는 기존 업로드 요청을 이어 확인합니다.

업로드가 꺼졌거나 인증이 필요하다는 안내가 나오면 먼저 해당 상태를 해결하세요. 미지원·손상 파일은 반복 업로드로 해결되지 않습니다.

현재 앱 연결에서 인증 갱신 중 재연결이 필요한 경우를 반복 확인했습니다. 인증 업데이트 안내가 나오면 다음 절차로 기존 계정을 다시 연결하세요.

1. ChatGPT 웹의 **플러그인**에서 설치된 **HWP Easy**의 관리 화면을 열고, **연결된 계정**의 **다시 연결**을 선택합니다.
2. HWP Easy 연결 안내에서 계속한 뒤 기존 계정의 로그인과 추가 인증을 인증 창에서 완료합니다. 비밀번호와 인증 코드는 AI 대화에 보내지 않습니다.
3. 재연결이 끝나면 에이전트에게 **“HWP 기능을 읽기 전용으로 한 번 조회해 줘”**라고 요청해 현재 연결을 확인하고 이어서 작업합니다.

이 절차는 2026년 10월 9일 기존 계정으로 재연결한 뒤 기능 조회·합성 저장본 조회·HWP 회수로 확인했습니다. 기능 조회 성공은 현재 연결이 복구됐다는 뜻이며 자동 갱신 문제가 해결됐다는 증거는 아닙니다. 원인은 아직 확인하지 못했습니다. 인증 오류만으로 저장 성공·실패를 판단하지 말고, 저장 결과가 불확실하면 재연결 후 기존 요청과 버전 기록을 확인하세요.

## 파일과 조회 내용의 보관

선택한 HWP와 저장된 이전 버전은 원격 문서 저장소에 업로드되어 직접 삭제할 때까지 보관됩니다. 작업 종료나 시간 경과로 자동 삭제하지 않습니다. 에이전트가 조회한 문서 내용은 요청한 AI 앱으로 전달됩니다.

문서별로 최대 128개 버전을 저장합니다. 한도에 도달하면 추가 수정·복구 저장을 거부하고 기존 버전을 유지합니다. 버전 충돌 안내가 나오면 최신 저장본을 다시 읽고 수정 내용을 재확인하세요. 응답 유실로 저장 결과만 불확실하다면 에이전트가 기존 요청을 그대로 재확인해야 합니다. 자동 삭제나 무조건 새 요청으로 반복 저장하지 않습니다.

중요한 원본과 완료본은 HWP로 내려받아 별도 보관하세요. 이전 버전 복구는 원격 저장소의 버전 복구 기능이며, 서비스 전체 장애에 대한 별도 백업·재해 복구를 보장하지 않습니다. 운영 미게시 파일 정리와 비용·성능 한도 검증은 남아 있습니다.

삭제하려면 문서 보기 링크를 지정해 HWP Easy에 삭제를 요청하세요. 삭제 작업은 그 문서의 저장된 버전을 함께 삭제하며 복구 기능으로 되돌릴 수 없습니다. 완료·정리 상태는 삭제 응답에서 확인해야 합니다. 이미 다운로드한 파일과 AI 대화에 전달된 내용까지 삭제하는 기능은 아닙니다.

본문과 최상위 표 셀이 첫 지원 범위입니다. 이름 있는 필드, 중첩 표, 머리말·꼬리말, 이미지 편집과 글자 서식 자체의 변경은 지원하지 않습니다. 기존 혼합 서식을 유지하는 치환은 위의 제한 안에서만 제공합니다. Dots는 MVP에서 제외한 추후 확장 항목입니다. 상세 검증 범위는 [연결 상태](codex-cloud.md), 개발 계약은 [원격 문서 안내](remote-documents.md)를 참고하세요.
