# 원격 HWP Easy 0.1.9 사용 기록

[문서 안내](README.md) · [현재 로컬 사용법](quick-start.md) · [현재 상태](project-status.md)

**보관한 원격 0.1.9의 서버 사본 사용 기록**입니다. 아래 업로드·다운로드는 현재 로컬 메인과 다른 흐름입니다.

2026년 10월 12일 로컬 0.2.15를 메인으로 정했다. 이 문서는 보관한 원격 0.1.9의 서버 사본 편집 방법이다. 현재 기본 사용법은 [HWP Easy 사용 안내](quick-start.md)를 참고한다.

아래는 당시 비공개 연결의 사용 방법입니다. 원격 플러그인의 제출·검증 이력은 [출시 기록](public-plugin-release.md)에 보관했습니다.

## 파일을 올리고 요청하기

1. HWP Easy에 연결한 계정으로 [HWP 업로드 화면](https://hwp-easy-runtime-probe.spark142857.chatgpt.site/documents/upload)을 엽니다.
2. `.hwp` 파일을 선택하고 **업로드**를 누릅니다. 파일을 선택하기만 하면 업로드되지 않습니다.
3. 저장본의 보기 화면에서 **링크와 읽기 요청 복사**를 누르고 에이전트 대화에 붙여 넣습니다. 자동 복사가 안 되면 **요청 확인 · 직접 복사**를 사용하세요.

보기 링크에는 같은 계정의 접근 권한이 필요합니다. 복사한 요청은 지금 보고 있는 버전을 읽고 요약하며 파일을 수정하지 않습니다. 이전 버전을 보고 있다면 **현재 저장본 보기**를 먼저 열어 주세요.

`[보기 링크]`를 실제 주소로 바꿔 다음처럼 요청할 수 있습니다.

> HWP Easy로 [보기 링크]의 지원하는 내용을 끝까지 읽고 요약해줘. 읽지 못한 부분이 있으면 알려줘. 파일은 수정하지 마.

> HWP Easy로 [보기 링크]의 표에서 ‘지원 동기’에 해당하는 셀을 찾아 아래 내용으로 바꿔줘. 다른 부분은 유지하고 같은 문서에 저장해줘. 저장된 버전의 보기 링크와 HWP 다운로드를 알려줘.

같은 문구가 여러 곳에 있으면 표의 위치나 앞뒤 내용을 함께 알려 주세요. 에이전트는 대상과 기존 내용, 현재 버전을 확인한 뒤 수정본을 검사합니다. 여러 곳을 함께 수정하다가 하나가 거부되면 나머지만 저장하지 않습니다.

원격 처리에는 다음 제한이 있습니다.

| 항목 | 범위 |
| --- | --- |
| 파일 크기 | 최대 4 MiB |
| 본문과 표 셀 길이 | 합계 400,000 UTF-16 단위. 😀는 2단위, 👩‍💻는 5단위로 계산됩니다. |
| 텍스트 수정 | 지원하는 기존 문단의 문구 교체, 검증된 빈 셀 채우기와 비우기 |
| 혼합 서식 수정 | 한 서식 구간 안에서 글자 수와 각 위치의 문자 길이를 유지하는 치환 |
| 줄바꿈 | 새 줄바꿈과 문단 추가는 지원하지 않습니다. 기존 셀의 여러 문단은 각각 지정해 수정할 수 있습니다. |

한도 안의 파일도 문서 구조에 따라 지원하지 않을 수 있습니다. 한도를 넘는 파일이나 수정, 복구는 저장하지 않고 기존 버전을 유지합니다. 지원하지 않는 문자나 빈 셀의 탭 입력이 거부되면 넣을 내용과 위치를 다시 정해 주세요. 에이전트가 줄바꿈을 없애거나 답변을 임의로 줄이지는 않습니다.

채팅 첨부를 가져오다가 `FILE_URL_NOT_ALLOWED`가 나오면 브라우저 업로드를 사용하세요. 허용되지 않은 파일 전달 주소를 받기 전에 차단한 오류이므로 재인증이나 반복 호출로 해결되지 않습니다. 업로드 화면에서도 손상 또는 미지원 안내가 나오면 그 파일은 저장할 수 없습니다.

## 결과 확인과 이전 버전

저장 후 에이전트가 반환한 **저장된 버전의 보기 링크**를 열어 결과를 확인하고 HWP를 내려받습니다. 기존 링크는 계속 이전 버전을 보여 주므로 후속 수정 뒤에는 새 링크를 사용하세요. 원격 저장은 PC 원본을 바꾸지 않습니다.

링크를 놓쳤다면 [내 문서](https://hwp-easy-runtime-probe.spark142857.chatgpt.site/documents)에서 찾을 수 있습니다.

- 문서는 마지막 저장 시각 순으로 표시합니다. 20개를 넘으면 **이전 문서 더 보기**를 누릅니다.
- **이름이나 문서 번호로 찾기**에는 직접 붙인 이름의 일부나 문서 번호를 입력합니다. 본문과 원래 파일 이름은 검색하지 않습니다. **검색 지우기**로 전체 목록으로 돌아갈 수 있습니다.
- 보기 화면의 **문서 이름 설정**에서 80자 이내의 이름을 붙입니다. 이름을 비우면 짧은 문서 번호를 표시합니다. 이름 변경은 HWP 내용과 버전을 바꾸지 않습니다.
- **이 저장본의 편집 가능 범위**에서 문단별 편집 후보와 읽기 전용인 이유를 확인합니다. 후보로 표시돼도 요청한 수정의 저장 전 검사는 필요합니다.
- **일부 내용만 읽을 수 있습니다**가 표시되면 에이전트가 지원하는 본문과 표 셀만 읽습니다. 그림이나 도형 등 읽지 못한 내용은 내려받은 HWP에서 확인하세요.

이미 저장한 버전이 처리 한도를 넘으면 내용 조회와 편집, 미리보기는 제공하지 않습니다. 안내 화면의 **이 버전 HWP 다운로드**와 **저장 버전** 목록은 사용할 수 있습니다. 다른 버전을 보는 것만으로 문서가 복구되거나 수정되지는 않습니다.

내려받는 파일 이름에는 문서 번호와 버전 번호가 들어갑니다. 직접 붙인 문서 이름은 목록과 보기 화면에 표시하며 원래 파일 이름은 자동 수집하지 않습니다.

이전 내용으로 되돌리려면 복구할 버전의 링크를 지정하세요.

> HWP Easy로 이 문서의 이전 버전을 확인하고, [되돌릴 버전의 보기 링크]의 내용으로 같은 문서를 복구해줘. 복구 결과 링크를 알려줘.

복구 전 버전과 선택한 이전 버전은 유지됩니다. 기본 미리보기는 내용 확인용입니다. 긴 답변을 넣으면 표가 커지거나 페이지가 늘어날 수 있고, 페이지 수가 같아도 간격과 배치는 달라질 수 있습니다. 제출할 파일은 외부 HWP 뷰어에서 글꼴과 표, 줄바꿈, 페이지 제한도 확인하세요. 자세한 시험 결과는 [양식 검사](first-form-check.md)에 있습니다.

## 업로드가 끝났는지 불확실할 때

연결이 끊기거나 응답이 늦어 결과를 확인하지 못했다면 **같은 화면에서 같은 파일로 재시도**하세요. 기존 요청의 결과를 다시 확인합니다. 이후 오류가 나왔다고 해서 앞선 업로드까지 실패했다고 판단할 수는 없습니다.

화면은 기존 파일과 요청을 유지하고 파일 선택을 잠급니다. **내 문서를 새 창에서 확인**하면 재시도 화면을 유지하면서 저장본을 찾을 수 있습니다. 새로고침하거나 창을 닫으면 요청 정보를 잃으므로 새 업로드 전에 내 문서부터 확인하세요. 원래 파일 이름은 보관하지 않으므로 저장 시각과 문서 번호, 내용을 함께 확인해야 합니다.

**업로드 완료는 확인했지만 저장본 화면을 열지 못했습니다**가 나오면 재업로드하지 말고 내 문서에서 찾으세요. 첫 시도에서 명확한 입력 제한이나 미지원 안내를 받았다면 다른 파일을 선택할 수 있습니다. 결과가 불확실했던 요청은 기존 화면에서 이어 확인해야 합니다.

인증이 필요하면 같은 계정을 새 창에서 다시 연결한 뒤 기존 요청으로 돌아옵니다.

1. ChatGPT 웹의 **플러그인**에서 HWP Easy 관리 화면을 열고 **연결된 계정**의 **다시 연결**을 선택합니다.
2. 기존 계정의 로그인과 추가 인증을 인증 창에서 마칩니다. 비밀번호와 인증 코드는 대화에 보내지 마세요.
3. 에이전트에게 **“HWP 기능을 읽기 전용으로 한 번 조회해 줘”**라고 요청하고 연결이 확인되면 작업을 이어갑니다.

이 절차로 연결이 복구된 사례는 있지만 자동 갱신 문제는 아직 조사 중입니다. 인증 오류만으로 저장 성공이나 실패를 판단하지 말고, 재연결 후 기존 요청과 버전 기록을 확인하세요.

## 파일과 조회 내용의 보관

업로드한 HWP와 이전 버전은 직접 삭제할 때까지 서버에 보관합니다. 대화 종료나 시간 경과, 연결 해제로 자동 삭제되지 않습니다. 에이전트가 읽은 내용은 사용하는 AI 앱으로 전달됩니다.

문서별로 최대 128개 버전을 저장합니다. 한도에 도달하면 추가 편집과 복구 저장을 거부하고 기존 버전을 유지합니다. 버전 충돌이 나면 최신 저장본을 다시 읽고 수정 내용을 확인하세요.

저장과 삭제의 응답은 다음처럼 구분합니다.

| 안내 | 할 일 |
| --- | --- |
| **저장 완료 여부를 확인하지 못했습니다** | 이미 저장됐을 수 있습니다. “중복 저장하지 말고 방금 요청을 그대로 다시 확인해줘”라고 요청합니다. 기존 요청을 잃었거나 파일 또는 수정 내용이 바뀌었다면 문서와 버전 기록부터 확인합니다. |
| 삭제 **완료 여부 불확실** | 삭제와 접근 차단이 완료됐다고 판단하지 않습니다. “이미 요청한 삭제만 그대로 이어 확인해줘. 다른 문서는 건드리지 마”라고 요청합니다. |
| 삭제 **버전 정리 미완료** | 새 조회와 저장은 차단됐지만 기록된 버전의 제거가 끝나지 않았습니다. 같은 삭제 요청을 이어 확인합니다. |

복구 기능은 서버에 보관된 이전 버전으로 돌아가는 기능입니다. 서비스 전체 장애에 대비한 백업을 보장하지 않으므로 중요한 원본과 완료본은 따로 보관하세요.

삭제하려면 문서 보기 링크를 지정해 요청합니다. 해당 문서와 저장된 버전을 함께 삭제하며 복구 기능으로 되돌릴 수 없습니다. 완료 응답을 확인해야 하며, 이미 내려받은 파일과 AI 대화에 전달한 내용은 삭제되지 않습니다.

원격 MCP의 첫 지원 범위는 본문과 최상위 표 셀입니다. 이름 있는 필드, 중첩 표, 머리말과 꼬리말, 이미지 편집, 글자 서식 변경은 지원하지 않습니다. Dots는 추후 검토할 기능입니다. 데이터 처리 조건은 [개인정보처리방침](privacy-policy.md), 자세한 동작과 검증 기록은 [원격 문서 안내](remote-documents.md)와 [연결 상태](codex-cloud.md)를 참고하세요.
