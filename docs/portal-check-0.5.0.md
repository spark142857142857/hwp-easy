## 차단 항목

> We are not accepting more skills-only submissions at this time.

현재 포털이 스킬 전용 제출을 접수하지 않는다는 제한입니다. 이번 ZIP의 이름이나 엔진 코드 오류로 안내된 항목은 아닙니다. 이 표시만으로 모든 계정의 접수가 중단됐는지, 현재 제출자에게 적용되는 자격 제한인지까지 단정하지 않습니다. 확인한 공개 안내에는 이 문구의 구체적인 해제 조건이 없었습니다.

패키지는 [데스크톱 전용 스킬 안내](https://developers.openai.com/plugins/deploy/desktop-only)에 따라 `extensions.com.openai.requires_local_executor:true`를 포함합니다. MCP 서버는 포함하지 않습니다. 공개 문서의 로컬 MCP 허용 목록 절차를 이 스킬 전용 접수 제한의 확정 해결책으로 제시하지 않습니다.
