# 로컬 HWP Easy 0.2.27 글상자 이동·크기 조정

[남은 작업](remaining-work.md) · [지원 기능](supported-features.md) · [프로젝트 상태](project-status.md)

2026년 10월 18일, F4의 남은 범위 중 **본문·셀·중첩 셀의 단순 사각형 글상자 위치·크기 변경**을 공통 로컬 실행기에 추가했다. 소스·분리 검증 패키지는 **0.2.27**이며 실제 Codex 설치는 **0.2.25**, Claude Code·Cursor 설치와 공개 ZIP은 **0.2.19**다. 이번 기록은 실제 앱 설치·모델 호출·공개 게시와 구분한다.

## 구현 범위

`read`의 `text_boxes[].geometry_editable`이 참인 글상자에 `transform_text_box`를 사용할 수 있다. 상자 자체의 대상 ID, 전체 `expected_properties`·`expected_flow`, 상자가 속한 블록의 전체 텍스트를 확인하고 요청한 폭·높이·가로/세로 위치만 변경한다. 글상자 내부 문단을 편집하는 `splice_text_box`와 대상·사전 조건이 다르다.

지원 조건은 **절대 크기·위/왼쪽 정렬·회전/뒤집기 없는 사각형**이며, 공통 개체 헤더·도형 크기·행렬·사각형 꼭짓점이 서로 일치해야 한다. 회전·확대 행렬·인라인·그룹 내부 등 검증하지 못한 프레임은 텍스트 읽기·지원 텍스트 편집과 구분하여 기하 변경을 거부한다.

- 폭·높이는 1–720000, 위치는 -720000–720000 범위의 정수 HWP 단위로 명시한다.
- 원시 텍스트·글자 서식·상자 채움/테두리·기준/감싸기·표 구조·다른 개체를 보존한다. 관련 줄 배치 캐시와 문서 미리보기 캐시는 갱신한다.
- 앞선 문단 삽입으로 표의 위치가 바뀌어도 최초 읽기의 상자·문단 대상을 묶음 안에서 추적한다. 마지막 작업이 실패하면 전체를 저장하지 않는다.
- 셀의 단을 기준으로 왼쪽 정렬한 절대 폭 글상자는 셀 가로 경계를 검사한다. `TEXT_BOX_EXCEEDS_CELL_WIDTH`·`TEXT_BOX_EXCEEDS_CELL_LEFT_BOUNDARY`를 보고하며 `reject_new_overflow`는 새 위험을 저장·백업 전에 거부한다. 종이 기준 셀 개체에 같은 셀 경계를 적용하지 않는다.
- 값이 같은 요청은 파일·백업을 만들지 않는다. 변경 요청은 같은 파일 저장과 이전 바이트의 복구를 사용한다.

전체 요청 계약은 [스킬 요청 참조](../plugins/hwp-easy/skills/edit-local-hwp/references/requests.md)에 있다. 스킬의 명시적 호출 전용 정책은 유지한다.

## 남은 배치 범위

명시한 도형 위치·크기를 변경하는 기능이며 **자동 크기 맞춤·주변 개체 회피·중첩 표 쪽 분할은 아니다.** 셀 높이를 넘어 크게 만든 부동 상자가 주변 본문을 덮을 수 있고, 외부 한글은 내용에 따라 상자를 늘려 표시할 수 있다. 원시 높이 저장과 외부 뷰어의 실제 표시 높이를 동일한 보증으로 취급하지 않는다.

셀·중첩 셀의 세로 경계·주변 본문 겹침 진단은 **I2**, 다단·셀·다른 쪽의 자동 재배치는 **F1**, 장문 중첩 표의 자동 분할은 **F2**에 남긴다. 그룹/상자 안 글상자와 추가 필드·개별 하위 그룹도 F4의 미완료 범위다. `layout_verified:false`를 유지한다.
