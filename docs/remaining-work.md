# 남은 작업

[프로젝트 상태](project-status.md) · [지원 기능](supported-features.md) · [문서 인덱스](README.md)

갱신일: **2026년 10월 23일 · 소스·검증 패키지 0.2.44**

**이번 완료: F3-B1 — 단일 중첩 체인의 표시 원점·접두부·상위 셀 정렬.** 소스·검증 패키지 **0.2.44**에서 깊이 2/3·위/가운데/아래 정렬·한국어 접두부·부동 개체 조합을 보완했다. 관련 회귀 177개, 분리 번들/독립 판독 9건, 실제 한글 27개 파일·27쪽과 SVG 표 경계 44곳·답변 108줄·복구 9쪽 픽셀을 확인했다. 원본의 부동 상태·문단 수·셀 정렬·정의를 보존한다. **F3-B 전체는 부분 완료**이며 복수 형제/복잡 호스트는 F3-B2에 남긴다. [검증 기록](local-release-0.2.44.md)

**이전 완료: R1 — Codex 0.2.42 실제 설치·새 채팅의 편집·같은 파일 저장·별도 복구.** 설치 25개 파일 ZIP 대조, 합성 3개 실제 모델 편집과 정확한 원본 복구·독립 판독·네이티브 확인을 완료했다. [설치 검증](local-install-0.2.42.md)

**이전 완료: F2 핵심 마감 회귀·지원 범위 확정.** F2 핵심 지원 범위의 확정 버전은 **0.2.42**다. 공개 원본 12개·추가 공개 요청 5건·합성 110건, 총 **127건**의 저장/복구·독립 판독과 실제 한글 **381개 상태 파일·758쪽**, 복구 **207쪽** 픽셀 대조를 통과했다. [마감 검증](f2-closure-0.2.42.md) · [확정 지원 범위](f2-support-0.2.42.md)

**F2 핵심 미완료 항목은 0개다.** 확정한 구조에서 장문·병합/중첩·꼬리말·후속 동기화·부동 배치·명시적 높이 축소를 완료했다. 모든 HWP의 자유 편집을 뜻하지 않는다. 추가 필드·앵커·그룹/회전과 불확실한 다중 쪽의 세밀한 공간 재사용은 아래 **후속 확장**으로 관리한다. 공개 표본에서도 글 편집 가능 범위와 전체 표 흐름 가능 범위를 구분했다.

**다음 기능 작업: F3-B2 — 복수 형제 표·복잡한 호스트·분할된 루트의 표시 원점.** 이어서 F3-C의 좁은 셀 내부 여백 축소·폰트/줄바꿈/쪽 계산, F3-D의 꼬리말/추가 진단을 진행한다. 설치·공개에서는 후속 R1(0.2.44)·다른 사용자 환경(R3)·공개 준비(R4·R5)가 남는다. 실제 Codex는 **0.2.42**, Claude Code·Cursor와 공개 ZIP은 **0.2.19**다. Claude Code·Cursor(D1)는 계속 보류하고 추가 외국어/이모지 조형(D3)은 최후순위를 유지한다.

## 우선 처리할 오류와 개선

B1·B2·I1은 **0.2.26**, B3와 I2의 지원 프로필은 **0.2.28 소스·검증 패키지에서 완료**했다. Codex 실제 설치·호출은 R1의 0.2.42에서 완료했고 Claude Code·Cursor는 D1로 보류한다.

- [x] **B1:** 저장 게시 전·후 강제 종료와 잠금 게시 도중 종료 후 재개·복구. 살아 있는 소유자 보호·동시 회수 경쟁 검사 통과. **소유자 없는 이전 형식 잠금의 자동 회수는 제외**하며 R3에서 판별·안내를 확인한다.
- [x] **B2:** 같은 문단의 그림 간 새 넘침 교환을 엄격 정책에서 거부. 번호 변경과 삭제 후 재삽입을 구분하고 무저장·백업 수 불변 확인.
- [x] **I1:** 하단 고정 글상자 20줄의 새 추정 위험을 경고하고 `reject_new_risk`에서 거부. 짧은 안내 저장·정확한 복구 확인. 다른 기준·내부 여백·자동 크기 조정은 후속 범위다.
- [x] **B3:** 24바이트 z-order를 고유 ID로 사용하던 오류를 36바이트 인스턴스 ID로 정정. 새 그림에 중복 없는 실제 ID를 할당하고 기존 0/중복 ID는 미확인으로 유지. 표시 순서와 구분·원래 B2 보호 회귀 확인.
- [x] **I2 지원 프로필:** 셀 첫 문단의 지원 사각형에서 세로 경계·긴 내용·일반 본문 겹침과 일반 셀 흐름 기반 위험을 구분해 보고. 새/악화 위험 엄격 거부·정상 짧은 편집·문단 삽입 후 대상 추적·같은 파일 저장·복구 검증. 종이/쪽 기준·내부 여백·불명확한 중첩 식별 등은 `inconclusive`와 F3의 추가 범위로 유지.
- [x] **CI 검사 재분산 반영:** Windows 표 흐름의 10분 예산 초과를 확인해 기존 셀 그림 검사를 짧은 패키지 작업으로 옮김. 검사 명령·18개 전체 행렬·시간/요청 제한은 유지하고 변경한 4개 OS 작업은 `package-balance` 범위로 검증. 엔진·0.2.44 ZIP은 그대로이며 실제 CI 커밋/결과는 [검증 기록](local-release-0.2.44.md#검증-결과)을 따름.

재현·설계·예외·검증 근거는 [0.2.26 기록](local-release-0.2.26.md)과 [0.2.28 기록](local-release-0.2.28.md)을 따른다. 원래 0.2.25 리뷰는 발견 당시의 이력으로 보관한다.

0.2.42는 `reflow_table`로 표 전체 흐름을 조정하고 완전한 흐름 프로필의 후속 편집을 최종 저장 전에 자동 동기화한다. 지원 밖의 장문 중첩 표는 계속 경고/엄격 거부하며, 답변 축약·글꼴 축소로 잘림을 숨기지 않는다. [지원 경계](supported-features.md#소스-0242-추가-기능)

0.2.42 설치에서 확인한 부동 문서의 WASM 겹침 경고 3건은 **F3-A 0.2.43 지원 프로필에서 0건으로 보완**했다. 중첩 원점·상위 정렬은 0.2.44 단일 체인에서 보완했다. 복수 형제/복잡 호스트·글꼴/표 높이·꼬리말 차이는 남으며 저장·복구 성공을 배치 진단 완성으로 처리하지 않는다. [변경과 한계](local-release-0.2.43.md)
