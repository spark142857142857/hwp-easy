# 남은 작업

[프로젝트 상태](project-status.md) · [지원 기능](supported-features.md) · [문서 인덱스](README.md)

갱신일: **2026년 10월 27일 · 소스·검증 후보 0.5.0-dev.1**

**I3 회전 그룹 글 표시를 확정 범위에서 완료했다.** 루트/하위 그룹의 글 누락·잘못된 원점·셀 경계 잘림·가운데/아래 정렬을 보완했다. 합성 20종의 편집·같은 파일 저장·정확한 복구와 실제 한글 배치를 대조했다. [범위와 검증](local-release-0.5.0-dev.1.md). 실제 Codex 설치는 0.2.51이며 이번에 갱신하지 않았다.

**최종 공개 버전은 0.5.0을 목표로 한다.** 현재 0.5.0-dev.1은 개발·검증 후보다. 남은 설치/배포 검증을 마친 뒤 직관적인 이름을 결정하고 저장소·패키지 명칭을 함께 변경한 다음 플러그인 심사를 진행한다. 이름은 아직 정하지 않았다.

**F4 추가 개체 편집을 한 묶음으로 마감했다.** 그룹/상자 내부 글·서식·문단, 개별 하위 그룹 변형, 추가 필드 표시값/속성 편집을 구현했다. [F4 확정 범위](f4-support-0.2.51.md)와 [0.2.51 검증 기록](local-release-0.2.51.md)을 따른다.

**F3의 핵심 지원 범위를 통합 마감했다.** 일상 문장/서식·빈 누름틀 안내·행 내부 쪽 이어짐·자동 다단·꼬리말/후속 본문을 함께 보완하고, 같은 파일 저장·정확한 복구와 실제 한글을 대조했다. 세부 항목을 계속 쪼개 진행하는 방식은 종료한다. 적용 조건과 지원 밖의 구조는 [F3 확정 범위](f3-support-0.2.50.md), 실행 결과는 [0.2.50 검증 기록](local-release-0.2.50.md)을 따른다.

**GitHub Actions는 사용자가 명시적으로 요청할 때만 실행한다.** 주요 단계 완료·버전 갱신·push 자체는 실행 허가가 아니다. 이번 작업에서는 실행하지 않았다. CI가 없다는 사실과 로컬 검사 통과를 구분한다.

- [x] **B1·B2 / 0.2.26:** 중단 저장 잠금 회수·개체별 새 넘침 비교. 소유자 없는 이전 형식 잠금의 자동 회수는 제외.
- [x] **B3 / 0.2.28:** z-order와 실제 인스턴스 ID 구분·새 그림 ID 할당.
- [x] **I1·I2:** 지원 글상자 장문/경계/본문 겹침 진단. F3에서 표시·추정 범위를 추가 보완.

## 관리 기준과 이전 기록

개선 묶음의 코드·테스트·배포·문서는 **한 의미 있는 커밋**으로 올린다. 기존 공개 이력은 유지한다. CI는 명시 요청 때만 실행하고, 평소에는 적절한 로컬 검사를 사용한다. 원격 보관본·실제 클라이언트를 요청 없이 갱신하지 않는다.

이전 세부 번호·당시 미완료 항목·CI 실행 결과는 [0.2.49까지의 보관 기록](remaining-work-history-20261027.md)에 남겼다. 현재 완료 판단에는 [F3 확정 범위](f3-support-0.2.50.md)와 최신 검증 기록을 사용한다.
