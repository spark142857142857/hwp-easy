2026년 10월 28일 기준입니다. **B7 수정과 0.5.2 패치 배포를 완료했습니다.** 세 앱 설치와 공개 패키지의 저장 및 복구를 확인했고, 문서의 현재 안내와 과거 기록을 분리했습니다.

## 남은 항목

| 항목 | 상태 | 다음 조건 |
| --- | --- | --- |
| OpenAI 디렉터리 | 외부 접수 제한으로 대기 | 접수 가능 여부를 확인한 뒤 최신 배포본 설명과 정책을 검토하고 심사 신청 |
| 실제 사용에서 발견한 오류 | 상시 대응 | 지원하는 구조에서 재현되는 사례가 나오면 합성 회귀를 추가해 수정 |
| Cloud 전체 흐름 | 후순위 | 실제 환경의 파일 전달, 편집과 결과 회수를 검증할 때 재개 |
| 추가 문자 조형 | 최후순위 | 아랍어, 인도계, 태국어, ZWJ 이모지 등이 실제로 필요할 때 검토 |

새 필수 기능을 계속 추가하는 단계는 아닙니다. 표와 개체의 지원 밖 구조는 [지원 조건](reference/support.md)을 따르며, 실제 필요와 재현 자료를 기준으로 확장합니다.

## 완료 및 제외

F1부터 F4와 I3, B1부터 B7의 확정 범위 수정, 세 앱 공통 설치와 GitHub 및 npm 공개를 완료했습니다. [최신 검증](verification.md)에 이번 결과와 제한을 기록합니다.

다른 PC와 새 사용자 검증은 사용자 요청으로 생략했습니다. Cursor IDE 채팅은 필수 검사에서 제외합니다. 스킬은 명시 호출 전용이며 원격 0.1.9는 보관 상태입니다.

GitHub Actions는 평소 수동 실행 전용입니다. 이번 패치는 사용자 허용으로 실행했으며 다음 작업의 자동 실행 허가로 이어지지 않습니다. 변경은 개선 항목별로 묶고 기존 공개 Git 이력은 유지합니다.

이전 세부 번호와 버전별 진행 상황은 [이전 기록](archive/README.md)에서 찾을 수 있습니다.
