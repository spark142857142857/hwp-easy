# 남은 작업

[프로젝트 상태](project-status.md) · [지원 기능](supported-features.md) · [문서 인덱스](README.md)

갱신일: **2026년 10월 18일 · 소스·검증 패키지 0.2.26**

**B1·B2 수정과 I1 진단 보완을 0.2.26 소스·분리 패키지에서 완료했다.** 같은 파일 저장·정확한 복구·독립 판독·대표 네이티브 확인을 통과했다. 실제 Codex 설치는 아직 0.2.25다. 다음 순서는 **0.2.26 설치·새 채팅(R1) → 다른 사용자 설치(R3) → 공개 준비(R4)**다. [0.2.26 검증 기록](local-release-0.2.26.md), [원래 리뷰](code-review-2026-10-18.md)를 참조한다.

## 우선 처리할 오류와 개선

세 항목 모두 **0.2.26 소스·검증 패키지에서 완료**했다. 실제 앱 설치·호출 갱신은 R1에 남긴다.

- [x] **B1:** 저장 게시 전·후 강제 종료와 잠금 게시 도중 종료 후 재개·복구. 살아 있는 소유자 보호·동시 회수 경쟁 검사 통과. **소유자 없는 이전 형식 잠금의 자동 회수는 제외**하며 R3에서 판별·안내를 확인한다.
- [x] **B2:** 같은 문단의 그림 간 새 넘침 교환을 엄격 정책에서 거부. 번호 변경과 삭제 후 재삽입을 구분하고 무저장·백업 수 불변 확인.
- [x] **I1:** 하단 고정 글상자 20줄의 새 추정 위험을 경고하고 `reject_new_risk`에서 거부. 짧은 안내 저장·정확한 복구 확인. 다른 기준·내부 여백·자동 크기 조정은 후속 범위다.

재현·설계·예외·검증 근거는 [0.2.26 기록](local-release-0.2.26.md)을 따른다. 원래 0.2.25 리뷰는 발견 당시의 이력으로 보관한다.

## 아직 구현하지 않은 기능 범위

F1–F4의 **기존 대표 프로필은 완료**했다. 이 표에는 그 이후에 남은 범위만 적는다.

| ID | 상태 | 남은 범위 | 완료 기준 |
| --- | --- | --- | --- |
| F1 | 미완료 | 다단·셀 안·다른 쪽으로의 부동 개체 재배치 | 대상·좌표·내용을 보존하며 실제 배치와 저장·복구 확인. 의도한 겹침의 자동 판정은 범위를 먼저 결정 |
| F2 | 미완료 | **중첩 표 장문의 자동 쪽 분할**, 복잡한 꼬리말·문단 기준 고정 개체 | 잘림 없이 본문을 이어 쓰고 고정 개체 위치 보존. 현재 장문 위험 거부를 자동 분할 완료로 취급하지 않음 |
| F3 | 미완료 | WASM과 외부 한글의 폰트·꼬리말 간격·쪽 계산 차이 | 재현 사례별 진단 정확도 검증. 불확실한 경우 `inconclusive`, `layout_verified:false` 유지 |
| F4 | 미완료 | 그룹/상자 내부 글상자·추가 필드·개별 하위 그룹, 셀 글상자 이동·크기 조정 | 구조별 읽기·편집 계약과 비대상 보존·저장·복구·배치 확인 |

F2의 장문 중첩 표는 기본 정책에서 경고하고, `reject_new_risk`를 선택하면 새로운 추정 위험을 저장 전에 거부한다. 제품이 답변을 자동으로 줄이거나 표를 자동 분할하는 기능은 아직 없다. [지원 경계](supported-features.md#codex-0225-추가-기능)

## 완료한 작업

- [x] **공통 로컬 실행:** 한 Node/WASM 엔진, 서버·한글 설치 없이 실행, 스킬은 명시적 호출만 적용. [아키텍처](architecture.md)
- [x] **기본 저장·복구:** 같은 파일 저장, 이전 바이트 보관, 버전 충돌 거부, 무변경 무저장, 원자적 묶음 편집. 0.2.26의 중단 잠금 회수는 지원하는 새 형식에서 완료했고 이전 형식은 자동 회수하지 않음. [파일 편집](local-file-editing.md)
- [x] **R1의 이전 단계 — Codex 0.2.25 실제 설치·새 채팅:** 10월 15일 25개 설치 파일 ZIP 대조, 합성 3개 편집·같은 파일 저장·별도 요청 복구, 독립 판독·네이티브 확인. 10월 18일 설치 runner의 저장·복구 재검사도 통과. [설치 기록](local-release-0.2.25.md#codex-설치와-새-채팅-검증)
- [x] **R2 — 공개·합성 양식 검증:** 공개 12개·배치 보완 3건·합성 15건, 같은 파일 저장·정확한 복구·독립 판독. 기존 네이티브 90개 파일·237쪽, 복구 76쪽 픽셀 일치. 장문 중첩 표의 자동 분할은 F2에 남음. [검증 기록](local-release-0.2.25.md)
- [x] **F1–F4 대표 프로필:** 같은 쪽 단일 단 본문 부동 개체 이동, 단순 고정 하단 보호, 배치 불확실성 표시, 본문·셀·중첩 셀의 단순 사각형 글상자 편집. 추가 범위는 위 기능 표를 따름. [지원 기능](supported-features.md)

버전별 상세 변경 이력은 [0.2.20](local-release-0.2.20.md) · [0.2.21](local-release-0.2.21.md) · [0.2.22](local-release-0.2.22.md) · [0.2.23](local-release-0.2.23.md) · [0.2.24](local-release-0.2.24.md) · [0.2.25](local-release-0.2.25.md) · [0.2.26](local-release-0.2.26.md)에 보관한다.

## 최근 점검과 관리 기준

10월 18일 0.2.26: Node/WASM **498개 통과**, Python **291개 실행·4개 건너뜀**, 새 분리 패키지 **4건**과 기존 배치 **15건**의 저장·복구·독립 판독 통과. 새 패키지 네이티브 **12개 파일·12쪽**, 복구 **4쪽** 픽셀 일치. [검증 상세](local-release-0.2.26.md)

현재 소스는 0.2.26, 실제 Codex 설치는 0.2.25, Claude Code·Cursor 설치와 공개 ZIP은 0.2.19다. 0.2.26 [기능 CI](https://github.com/spark142857142857/hwp-easy/actions/runs/39110409969)는 10월 18일 자동 실행 중단 방침에 따라 취소 요청했으며, 이전 `e593a0c`의 CI 10개 작업은 성공했다. 다음 전체 CI는 [주요 단계에서 수동 실행](developer-guide.md#검사)한다. 취소한 실행이나 이번 로컬 검사를 새 Linux CI 통과 또는 새 채팅 검사로 기록하지 않는다.

제품 범위와 결정은 [PRD](PRD.md), 현재 제공 기능은 [지원 기능](supported-features.md), 배포·설치 상태는 [프로젝트 상태](project-status.md)를 기준으로 한다. 새 검증은 날짜·버전·완료 기준을 함께 남기고 기존 근거를 덮어쓰지 않는다. 원격 0.1.9는 보관하며 HWPX·PDF·DOCX 변환은 제품 범위 밖이다. 독립 GUI·설치 프로그램은 현재 확정한 작업이 아니다.
