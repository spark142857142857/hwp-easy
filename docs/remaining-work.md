# 남은 작업

[프로젝트 상태](project-status.md) · [지원 기능](supported-features.md) · [문서 인덱스](README.md)

갱신일: **2026년 10월 18일 · 소스·검증 패키지 0.2.30**

**0.2.30에서 깊이 2·3 중첩 셀의 지원 사각형 재배치를 추가했다.** HWP 단·본문 문단 기준과 조상 표/셀 여백·앞선 글 폭을 계산해 부동 상태·내용·서식을 유지한다. 엄격 정책의 같은 파일 저장·정확한 복구와 대표 한글 배치를 확인했다. **현재 WASM SVG·썸네일의 중첩 원점 차이는 남아** 투영 좌표와 표시 불확실성을 구분한다. 후속 행·가운데 정렬·병합·복잡한 표/개체 등은 계속 미완료다. 실제 Codex 설치는 0.2.25다. [0.2.30 검증 기록](local-release-0.2.30.md)

## 우선 처리할 오류와 개선

B1·B2·I1은 **0.2.26**, B3와 I2의 지원 프로필은 **0.2.28 소스·검증 패키지에서 완료**했다. 실제 앱 설치·호출 갱신은 R1에 남긴다.

- [x] **B1:** 저장 게시 전·후 강제 종료와 잠금 게시 도중 종료 후 재개·복구. 살아 있는 소유자 보호·동시 회수 경쟁 검사 통과. **소유자 없는 이전 형식 잠금의 자동 회수는 제외**하며 R3에서 판별·안내를 확인한다.
- [x] **B2:** 같은 문단의 그림 간 새 넘침 교환을 엄격 정책에서 거부. 번호 변경과 삭제 후 재삽입을 구분하고 무저장·백업 수 불변 확인.
- [x] **I1:** 하단 고정 글상자 20줄의 새 추정 위험을 경고하고 `reject_new_risk`에서 거부. 짧은 안내 저장·정확한 복구 확인. 다른 기준·내부 여백·자동 크기 조정은 후속 범위다.
- [x] **B3:** 24바이트 z-order를 고유 ID로 사용하던 오류를 36바이트 인스턴스 ID로 정정. 새 그림에 중복 없는 실제 ID를 할당하고 기존 0/중복 ID는 미확인으로 유지. 표시 순서와 구분·원래 B2 보호 회귀 확인.
- [x] **I2 지원 프로필:** 셀 첫 문단의 지원 사각형에서 세로 경계·긴 내용·일반 본문 겹침과 일반 셀 흐름 기반 위험을 구분해 보고. 새/악화 위험 엄격 거부·정상 짧은 편집·문단 삽입 후 대상 추적·같은 파일 저장·복구 검증. 종이/쪽 기준·내부 여백·불명확한 중첩 식별 등은 `inconclusive`와 F3의 추가 범위로 유지.

재현·설계·예외·검증 근거는 [0.2.26 기록](local-release-0.2.26.md)과 [0.2.28 기록](local-release-0.2.28.md)을 따른다. 원래 0.2.25 리뷰는 발견 당시의 이력으로 보관한다.

## 아직 구현하지 않은 기능 범위

F1–F4의 **기존 대표 프로필은 완료**했다. 아래에서 추가한 완료 범위와 아직 남은 범위를 구분한다.

| ID | 상태 | 남은 범위 | 완료 기준 |
| --- | --- | --- | --- |
| F1 | **부분 완료** | **완료:** 균등 다단·일반 셀·깊이 2·3 첫 행 중첩 사각형, 같은 구역 다른 쪽 앵커 이동. **남음:** 후속 행/문단·가운데 정렬·병합·추가 표/개체, 셀/구역 간 이동·비균등 다단·의도한 겹침 판단 | 지원 중첩 프로필은 0.2.30의 엄격 저장·복구·대표 네이티브 확인 완료. 추가 구조별 원점·내용 흐름 검증과 지원 확장 필요. 확실하지 않은 배치는 저장 전 거부 |
| F2 | 미완료 | **중첩 표 장문의 자동 쪽 분할**, 복잡한 꼬리말·문단 기준 고정 개체 | 잘림 없이 본문을 이어 쓰고 고정 개체 위치 보존. 현재 장문 위험 거부를 자동 분할 완료로 취급하지 않음 |
| F3 | 미완료 | WASM과 외부 한글의 폰트·꼬리말 간격·쪽 계산 차이, 중첩 셀 SVG/썸네일의 표시 원점 차이. I2의 종이/쪽 기준·셀 후속 문단·내부 여백·불명확한 중첩 식별 추가 프로필 | 재현 사례별 진단 정확도 검증. 관측/추정 위험과 네이티브 좌표를 구분하고 불확실한 경우 `inconclusive`, `layout_verified:false` 유지 |
| F4 | 부분 완료 | 그룹/상자 내부 글상자·추가 필드·개별 하위 그룹은 미완료. 단순 본문·셀·중첩 셀 사각형의 명시적 이동·크기 변경은 0.2.27 완료 | 남은 구조별 읽기·편집 계약과 비대상 보존·저장·복구·배치 확인. 자동 배치·자동 크기 맞춤과 구분 |

F2의 장문 중첩 표는 기본 정책에서 경고하고, `reject_new_risk`를 선택하면 새로운 추정 위험을 저장 전에 거부한다. 제품이 답변을 자동으로 줄이거나 표를 자동 분할하는 기능은 아직 없다. [지원 경계](supported-features.md#codex-0225-추가-기능)

현재 소스는 0.2.30, 실제 Codex 설치는 0.2.25, Claude Code·Cursor 설치와 공개 ZIP은 0.2.19다. 0.2.26 [기능 CI](https://github.com/spark142857142857/hwp-easy/actions/runs/39110409969)는 10월 18일 자동 실행 중단 방침에 따라 취소 요청했으며, 이전 `e593a0c`의 CI 10개 작업은 성공했다. 다음 전체 CI는 [주요 단계에서 수동 실행](developer-guide.md#검사)한다. 이번 0.2.30 단계에서는 CI를 실행하지 않았다. 취소한 실행이나 로컬 검사를 새 Linux CI 통과 또는 새 채팅 검사로 기록하지 않는다.

제품 범위와 결정은 [PRD](PRD.md), 현재 제공 기능은 [지원 기능](supported-features.md), 배포·설치 상태는 [프로젝트 상태](project-status.md)를 기준으로 한다. 새 검증은 날짜·버전·완료 기준을 함께 남기고 기존 근거를 덮어쓰지 않는다. 원격 0.1.9는 보관하며 HWPX·PDF·DOCX 변환은 제품 범위 밖이다. 독립 GUI·설치 프로그램은 현재 확정한 작업이 아니다.
