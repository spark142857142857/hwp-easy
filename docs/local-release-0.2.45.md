# 로컬 HWP Easy 0.2.45 검증 기록

[남은 F3](remaining-work.md#f3-세부-현황) · [지원 기능](supported-features.md#소스-0245-추가-기능) · [프로젝트 상태](project-status.md)

검증일: **2026년 10월 23일**. **F3-B2의 형제 표·복수 문단 호스트·행 경계 루트 분할**을 보완한다. 소스·검증 패키지는 **0.2.45**, 실제 Codex 설치는 **0.2.42**, Claude Code·Cursor 설치·공개 ZIP은 **0.2.19**다. 실제 앱 설치·로그인·모델 호출과 공개/포털 갱신은 진행하지 않았다.

## 변경

고정 WASM 렌더러는 같은 깊이의 형제 표를 글자 폭만큼 오른쪽에 표시하고, 여러 문단 호스트의 가운데/아래 정렬에서 중첩 표 높이를 빠뜨렸다. 쪽마다 분할된 루트의 셀 번호가 0부터 다시 시작해 원래 셀과 다른 대상으로 보일 수도 있었다. 단일 체인의 깊이를 식별자로 쓰던 렌더 매핑을 원시 경로·제어 순서·격자·쪽별 행/열 경계의 대조로 교체했다.

일회용 입력에서 형제 표를 원래 순서대로 세로 배치하고, 지원 평문/빈 앵커의 높이와 마지막 줄의 간격을 구분해 상위 셀 정렬을 반영한다. 행 경계 분할은 원래 셀 번호와 표 ID를 복원한다. 기존 빈 부동 앵커 보정 후에도 식별을 다시 대조한다. 편집 대상·저장·복구는 원본에서 처리하며 임시 공백/문단·여백/정렬·추가 정의를 HWP에 저장하지 않는다.

## 지원 조건과 미완료 범위

| 구분 | 범위 |
| --- | --- |
| 형제 표/복수 루트 | 한 구역·가로·한 단, 최대 16개 표·깊이 3, 확인 가능한 격자와 정규화된 부동 표. 원래 제어 순서·전체 경로로 구분 |
| 복수 문단 호스트 | 위/가운데/아래 정렬, 지원 단일 크기 접두부 64자 이하. 여러 문단 정렬은 줄바꿈이 없는 검증 가능한 평문 폭/높이로 제한 |
| 행 경계 분할 | 기존 `pageBreak:1`의 완전한 행/셀 단위 분할. 쪽별 행·열과 전체 셀 포괄을 확인하고 원래 셀 ID로 복원. 시험 편집은 기존 큰 높이 안에서 수행 |
| B2 추가 범위 미완료 | 필드/다른 개체가 섞인 셀 호스트, 다단, 반복 행/부분 행, 모호한 제어 순서·폭/정렬 프로필 |
| F3-C 미완료 | `pageBreak:2`에서 한 행의 글이 두 쪽에 이어지는 경우, 글꼴/좁은 셀 내부 여백·혼합 크기·줄바꿈/쪽 계산 |
| F3-D 미완료 | 표 뒤 빈 문단·후속 본문의 세로 간격, 고정 꼬리말 간격과 추가 개체/좌표 기준 |

기존 `reflow_table`의 줄 단위 이어짐은 `pageBreak:2`를 사용한다. 이번 표시 보정이 이를 행 단위 분할로 바꾸지 않는다. 실제 한글에서 한 행이 나뉘는데 WASM은 통째로 다음 쪽에 놓는 사례를 재현했으며, 이를 완전한 행 분할로 간주하지 않고 원래 뷰/미지원 이유를 유지한다. **F3-B 전체와 F3-C/D는 아직 완료가 아니다.** 추가 외국어/이모지 조형은 계속 D3 최후순위다.

`render_nested_tables`/`render_unadapted_tables` 및 `NESTED_TABLE_RENDER_ADAPTED`/`NESTED_TABLE_RENDER_UNVERIFIED`로 적용과 한계를 구분한다. `diagnostics_complete:false`, `layout_verified:false`를 유지하며 미리보기 경계의 일치를 전체 인쇄 배치 인증으로 취급하지 않는다.

전체 CI는 기존 **18개 OS 실행·시간 제한·개별 요청 제한**을 유지한다. 기존 F3-A 패키지 검사를 표 흐름 작업으로 분산하고 새 B2 패키지는 짧은 기존 패키지 작업에 넣었다. 기존 검사 명령을 삭제하지 않고 새 소스/패키지 검사를 추가했다. CI의 Claude Code/Cursor 패키지 작업은 합성 파일/생성 번들 검사이며 실제 앱을 갱신하거나 호출하지 않는다. 실제 설치 트리 해시와 이전 0.2.44 ZIP의 불변을 확인했고 computer-use는 **0회**다.
