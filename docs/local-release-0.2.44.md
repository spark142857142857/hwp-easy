# 로컬 HWP Easy 0.2.44 검증 기록

[남은 F3](remaining-work.md#f3-세부-현황) · [지원 기능](supported-features.md#소스-0244-추가-기능) · [프로젝트 상태](project-status.md)

검증일: **2026년 10월 23일**. **F3-B1 — 단일 중첩 체인의 표시 원점·접두부·상위 셀 정렬**을 보완한다. 소스·검증 패키지는 **0.2.44**, 실제 Codex 설치는 **0.2.42**, Claude Code·Cursor 설치·공개 ZIP은 **0.2.19**다. F3-B 전체 완료와 실제 설치 갱신을 뜻하지 않는다.

## 문제와 변경

정규화한 F2 문서의 셀 안 부동 표가 실제 한글에서는 왼쪽 여백 뒤에 놓이지만, 고정 WASM 렌더러에서는 가운데에 놓이고 앞쪽 글이 생략되는 사례를 재현했다. 대표 사례의 표 왼쪽 경계는 약 186.6px 대신 120.2px가 맞았다. 표를 포함한 상위 셀에 가운데/아래 정렬이 있을 때 접두부와 안쪽 표가 함께 밀리는 차이도 확인했다. 실제 HWP의 배치는 맞으므로 저장 구조를 변경해 미리보기를 맞추지 않는다.

`local_nested_render_view.mjs`는 검증한 프로필의 **일회용 사본 입력**에서만 접두부와 표를 별도 문단으로 표현하고 저장된 접두부 높이를 반영한다. 표를 포함한 상위 셀의 표시 정렬을 일반 셀 정렬과 구분하며 원래 셀 여백을 명시한다. `local_render_view.mjs`가 쪽/본문 경계를 검사하고 기존 F3-A 보정과 함께 이 문서를 연다. SVG·썸네일·렌더 좌표 진단은 같은 뷰를 사용한다.

진단의 텍스트 경로·표 제어 식별은 원래 경로로 되돌린다. 읽기·편집 대상은 원본에서 선택한다. 일회용 문서는 내보내기·저장에 사용하지 않는다. 원본 HWP의 **부동 상태·문단 수·셀 정렬·글자 서식·정의**와 복구 바이트를 보존한다. 변경 없는 미지원 뷰의 보고 한계가 기존 F1 원시 격자 배치 증명을 막지 않도록 구분했고, 보정한 뷰는 계속 그 증명에 사용할 수 없다.

## 지원 조건과 남은 범위

| 구분 | 범위 |
| --- | --- |
| 이번 지원 | 한 구역·가로·한 단, 한 루트의 깊이 2/3 단일 중첩 체인, 전체 표가 같은 쪽 본문에 들어오는 정규화된 F2 흐름 |
| 호스트/서식 | 상위 셀의 단일 문단·단일 표 앵커·지원 평문 접두부, 문단 여백/들여쓰기/앞뒤 간격 0, 100–300% 줄 간격, 위/가운데/아래 정렬. 기본/개별 셀 여백과 확인 가능한 격자 |
| F3-B2 미완료 | 복수 형제 표, 복수/복잡한 호스트, 분할된 루트와 다단. 원점/정렬을 추정해 보정하지 않고 미지원 이유 보고 |
| F3-C 미완료 | 글 너비에 따라 렌더러가 줄이는 셀 내부 여백, 좁은 셀의 폰트·줄바꿈/높이·쪽 계산. 예컨대 표 프레임 원점이 맞아도 안쪽 글의 왼쪽 여백은 다를 수 있음 |
| F3-D 미완료 | 꼬리말 간격, 표 뒤 빈 문단/후속 본문의 세로 간격, 추가 페이지/개체 기준과 복잡한 내부 여백/식별 프로필 |

`render_nested_tables`는 원래 표 ID·셀 경로·접두부 높이·상위 셀 정렬을 보고한다. `render_unadapted_tables`는 미지원 이유를 구분한다. `NESTED_TABLE_RENDER_ADAPTED`/`NESTED_TABLE_RENDER_UNVERIFIED`는 한계이며 **`diagnostics_complete:false`, `layout_verified:false`**를 유지한다. 아랍어 등 추가 조형은 D3 최후순위다.
