# 로컬 HWP Easy 0.2.51 검증 기록

[F4 확정 지원 범위](f4-support-0.2.51.md) · [남은 작업](remaining-work.md) · [프로젝트 상태](project-status.md)

2026년 10월 27일. 그룹/상자 내부 글상자·개별 하위 그룹·추가 필드의 읽기와 편집을 **하나의 F4 개선 묶음**으로 마감했다. 같은 Node/WASM 엔진과 원본 스트림 패치·같은 파일 저장·정확한 복구를 사용한다. 실제 설치·공개와 지원 밖 구조의 조판 인증은 별도다.

## 변경 사항

- 원본 제어 순서·그룹 자식·내부 문단 경로로 대상을 식별한다. 일반 커서에 없는 그룹 내부 글도 일회용 본문 투영으로 텍스트/글자 모양을 검사한다. 임시 문서는 저장하지 않는다.
- 내부 글의 교체·범위 편집·혼합 서식·문단 정렬/간격과 문단 나누기·합치기·추가·복제·삭제를 지원한다. 배치의 원래 대상은 레코드 출처로 추적하며, 필드 중간 분할·모호한 대응·마지막 문단 삭제는 거부한다.
- 개별 하위 그룹의 이동·회전·크기를 직계 부모 좌표에서 처리한다. 선택한 트리의 변환을 반영하고, 필요한 정규 루트 좌표계 보정 뒤에도 비대상 실제 변환을 검사한다.
- 기존/내부 누름틀과 지원 추가 필드의 표시값·메타데이터를 구분한다. 누름틀 이름/안내, 다른 지원 필드 이름/명령, 하이퍼링크/범위 책갈피 생성과 지원 래퍼 삭제를 추가했다. 명령 실행·외부 접속·수식 계산/자동 갱신은 하지 않는다.
- `find`에 지원 글상자 문단을 포함한다. 내부 높이 위험은 내재 내용 프레임의 추정으로 보고하며 바깥 셀/쪽 좌표로 오인하지 않는다.

실제 한글 비교에서 **하위 그룹 축소/이동 후 비대상 형제가 늘어나는 차이**를 발견했다. 상위 내용 경계가 바뀌자 한글이 기존 바깥 프레임에 다시 맞추던 문제다. 지원하는 1:1 독립 부동 루트의 원점·프레임·자손 좌표계를 함께 보정했다. 시험의 아래 형제 선이 원래 `y=400`에서 `418`로 밀리던 차이를 제거하고, 최종 `y=400`과 형제 영역 픽셀 일치를 확인했다. 형제 바이트가 같다는 검사만으로 통과 처리하지 않았다.

도형 모서리는 원래 색의 쪽 이미지에서 ±2px 이내 선을 확인한다. 형제 영역과 복구 이미지는 정확한 픽셀 비교다. 메타데이터만 바꾼 비어 있지 않은 필드의 표시도 동일하게 유지했다. 동적 필드 검사는 저장된 캐시의 보존/편집이며 외부 재계산의 의미를 인증하지 않는다. `layout_verified:false`를 유지한다.

24개 프로필은 그룹 글·빈/동일 문구·서식·문단 경계/추가, 중첩 그룹·셀/중첩 셀·상자 내부 상자, 필드 값/이름/안내/생성/삭제, 하이퍼링크/범위 책갈피·날짜 캐시, 글·그림·혼합 하위 그룹과 바깥 그룹 변형을 포함한다. 지원 밖의 깊은 조상/비정규 프레임 보정·세로쓰기·필드 실행/복잡 범위는 [F4 범위](f4-support-0.2.51.md#지원-밖의-조건)에 남긴다.

## CI·설치·공개

**GitHub Actions 0회, computer-use 0회.** CI는 여전히 `workflow_dispatch` 전용이며 사용자 명시 요청 때만 실행한다. 새 F4 검사를 기존 수동 소스 검사 목록에 추가했지만 dispatch/rerun은 하지 않았다. 새 Linux CI 통과를 주장하지 않는다.

Codex 실제 설치는 **0.2.42**, Claude Code·Cursor 설치/공개 사전 릴리스는 **0.2.19**로 유지한다. 원격 0.1.9 코드/ZIP과 명시 호출 전용 정책을 보존한다. 파일 선택·UI 클릭·전역 설정/레지스트리·다른 한글 창 제어 없이, 신뢰한 합성 파일만 별도 숨김 Hancom Automation으로 대조했다.

## 재현

```sh
node --test --test-concurrency=1 tests/test_local_f4.mjs tests/test_local_complex_group.mjs tests/test_local_text_boxes.mjs
node scripts/package_local_plugin.mjs
node scripts/check-local-f4.mjs outputs/local-f4
python scripts/check-local-f4.py outputs/local-f4
# 선택적 개발 QA: 기존 Hancom Automation 설정이 있는 Windows, 합성 파일만 사용
python scripts/render-local-f4-native.py outputs/local-f4
python scripts/check-local-f4-native-images.py outputs/local-f4
```

새 출력 디렉터리에서 실행한다. 독립 판독에는 개발용 olefile, 이미지 비교에는 Pillow, 네이티브 QA에는 pywin32/한글이 필요하다. 제품 실행에는 추가하지 않았다. 증거는 로컬 `outputs/f4-051-20261027/verified/`과 상위 로그에 보관하고 개인 문서·QA HWP/이미지·설치본은 커밋하지 않는다.
